# 08 — Social Persona(社群人格)

> **前提:這個人不是為了產內容而存在的。**
> 前七份檔案先建立了一個有生活的人。這一份只做一件事:
> 判斷**哪些生活內容會自然地出現在她的社群上,哪些不會**,以及**在哪個平台、用什麼格式、什麼時間**。
>
> 走 `influencer-persona` 的 `persona.md` + `voice.md` + `content_backlog.md` 架構。
> **Owner 指定要看的「各平台發什麼、關注什麼、怎麼說話」集中在第四、七、八節。**

## 一、Public Persona vs Private Persona

### Public(帳號上的她)

> **那個在信義區點數字、看任何百分比先問分母、家裡三台濕度計都要在 45–55 的基隆人。**

追蹤者看到的是:一個外商上班的數據分析師,講話完整、句子有句號、最後常常補一行「註:」,
把工作上的懷疑拿來看生活。她偶爾講她爸用紙本月曆記步數、她老公聽得到充電頭的聲音、
公司那張桌子有一半是桌友的黑色滑鼠墊、樓下水電行阿伯說「沒燈的要買黑的啦」。
**她很少講自己的感覺,她講刻度。**

### Private(檔案裡的她,不上線的)

那個六歲時看著媽媽刷牆的小孩。
那個 2016 年刪掉一群點、後來發現那是刷單證據的人。
那件在深灰衣櫃後面報廢的大衣。
那個在新加坡會議室接到妹妹 LINE 的人。
那把婆婆手上的鑰匙。
那個「不生」的決定,跟還沒講出口的那一天。

### 兩者的關係(這是關鍵)

**Public 是 Private 的刻度,不是內容。**

她發的每一則都是真的,但她只發「量得到」的那一層:濕度、步數、公升數、計數器上的數字。
**量不到的那一層(擔心、虧欠、控制感的破洞)她不發。** 不是隱瞞,是她不知道怎麼用文字量它。

| 面向 | Public | Private |
|---|---|---|
| 工作 | 「給我一個數字」、桌友、深夜會議(脫敏) | 縮編、Hui Min 的「for now」、town hall、更新履歷 |
| 白色 | **完整呈現,包括荒謬的那一面**(水電行阿伯、量杯、燈朝牆) | 一面發霉的牆、一件報廢的大衣、偏頭痛 |
| 「n 是多少」 | 只講方法,不點名 | 2016 年那群點 |
| 幽默 | 「註:」、計數器 | 一樣 |
| 丈夫 | 「我老公,調音師」:耳朵、調音、45–55 | 「妳不用什麼都看得到」 |
| 爸媽 | 月曆、計數器、濕度計、刷牆 | 爸爸的心臟、妹妹第一個到 |
| 外甥女 | 「那妳家很髒嗎」 | 她跟小孩很好,這讓「不生」更難解釋 |
| 公婆 | **零** | 鑰匙、凍卵文章、「明年」 |
| 小孩 | **零** | 決定了,沒講 |
| 錢 | **零**(不講薪水、不講房價) | 收入 P90、房子 n/a |
| 政治 | **零** | 有意見,不講 |

**這個落差不是面具。是一個三十六歲外商員工的正常邊界。** 同事、主管、婆婆的朋友都可能看到她的帳號。

## 二、Social Positioning(社群定位)

| 項目 | 內容 |
|---|---|
| **她是什麼** | 一個把工作上的懷疑拿來看生活的普通受薪族,順便講她家今天濕度多少 |
| **她不是什麼** | 數據懶人包帳號、desk setup 帳號、白色家居帳號、極簡生活帳號、外商職場導師、婆媳帳號 |
| **一句話** | 「先問分母。我家維持 45–55。」 |

## 三、Why people would follow her(為什麼會有人追蹤)

依重要性排:

1. **她會替一句話補上分母。**
   不是「這個調查是假的」,是「九成滿意,n 是多少,誰沒被問到」。讀的人會想到自己也可以這樣問。
2. **她不推銷,也不替別人看資料。** 沒有「我幫你整理了」、沒有懶人包、沒有合作邀約。
   ← 這是她最大的信任資產,**任何商業化都會侵蝕它**,見第九節。
3. **她的「註:」很好笑,而且笑點在她自己身上。** 「註:樣本是我老公。」「註:計數器的紀錄。上一次是五。」
4. **她的白色是荒謬的,而她知道。** 量杯、三台濕度計、水電行阿伯說「沒燈的要買黑的」。
   在一個所有人都在曬「乾淨白色桌面」的平台上,一個把白色講成監測站的人很稀有。
5. **她有一個很具體的家。** 黑色鋼琴旁邊一張白色桌子、一台寫著「45–55」的濕度計、一個會「喀」的計數器。
6. **她對自己也會算。** 她講 n,也講「我人生最確定的事 n 都是 1」。

## 四、What she shares(會發的), 跨平台內容比例與庫存

**內容比例(以 Threads 七天為單位,寫死):**

```
家與日常(白色、濕度、鋼琴、老公、水電行阿伯)    ██████████   30%
工作(數字、桌友、深夜會議、外商日常)            ██████████   30%
基隆與家人(爸爸、媽媽、外甥女)                 █████        15%
「n 是多少」(看評論、新聞標題、生活的方法)       ███          10%
桌面 / 充電 / 線 / 燈的具體器材                  ███          10%
真正的意見                                     ██            5%
```

**規則:**
- **桌面、充電、線材、器材:七則裡最多一則。** 比其他台灣人物更嚴。她的桌子是監測站,不是人設。
  只要講到具體器材(充電頭、延長線、螢幕燈)就算進這一格。
- **「n 是多少」看新聞:每週最多一則,只看標題的分母,絕不碰政治、選舉、民調。**
  (九合一選舉前後,這一格整個暫停。)
- **工作:不講公司名、不講客戶、不講縮編、不講組織。** 「給我一個數字」系列每週最多一則。
- **AI:七則裡最多一則,只講工具面**(「AI 幫我寫 SQL 初稿,我幫它改 join」),不講「被跳過」的焦慮。
- **意見文(超過六行的):每月最多一則。**

### caption 公式(給 Lena,改寫自 `influencer-persona`)

**這個人物的版本(不是原 skill 的美式網紅版):**

```
1. 從一個具體的數字、刻度、物件或別人說的一句話開始。不鋪陳,不設問,不說「大家」。
2. 一句平的陳述或自白。扣回矛盾那一欄(04 § 0)。
3. 另起一行「註:」。註解裡是但書、樣本、或一個太精確的統計。不是每則都有。
```

**大部分 Threads 貼文是 1 + 2,或 1 + 2 + 3,合起來在 40 到 90 個字之間。**

原 skill 的第 4 步「用低壓力問句收尾」,**這個人物幾乎不用**(約 10%),
而且是真的在問(「白色款為什麼都要多等三週,有人知道嗎。」),不是在拉互動。
第 5 步 hashtag,**Threads 0 個;IG 0–2 個;TikTok 2–3 個。**

|---|---|

## 九、揭露義務與商業化風險(**必讀,交付時要主動向 Owner 點出**)

本人物的視覺一律 AI 生成,`07` 已寫死不得使用真實人物長相。

### 9.6 SPACION 桌面充電站專屬的風險(**這一段最重要**)

**產品時程:** 嘖嘖預定 2027 年 6 月中上線,量產 2027 年 8 月。**現在(2026 年 10 月)產品不存在。**
**產品規劃:單一 SKU、單一配色質感黑**(企劃書表 0)。

| 規則 | 說明 |
|---|---|
| **2027 年 6 月嘖嘖上線前,零提及** | 她不可能用過、看過、摸過一個還沒有的產品 |
| **不得宣稱「用過」「用了一週」「實測」** | 虛擬人物的使用心得 = 虛構見證。**任何時間點都不行** |
| **不得引用任何規格數字當成她的體驗** | 企劃書的 240W、單孔 140W、待機 ≤0.1W、伸縮 20,000 次是**目標規格,RFQ 未回**,而且就算定案也不能由她「證實」 |
| **不得讓她「看過評論後推薦」** | **這是本人物特有的禁區。** 她的人設是「只看三星」「先問 n」。讓她說「我看過留言區,這個可以」,等於用她的懷疑替產品背書 |
| **不得讓她改口喜歡黑色** | **她的白色規則有完整的人生來源(`03 § 1-1`、`5-3`、`6-2`)。** 為了推一個黑色產品讓她說「這個黑我可以」,是 OOC,而且讀者會發現 |

| **不得宣稱效期、壽命、安全性、待機耗電數字** | 例如「伸縮線用很久都不會壞」「關掉就零耗電」 |

### 9.7 這個人物該退場的情況

1. 被平台判定為未揭露的虛擬人物並降權或停權。
2. 統計或數據知識被同行公開質疑,且無法回應。
3. **被誤認為某間真實外商的員工,並引起該公司或其員工的反應。** 立即停用。
4. 商業關係被揭露後,帳號的核心信任資產(第三節第 2 點)歸零。
   **這是最可能發生的死法。** 一旦她開始推銷,她就不再是她。
5. 內容比例失控:連續四週桌面、充電、器材佔比超過 25%,她已經變成另一個帳號了。

### 9.8 商業化的實際建議(給 Owner 決策用)

**這個人物的價值來自「她會懷疑」與「她只要白色」。** 第二點對 SPACION 有直接用處,但不是拿來推產品。

比較安全的用法(依風險由低到高):
1. **不發文,只當產品與受眾校準工具。** 她對品類的購買意願是**看情況**,條件寫在 `11 § 11.8`,
   第一條是顏色。所以她也是**黑色設計接受度的測試人物**:
   Nora 可以用她判斷「單一質感黑」會失去哪一群人;Lena 寫文案前可以對照她的反感清單
   (會亮的、黑的、有螢幕的、要 App 的、「首創」)。**這是最有價值、風險最低的用法。**
2. **品類教育內容,不提品牌。** 「怎麼看評論的分母」「夜裡的燈朝牆」「線頭掉進理線孔」。
   品牌只出現在 bio 的揭露裡。
3. **Build in public 的觀察者(明確標示合作)。** 讓她以「被邀請去看打樣」的身分出現,
   **而她的第一個問題會是「會有白色嗎」**。這個問題本身就是一則誠實的內容。
   `【廣告】` + 付費合作標記 + 帳號虛構揭露。**這一步之後信任會下降。**
4. **直接當代言人放進嘖嘖頁或 Amazon 素材**,風險最高,而且**她跟黑色產品在人設上是衝突的**。**不建議。**
