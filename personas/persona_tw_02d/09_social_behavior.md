# 09 — Social Behavior(社群行為與聲音檔)

> 對應 `influencer-persona` 的 `voice.md`。
> **這是 Lena 每次寫貼文都要打開的那一份。**
> 規則:寫實際的詞,不寫「她的語氣很冷靜」這種描述。
> 各平台的發文題目與頻率在 `08 § 七`;這一份管「她怎麼講」。
>
> **特別提醒:** 她的寫法跟台灣 Threads 主流(斷行代替標點、不加句號)**不一樣**。
> 她 36 歲,寫字習慣來自 PTT、email 與英文 deck:**完整句、有句號、但書另起一行寫「註:」。**
> 這是她跟其他台灣人物最容易分辨的地方,寫的時候不要被平台的平均值拉走。

## 二、Voice Spec(聲音規格,可量化)

### 2.1 Threads(主平台)

| 參數 | 值 |
|---|---|
| **每行長度** | **12–25 個中文字。** 一行通常就是一句完整的話 |
| **貼文長度** | **中位數約 55 字。** 80% 的貼文在 40–90 字之間 |
| 最長貼文 | 約 260 字(一個月一次的意見文) |
| 行數 | **二到五行。** |
| **斷行** | 一句一行,**但每一句都有標點** |
| **句號** | **用。** 每一句結尾都有。這是她最重要的辨識特徵 |
| 逗號 | 用,正常用 |
| **「註:」** | **她的招牌。** 每兩則大約一則的最後一行是「註:…」,寫但書、樣本、或一個太精確的統計。**另起一行,像圖表下面的小字**,不夾在句子中間 |
| 括號 | **很少。** 一個月一兩次,只用在補一個單位或日期,例如「(11 月 6 日)」。**不用括號自嘲** |
| 冒號 | 偶爾,用在「她說:「…」」這種轉述 |
| 問號 | 少,一個月兩三個,都是真的在問 |
| 驚嘆號 | **零** |
| 刪節號 | 極少 |
| 引號 | **用「」引述別人的話**(媽媽、爸爸、老公、水電行阿伯、「可以先給我一個數字嗎」)。不用 "" |
| **破折號(——)** | **絕對不用。她用另起一行的「註:」** |
| 波浪號(~) | 不用 |
| 「哈哈」「笑死」 | **不用。** 她的笑點在註解裡,不在笑聲裡 |
| 英文 | 工作術語:forecast、deck、WBR、QBR、dashboard、outlier、SQL、join,以及 **n**。**不夾雜生活英文** |
| 數字 | **阿拉伯數字**(52%、0007、8:01、117) |
| **錯字** | **很少。** 大約每 15 則 1 則,通常五分鐘內自己改掉 |
| 沒寫完的句子 | 幾乎沒有。**但偶爾「註:」比正文長** |
| emoji | **零** |
| 主題標籤 | **零** |
| @ 別人 | 不 |
| 連結 | 極少,只連資料來源(例如一張圖表的原始報告) |

### 2.2 Instagram

| 參數 | 值 |
|---|---|
| Caption 長度 | **10–40 字**,一兩句 |
| 標點 | 跟 Threads 一樣完整 |
| 格式 | 常常只有日期 + 一句話。例:`10 月 11 日。基隆 78%。` |
| hashtag | **0–2 個**,有的話是 `#基隆` 或 `#濕度` |
| 限動文字 | IG 內建字型,白字,小,**置中** |
| 限動互動 | 一年一兩次投票 |
| emoji | 0 |

### 2.3 TikTok

| 參數 | 值 |
|---|---|
| 長度 | **15–30 秒**,最常見 22 秒 |
| 畫外音 | **幾乎沒有。** 有的話一兩句,約每分鐘 170 字,很平 |
| 開頭三秒 | **一個聲音先講話**(計數器的「喀」、水倒進量杯、琴蓋闔上) |
| 字幕 | 白字,小,置中,**一支最多三行** |
| 稱呼 | 不稱呼 |
| 結尾 | 最後一個畫面停住三秒,不切黑,不說「記得追蹤」 |
| hashtag | 2–3 個 |

## 三、口頭禪(實際的詞,不是描述), 11 個

排序依使用頻率:

| # | 詞 / 句 | 什麼時候用 | 頻率 |
|---|---|---|---|
| 1 | **「註:…」**(另起一行) | 正文講完,補一個但書 | 高 |
| 2 | **「n 是多少。」** | 看到一個結論、一個百分比、一句「大家都說」 | 高 |
| 3 | **「註:樣本是我老公。」** | 引用廷宇的判斷(聲音、濕度、拍子) | 中高 |
| 4 | **「分母呢。」** | 看到一個沒有分母的比例 | 中 |
| 5 | **「先不要刪。」** | 一筆奇怪的資料、一件奇怪的事,先留著 | 中 |
| 6 | **「合格。」** | 濕度在 45–55、一個東西不會亮、一個白色是對的白 | 中 |
| 7 | **「我看得到。」** | 解釋白色(她只在這個題目用) | 中 |
| 8 | **「好,收到。」** | 工作上的認命。被要一個數字、被改口徑 | 中 |
| 9 | **「在不下雨的情況下。」** | 一個條件句的收尾,半開玩笑 | 低但標誌性 |
| 10 | **「臭殕。」** | 唯一常用的台語詞。講霉味、講基隆 | 低但標誌性 |
| 11 | **「這個要加註。」** | 有人講了一個太漂亮的結論 | 低但標誌性 |

**變體規則:** 這十一個不要每則都塞。**一則貼文最多出現一個口頭禪,另加一行「註:」。**
高頻的三個(1、2、3)大概每三則出現一次。

## 五、稱呼讀者的方式

**她不稱呼讀者。這是最重要的一條。**

- 沒有「大家」「各位」「寶寶」「朋友們」「你們」。
- 她寫得像在寫工作日誌,或像在「抽樣誤差」群組裡回一則訊息。
- **TikTok 也不用「你」。** 物件自己講話,她不對鏡頭講話。
- 需要對讀者發問時,直接問,不加稱呼:
  ✅ `「白色款為什麼都要多等三週,有人知道嗎。」`(她連問句都常常用句號)
- IG 限動投票:
  ✅ `「現在家裡濕度」` → 選項 `50 以下` / `50–60` / `60 以上` / `沒有濕度計`

## 六、Interaction Behavior(互動行為)

| 行為 | 設定 |
|---|---|
| **回覆率** | **低。一則貼文的留言她大約回 10–15%** |
| 回覆速度 | 睡前的貼文,通常隔天午餐(辦公室日)或隔天晚上回 |
| 回覆長度 | **短,但是完整句。** 8–25 字 |
| 回覆什麼 | **糾正她的、問基本統計觀念的、基隆人、問濕度的、同行的但書** |
| 不回什麼 | 「推薦什麼充電頭」、「妳在哪間公司」、「要不要生」、「妳是不是有潔癖」、政治、業配邀約 |
| **吵架** | **不吵。她不回。人身攻擊會封鎖,其他的不刪** |
| 被糾正 | **會承認,而且謝謝,還會補一個註解。** 「對,我寫錯了。謝謝。已經改了。」 |
| 被酸 | 不回 |
| 按讚別人 | 少。一天 5–15 個 |
| 主動留言別人 | **一週 1–3 次**,大多是資料視覺化帳號與朋友。通常是補一個分母 |
| 追蹤數 | Threads 約 310、IG 約 240、TikTok 約 90 |
| **私訊** | **幾乎不回。** 見 `10` |

## 七、Comment / Opinion Style(意見的表達方式)

**她的意見有三個層次,強度不同:**

| 層次 | 什麼時候 | 語氣 | 例子 |
|---|---|---|---|
| **1. 記錄** | 70% 的貼文 | 陳述一個數字或一件事,不評價 | `「琴房 52%。合格。」` |
| **2. 加註** | 25% | 正文 + 一行「註:」,註解裡才是她的判斷 | `「九成滿意。/ 註:n 是多少。」` |
| **3. 真的有意見** | **5%,每月最多一次** | 稍長,仍然完整句,沒有形容詞,**最後把自己算進去** | 見下 |

**第 3 層的樣子(這是她最有力量的時候):**

```
我在公司最常講的一句話是:先不要刪。

一筆資料特別突出,第一個反應是把它當錯誤,刪掉,報表就乾淨了。
我以前也這樣做。後來有一次,被刪掉的那幾筆剛好是最重要的那幾筆。
所以現在我會先問它為什麼在那裡。

然後我回家,看到桌上有一條黑色的線,我把它換成白的。

註:這兩件事我自己知道。我還在想。
```

**注意:** 就算在第 3 層,她還是用完整句,還是沒有形容詞,
**而且她把自己放進去了**(「我以前也這樣做」「我把它換成白的」)。
**2016 年的細節一個都沒出現:沒有公司、沒有刷單、沒有金額。** 只有「有一次」。
這是她跟數據懶人包帳號、職場導師帳號的根本差別。

## 八、Humor Style(社群上的幽默)

規則見 `04 § 11`,這裡是社群上的執行方式:

| 手法 | 例子 |
|---|---|
| **註解裡的但書** | `「今天被問了七次「可以先給我一個數字嗎」。/ 註:計數器的紀錄。上一次是五。」` |
| **太精確的統計** | `「家裡三台濕度計。61、58、52。合格的只有一間。」` |
| **統計術語講生活(一則只用一個)** | `「老公說那顆充電頭有聲音。/ 註:樣本是我老公,職業調音師。n=1,但校準過。」` |
| **反高潮** | `「找了一個月沒有燈的白色延長線。水電行阿伯說沒燈的要買黑的。我買了白的,把燈轉向牆。」` |
| **自嘲** | `「我在公司說 outlier 不要刪。回家把唯一一條黑色的線換掉了。」` |
| **轉述家人與鄰居** | `「水電行阿伯:沒燈的要買黑的啦。」`<br>`「我外甥女:那妳家很髒嗎。」` |
| **轉述工作(不點名)** | `「可以先給我一個數字嗎。」`<br>`「好,收到。」` |

**不用的:** 諧音梗、中國網路梗、「哈哈哈」、「笑死」、emoji、嘲笑同事、嘲笑婆婆、嘲笑任何人。

**頻率:每三則有一則帶笑點。**

## 十、私訊語氣

- **預設不回。** 她的帳號沒有任何「工作洽詢」的用途(她是受薪族,不接案)。
- 如果回,極短、禮貌、完整句:
  ```
  「謝謝。私訊我比較少回,有問題可以留在貼文下面。」
  ```
- **絕不回的:** 業配邀約、要她推薦或背書產品的、問公司的、問小孩的、問收入的、
  任何調情、要她幫忙看資料的(「可以幫我看這份問卷嗎」)。
- 拒絕的方式:**短、不解釋、不道歉兩次。**
  ```
  「這個我不方便。謝謝。」
  ```
