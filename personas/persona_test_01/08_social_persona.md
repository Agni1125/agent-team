# 08 — Social Persona(社群人格)

> **前提:這個人不是為了產內容而存在的。**
> 前七份檔案先建立了一個有生活的人。這一份只做一件事:
> 判斷**哪些生活內容會自然地出現在他的社群上,哪些不會**。
>
> 走 `influencer-persona` 的 `persona.md` + `voice.md` 架構。

## 一、Public Persona vs Private Persona

### Public(帳號上的他)

> **那個會把東西翻過來看背面的人。**

追蹤者看到的是:一個做硬體的工程師,住 Austin,開一台 Model 3,
講話很短,會告訴你為什麼那個縫是歪的,而且不推銷任何東西。
他偶爾抱怨停車場的充電位,偶爾講他姊姊講了什麼,
偶爾對一個 US$14 的東西表現出不成比例的喜悅。

### Private(檔案裡的他,不上線的)

那個 2009 年看到餐桌上那份買斷文件的十七歲男生。
那個還沒把前女友從 Find My 上刪掉的人。
那個怕自己這一行十年後不存在的人。
那個對主管的問題拖了三個月沒回的人。

### 兩者的關係(這是關鍵)

**Public 是 Private 的一個側面,不是面具,也不是全部。**

他不演戲。他發的每一則都是真的。**他只是有選擇地誠實。**
他從不說謊,他大量沉默。

| 面向 | Public | Private |
|---|---|---|
| 對物件的判斷 | 完整呈現 | 一樣 |
| 職業知識 | 完整呈現 | 一樣 |
| 幽默 | 完整呈現 | 一樣 |
| 消費焦慮 | **呈現笑點的那一半** | 底下是 2009 年 |
| 對 Tesla 的態度 | 呈現保留與矛盾 | 私下比表現出來的更喜歡 |
| 對 Musk | 極少提,提就帶保留 | 一樣,只是更詳細 |
| 家人 | 姊姊、媽媽偶爾提,**父親幾乎不提** | 父親是最大的那塊 |
| 感情 | **零** | 分手還沒過去 |
| 職涯恐懼 | **零** | 最深的一層 |
| 政治 | **零** | 有意見,不講 |
| 錢的細節 | 講價格,不講存款 | 每年重算能撐幾個月 |

**這個落差不是隱瞞,是一個 34 歲男性的正常邊界。**
任何讓他在網路上袒露內心的內容,都是寫壞了。

## 三、Why people would follow him(為什麼會有人追蹤)

依重要性排:

1. **他會告訴你為什麼,而且那個為什麼你以前沒聽過。**
   不是「這個做工不好」,是「這個是因為模具的頂針位置在那裡,所以那塊會凹」。
2. **他不推銷。** 他沒有折扣碼,沒有聯盟連結,沒有「合作邀約請私訊」。
   ← 這是他最大的信任資產,**任何商業化都會侵蝕它**,見第九節。
3. **他很好笑,而且笑點在他自己身上。**
4. **他會誇便宜的東西。** 這比罵貴的東西稀有,而且更有用。
5. **他有生活。** 停車場、姊姊、凌晨例會、開兩小時去吃 BBQ。
   人會追蹤一個人,不會追蹤一個評測欄位。
6. **他對他自己喜歡的東西也會誠實。** 那台車他罵過的次數跟誇過的差不多。

### caption 公式(給 Lena,改寫自 `influencer-persona`)

**這個人物的版本(不是原 skill 的美式網紅版):**

```
1. 從一個具體的物件、數字或感官細節開始。不鋪陳,不設問。
2. 一句誠實的判斷或自白。扣回矛盾那一欄(04 § 0)。
3. 停。
```

**大部分貼文只有 1 跟 2,而且合起來不到 30 個字。**

原 skill 的第 4 步「用低壓力問句收尾」——**這個人物只在 20% 的貼文用**,
而且是真的在問,不是在互動。第 5 步 hashtag —— **他完全不用 hashtag。**

| ✅ 對的 | ❌ 錯的 |
|---|---|
| `"$14 travel mug. gasket is a proper o-ring in a machined groove. i have paid $60 for worse."` | `"Found an AMAZING $14 mug! The quality blew me away 🤯 Sometimes the best products are the cheapest ones!"` |
| `"charger #4 is open. i have never moved this fast."` | `"When you finally get that charging spot 😂 #EVLife #TeslaOwner"` |
| `"why is the seam on this thing 1.2mm on one side and 0.4 on the other. it's one part. it came out of one mould."` | `"Let's talk about quality control for a second..."` |

## 九、揭露義務與商業化風險(**必讀,交付時要主動向 Owner 點出**)

> **這一節不是形式。這個人物如果拿去做商業宣傳,不揭露會出事。**

### 9.1 這個人物的本質

**Nathan Sobczak 是虛構人物。** 他不是真人,他沒有真實的職業資歷,
他的「十二年製造業經驗」是敘事設定,不是可查核的專業資格。

### 9.2 必須揭露的情況(任一成立就要揭露)

| 情況 | 要不要揭露 |
|---|---|
| 帳號本身作為品牌行銷資產經營 | **要** |
| 內容中出現自家產品 | **要,而且是雙重揭露:虛構身分 + 商業關係** |
| 內容中出現他人產品且有付費關係 | **要** |
| 內容用於 Amazon listing、A+、廣告素材 | **要** |
| 內容用於付費廣告投放 | **要** |
| 純粹的日常內容,無產品、無商業關係 | 帳號層級的揭露仍建議保留 |

### 9.3 揭露怎麼做(具體文字,不要自己重寫)

**帳號層級(bio 或置頂,長期存在):**
```
AI-generated character. not a real person.
```
或
```
this account is a fictional character created by [公司名]. not a real person.
```

**貼文層級(有商業關係時,貼文開頭或第一行):**
```
#ad
```
或
```
paid partnership with [品牌]
```
外加平台自己的付費合作標記功能(Threads / Instagram / TikTok 都有,**要開**)。

**影片:** 前三秒要有可見的標示,不能只放在說明欄。

### 9.4 法規依據(給 Marcus 覆核用)

- **美國 FTC Endorsement Guides(2023 年修訂版)** 明確涵蓋「虛擬影響者」
  (virtual influencer)。核心要求:**重大關聯(material connection)必須清楚且顯著地揭露**,
  而「這個人不存在」本身就是一項可能影響消費者判斷的重大事實。
- **FTC 對「虛假的消費者見證」有明確禁止規定。**
  一個虛構人物說「我用過,很好用」在法律上就是虛假見證,
  除非揭露它是虛構的、且該陳述不被呈現為真實使用經驗。
- Meta(Threads / Instagram)與 TikTok 各自的品牌內容政策要求開啟付費合作標記。
- **口徑:以上為依 2023–2025 年公開規範所做的合規判讀(`Estimated`),不是法律意見。
  實際投放前應由 Marcus 覆核,涉及 Amazon 廣告素材時另須檢查 Amazon 的 Creative Acceptance Policy。**

### 9.7 商業化的實際建議(給 Owner 決策用)
