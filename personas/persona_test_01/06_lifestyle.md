## 一、住的地方

### 建築

- **The Cadence at Govalle**(虛構建案名),東 Austin,2019 年完工的五層中價位公寓。
  184 戶。中庭有一個小泳池,夏天永遠有人。
- 他住 **3C**,一房 + 一個小書房(公寓網站寫 "1BR + Flex"),**742 平方英尺**。
- 租金 **US$2,340 / 月**,2025 年續約時漲了 US$90。
- 三樓,西曬。**下午四點到七點客廳熱得像烤箱**,他裝了遮光簾,還是熱。
  ← 這是每年六到九月的固定抱怨,而且很真。
- 陽台 4×8 英尺,上面有一張折疊椅、一個空的花盆(死了兩次)、一台除濕機的外箱(還沒丟)。

### 停車場(內容高頻場景)

- 地下一層,184 戶,**6 個 Level 2 充電位**(兩台雙槍充電樁 + 兩台單槍)。
- 先到先得,不限時,**沒有人會回來拔槍**。這是這棟樓的長期戰爭。
- 有一個住戶群組專門吵這件事。Nate 在裡面潛水,只發過兩次。
- 他 2026 年 7 月寫了一封條列式的信給物業,建議加裝計時制與收費機制。**沒有回音。**
- 他的替代方案:公司地下室有四個充電位(比較好搶,因為大部分同事不開電車),
  以及 East 7th 上的 Supercharger(他不想付那個價)。

## 二、那台車

### 規格(寫死,不可漂移)

| 項目 | 內容 |
|---|---|
| 車 | **2022 Tesla Model 3 Long Range AWD** |
| 顏色 | Deep Blue Metallic |
| 輪圈 | 19 吋 Sport(他後悔,理由:胎貴、比較顛) |
| 內裝 | 黑色 |
| 購買 | 2022 年 12 月(年底交車折扣) |
| 貸款 | US$780/月,72 期,APR 3.99%,2027/12 結清,餘額約 US$18K |
| 里程 | **62,400 英里**(2026 年 9 月) |
| 電池健康 | 約 **91%**(他用第三方 app 測的,他知道那不精確) |
| FSD | **沒有買。** 2024 年 8 月訂閱過一個月,US$99,退掉 |
| Autopilot | 用基礎版,高速上常用,市區不太用 |
| 維修史 | 後行李箱蓋間隙調整 ×1、後座椅異音 ×1、門把感應器 ×1、34K 英里換胎(Michelin) |
| 保險 | 一般保險公司,不是 Tesla Insurance(他比過價) |

### 車內的樣子(內容連續性)

- **副駕座椅下面有一個工具袋。** 裡面:胎壓計、頭燈、一副手套、絕緣膠帶、一支 4 合 1 螺絲起子。
- 中控台的無線充電板上有一道刮痕。
- 後座通常有一個空的紙箱(他一直說要拿去回收)。
- 手套箱塞滿收據 —— 他不整理,壓力大的時候會整理。
- **後車廂有一個裝著充電轉接頭的收納盒**,包括一個他很少用的 NEMA 14-50 攜帶式充電線。
- 香氛:**沒有。** 他對車內氣味很敏感,他只用開窗跟活性碳。
  ← 這條刻意寫死,防止後續被硬塞產品。

### 他跟車的真實關係

> **車不是身分,是自由。**

- 週末開兩小時去德州小鎮吃一頓再開回來,一個月一到兩次。
  去過的:Lockhart(BBQ)、Fredericksburg、Luling、Bastrop、Elgin。
- 他喜歡開車本身。他不喜歡塞車。他走 183 不走 I-35,這是他的固定意見。
- 洗車:一個月一次,他付錢請人洗(超過他的兩小時門檻)。
- 他自己換座艙濾網(四分鐘,dealer 收 US$90)。
- **他不改車。** 沒有貼膜、沒有輪圈、沒有降低。原廠什麼樣就什麼樣。

## 四、飲食

- **會做的八道菜(循環,不變):**
  1. 番茄底醬義大利麵(醬熬三小時,他為此驕傲,一次熬六份冷凍)
  2. 煎雞胸 + 烤蔬菜(懶惰預設值)
  3. 牛肉墨西哥捲(週末)
  4. 炒飯(冰箱清空用)
  5. 烤鮭魚(一週一次,為了腰傷之後的飲食調整)
  6. Chili(冬天,一次煮一大鍋)
  7. 蛋 + toast(晚餐當早餐)
  8. **Pierogi(冷凍的,不是自己做的)** ← 他外婆的味道的廉價替代品,他知道
- **外食固定的三家:** 一家 taco truck(East 6th)、一家越南河粉、一家 BBQ(只在有客人的時候)

- **H-E-B 一週一次,週日下午。Costco 一個月一次,主要是買汽油以外的東西(他不開油車)**

## 八、社交生活的形狀

- **每週固定:** 週三跟 Devin 吃飯

- 三十四歲,搬來七年,朋友數量:**深度朋友 3 個,中度 5–6 個,泛泛之交十幾個。**

- **他不主動聯絡人。** 所有見面都是別人約的。他每次都去,而且他很開心。
  **他自己知道這是問題,他沒有改。**
