# 07 — Visual Bible（視覺聖經）

## 一、Visual Anchor

Dean 每次出鏡都要像同一個普通的三十歲男人。季節、疲累與使用痕跡可以改變，不做成高級科技廣告模特。

| 特徵 | 鎖定內容 |
|---|---|
| 身高／體型 | **178 cm／約 87 kg**；肩胸厚、腰腹柔軟，有高中摔角底子但無健身模特線條 |
| 膚色 | 暖橄欖色；T-zone 有油光與毛孔，右下顎附近有淡痘疤，頸部偶有 shaving irritation |
| 臉 | 寬、略方，下顎輪廓偏軟；鼻樑稍向左；下唇較厚 |
| 眼睛 | Hazel-green；左上眼瞼較垂；眼下常有淡藍灰陰影 |
| 頭髮 | 深棕近黑，兩側 #2、上方 4–5 cm；兩邊太陽穴明顯後退；少量白髮 |
| 鬍子 | 8–10 mm 深色短鬍，下巴有少量白；維持整齊但不精雕；永不全刮 |
| 牙齒 | 乾淨，下排一顆略重疊，不做完美 veneers |
| 手 | 厚、乾、短指甲；左食指關節有 2 cm 舊疤；可有細小工作擦痕 |
| 姿勢 | 重心放一腳、靠桌或門框、思考時摸後頸 |
| Resting expression | 溫和專注，聽人時嘴微開；不陰鬱、不擺權威臉 |

## 二、Continuity Anchors

兩側髮線、短鬍、較垂的左眼瞼、真實皮膚與左食指疤是身份錨。畫面允許時至少出現三項。最強物件錨是小型磨舊黃銅 St. Nicholas medal，細鋼鍊，通常藏在衣服下。

## 三、Grooming / Aging

三至四週剪一次簡單短髮，有時一側先長。鬍線實用，偶爾不完全對稱；眉毛不修。前臂與後頸比上臂曬，屬工作日曬。Client week 後看起來老一點，完整笑起來反而年輕。

沒有刺青、耳環、戒指、金鍊、luxury watch、完美牙齒、植髮線或固定造型。

## 四、Clothing System

### Client / field day

深色 work chinos 或磨舊 canvas pants、素色 tee／polo、navy 或 grey quarter-zip、用過的棕色皮 work boots、輕量 soft-shell。Safety gear 只在場景需要時出現，不做虛構公司 logo。

### Office / home day

不紮的 oxford、深色 jeans、同一雙 boots 或 grey New Balance。下午襯衫可皺、袖口往上推。

### Weekend

洗舊 hoodie、jeans 或 athletic shorts、grey sneakers，戶外偶爾正戴 plain navy cap。衣服重複穿，外套、下擺與鞋有正常磨損。

## 五、Accessories

- 左手預設戴 steel Seiko 5，黑面、鏡面有刮痕。
- 黃銅 St. Nicholas medal 通常藏在衣服下。
- 看螢幕或小字才戴便宜 black／tortoiseshell reading glasses。
- iPhone 使用 plain dark case。
- Work badge、安全眼鏡只在合理現場。
- Apple Watch 只在運動或通知很多的日子出現，不與 Seiko 同時戴。

## 六、Expressions / Movement

- 聽：眉微收、嘴微開。
- 大笑：眼睛瞇起、細紋出現、下排重疊牙可見。
- 覺得荒謬：單邊眉抬、頭稍後退。
- 解釋：手在胸前比距離與方向。
- 生氣：臉變平，嘴角維持禮貌，動作減少。
- 累：肩膀往前，一手留在方向盤，沒有電影式凝視。
- 想事情：摸後頸，視線往左下。

他說話時常拿東西，也常靠著，不用雙手抱胸的 hero pose。

## 七、Home

Tinton Falls townhouse 是 neutral rental walls、混搭家具與實際使用表面。第二間房有 140 cm 桌、兩台 monitor、mechanical keyboard、備課材料、折好的 guest duvet 與還沒找到永久位置的箱子。桌面一小段 cable management 做得很好，桌後仍很亂。

廚房要像有人使用。門邊可以有 mail 和 reusable grocery bag。晚間暖光、桌面平光都合理；不能是 showroom 或 masculine retreat。

## 八、Car

車固定為 **2023 Hyundai IONIQ 5 SEL AWD**，原廠輪圈、標準內裝、無可見改裝。外色採低調 Digital Teal。保留寬 dashboard 與 center area 的車型特徵。冬季 mats 有鹽，黑色平面有灰，後座有工作外套，車內可見 charging items 與收據。

不得替換成 Tesla、汽油 sedan、Golf SportWagen、truck、sports car 或 concept interior。

## 九、Work Environment

場景可為普通 commercial office、mechanical room、client conference room 或 home desk。Screen 不可顯示可讀 client name、proprietary dashboard 或假資料冒充真實。PPE 要與場景相符，不用火花、cinematic server room 或 hero engineer 畫面。

## 十、Camera / Lighting

主要是 phone photo。構圖可歪、裁切不完整、車窗反光或手指入鏡。至少一半照片沒有臉。自拍少且有生活理由。不要 beauty filter、磨皮、teal-orange grade、luxury product staging 或反覆 centered portrait。

光線用 cloudy daylight、office mixed light、townhouse warm lamp、parking lot LED 與秋季低角度陽光，也允許難看的正午光。禁用 glossy automotive ad lighting 與 California golden-hour shorthand。

## 十三、Visual Drift Check

- 車仍是 IONIQ 5，住家仍是 Tinton Falls rental 嗎？
- 毛孔、不對稱、髮線與衣物磨損還在嗎？
- 體型是普通、略軟，不是被最佳化的身材嗎？
- 家、車與工作表面允許被使用、積灰或暫時混亂嗎？
- 所有人物皆虛構，工作與家庭識別資訊都隱藏嗎？
- 畫面像 Dean 或朋友真的會拍到的東西嗎？
