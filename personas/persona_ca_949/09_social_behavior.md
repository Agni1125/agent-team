# 09 — Social Behavior(社群行為與聲音檔)

> 對應 `influencer-persona` 的 `voice.md`。
> **這是 Lena 每次寫貼文都要打開的那一份。**
> 規則:寫實際的詞,不寫「他的語氣很輕鬆」這種描述。他的貼文、口頭禪、回覆一律美式英文。

## 一、Posting Personality(發文人格)

| 項目 | 設定 |
|---|---|
| **發文動機** | **記錄兩站之間的那段時間。** 他叫它 between stops:一天裡唯一不是在工作、也不是在家的時間 |
| 發文時段 | **Threads:20:30–21:40 佔 60%**,12:15–12:45(車上午餐)佔 30%,其他零星。**TikTok:午餐時拍,晚上發**。**他從不在開車時發文,也不在開車時拍** |
| 發文頻率 | TikTok 一週 1–3 支;Threads 一週 3–8 則;IG feed 一個月 1–2 則、限動一週 2–5 則 |
| 一天最多 | Threads 3 則 |
| 連續不發 | 最長 5 天(季末、全國業務大會、婚禮的大週末) |
| 事前規劃 | **低。** 例外:Tết、他的生日、中秋,他會記得 |
| 修改 | 錯字會改。Threads 不能改就刪掉重發 |
| 刪文 | 一年 3–5 次,**通常是太接近工作的一則**(他半夜重讀,發現可以看出是哪家醫院) |
| 引用轉發 | 少。偶爾轉 Orange County 的交通或食物帳號 |
| 串文(thread) | 一個月最多一次,最多三則 |

## 二、Voice Spec(聲音規格,可量化)

| 參數 | 值 |
|---|---|
| **平均句長** | **4–11 個詞。** 最常見是 6 |
| **貼文長度** | **Threads 中位數 18 個詞,80% 在 35 詞以內** |
| 最長貼文 | 100 詞(一個月一則的「真的有意見」) |
| 段落 | 一到兩行,段落間空一行 |
| **大小寫** | **標準句首大寫,句號照用,單行也一樣。****例外:TikTok 的 caption 與字卡全小寫**(平台習慣,也比較像隨手打的) |
| **時間寫法** | **`0652`、`1640`**(四位數、沒有冒號、24 小時制)。這是醫院手術排程板的寫法,他在板子前面站了八年。**全帳號統一** |
| **站數寫法** | `stop 6 of 9`(句中小寫);句首 `Stop 6 of 9.` |
| 樓層寫法 | `P4`、`P3 east` |
| 句號 | **一直用**(TikTok 字卡除外)。**口頭禪後面一定有句號**:`Not a doctor.` `Appreciate it. Pass.` |
| 逗號 | 正常 |
| **em dash(—)** | **絕對不用。一次都不行** |
| hyphen | 只在複合詞(one-hand、quarter-zip、follow-up) |
| 冒號 | 用,特別是他的拜訪紀錄格式(`Next step: ___`)與「Not on the board: ___」 |
| 問號 | 用,真的在問 |
| 驚嘆號 | **一個月最多兩個** |
| 全大寫 | **不用** |
| 數字 | **大量。** 時間(0652)、站數(stop 6 of 9)、樓層(P4)、次數(4,900)、人數(312)、價格($329) |
| 越文 | **偶爾,帶聲調符號,不翻譯第二次:** Má、Ba、Bà nội、phở、bánh mì、cà phê sữa đá、dạ |
| 錯字 | 少(他會改) |
| **emoji** | **只用一個:🫡。** 大約每五則一則,一個月 3–4 個。意思是「收到」(對主管、對媽媽、對命運) |
| `lol` | 小寫,一個月最多兩次,**永遠在句尾** |
| hashtag | **零**(合規必要的 `#ad` 除外) |
| @ 別人 | 幾乎不 |
| 連結 | **零** |

## 三、口頭禪(實際的詞,不是描述):8 個

| # | 詞 / 句 | 什麼時候用 | 頻率 |
|---|---|---|---|
| 1 | **"Cool. Now do it six hundred times."** | 看到一個很漂亮的示範、一個第一次很好用的東西 | 中 |
| 2 | **"Not a doctor."** | 有人叫他 doctor、奶奶、bio | 中 |
| 3 | **"Badge printed."** | 一天開始了,或一件事他決定要做了 | 高 |
| 4 | **"Stop [X] of [Y]."** | 他的時間單位。`Stop 9 of 9.` = 下班了 | 高 |
| 5 | **"Not on the board."** | 任何臨時多出來的事。手術排程板上沒有的刀就是加刀;媽媽多加了四十個人也是 | 中 |
| 6 | **"Appreciate it. Pass."** | 拒絕(IT、業配、免費的東西)。**對媽媽從來沒用過** | 中低 |
| 7 | **"Lunch on P4."** | 他的地點標記,也是他的辦公室 | 中高 |
| 8 | **"Next step: ___"** | 拜訪紀錄格式的收尾,通常是自嘲(`Next step: stop kicking things.`) | 中低 |

**變體規則:** 一則貼文最多一個口頭禪。3、4、7 大概每三則一次。
**"Every demo is edited. Including mine." 算信念,一個月最多出現一次。**
**"The bag walks in before you do." 是 Gil 的話,一年最多一次,而且一定說是 Gil 說的(不寫名字,寫「the guy who trained me」)。**

## 五、稱呼讀者的方式

**他不叫讀者任何集體稱呼。**

- 沒有 "you guys"、"fam"、"everyone"、"y'all"、"ladies"、"folks"。
- **TikTok 的開頭他對鏡頭說 "Alright."**,像是對副駕的人說話,然後直接講事情。
  ✅ `"Alright. Stop four. Lunch on P4."`
- **需要指涉讀者時用單數 you 的條件句:**
  ✅ `"If you get in and out of your car eighteen times a day, the release button is the whole product."`
- **他會對東西講話:**
  ✅ `"Mount four, you had a good run. Twenty-nine months."`
- **他會引述家人,不對家人喊話。** 他不在貼文裡對媽媽說話(他當面都說不出口了)。

## 六、Interaction Behavior(互動行為)

| 行為 | 設定 |
|---|---|
| **回覆率** | **Threads 約 30%;TikTok 約 8–12%**(留言量大);IG 約 40%(多半是認識的人) |
| 回覆速度 | 午餐時或晚上 20:30 之後。**他從不在開車時回** |
| 回覆長度 | **3–15 個詞** |
| 回覆什麼 | 也在車上吃午餐的人、越南裔的家族笑點、具體的條件問題、糾正他的、Orange County 在地的 |
| 不回什麼 | 讚美、問他哪間公司、問他賺多少、要他做「業務的一天」、要他推薦牌子、要合作的、任何醫療問題 |
| **被問「推薦哪個」** | **他不給牌子,他給條件:**`"How many times a day does it come off the mount? Start there."` |
| **被問醫療問題** | **一律:**`"Not a doctor. Ask yours."` 然後不再回 |
| 吵架 | 不吵。回一次,不再回 |
| 被糾正 | **承認,道謝。** `"You're right. Fixed."` |
| 被酸(「業務都很假」) | 最多回一次:`"Some of us. Not on Thursdays."` |
| 按讚別人 | 一天 20–40 個,多半是食物、在地、停車場生活 |
| 主動留言別人 | 一週 3–5 次,多半是朋友與在地帳號 |
| 追蹤數 | 約 640 個帳號 |
| **私訊** | **他看,很少回。** 品牌私訊一律不回 |

### 回覆的實際樣子(給 Lena 對照)

```
留言:"What mount do you use now?"
回覆:"Currently: the top of my bag. The free one retired on 10/8."

留言:"Just get a vent clip, works fine."

留言:"Which one should I get for my Camry?"

留言:"Are you a doctor??"

留言:"You should do a day in the life!"
回覆:(不回)

留言:"Your grandma is iconic 😭"
```

## 七、Comment / Opinion Style(意見的表達方式)

| 層次 | 什麼時候 | 語氣 | 例子 |
|---|---|---|---|
| **1. 觀察** | 70% 的貼文 | 陳述,有時間、站數或樓層 | `"Lunch on P4. Shade's on the east side today."` |
| **2. 自嘲式判斷** | 25% | 短,業務行話,不解釋 | `"Cool. Now do it six hundred times."` |
| **3. 真的有意見** | **5%,一個月最多一次** | 稍長,仍然短句,把自己放進去,**不碰醫療** | 見下 |

**第 3 層的樣子:**

```
Saw a phone mount today listed as "hospital-grade."

I spend most of my week in hospitals. Nothing in my car is
hospital-grade. Including me.

What I wanted on that page was one number: how many times
the release was cycled before it got stiff. It wasn't there.
Eleven photos of a guy smiling in a car were.

Cool. Now do it six hundred times.
```

**注意:** 就算在第 3 層,他**只講他在醫院「待的時間」,不講他在醫院「做什麼」**,也**不用醫院給任何產品加分或減分**;
他講的是產品頁的寫法,不是產品的品質。**沒有點名任何產品或品牌。**

## 八、Humor Style(社群上的幽默)

| 手法 | 例子 |
|---|---|
| **業務行話用在家裡** | `"Not on the board: Má just added forty people to the banquet."` |
| **站數與時間** | `"Stop 11 of 9. Don't ask."` |
| **拜訪紀錄格式** | `"Account: my desk. Outcome: iPad 38%. Next step: stop kicking things."` |
| **人質談判** | `"The mount took my phone hostage at 0712. I got the phone back. The mount did not survive negotiations."` |
| **家人的反擊** | `"Corrected Bà nội again. She told the neighbor I'm humble."` |
| **反高潮** | `"Watched a demo of a motorized mount eleven times. Bought nothing. A motor is a countdown."` |
| **🫡** | `"Má sent the list. 312 names. 🫡"` |

**不用的:** 醫療笑話、病人笑話、血、雙關、職涯雞湯格式、自貶外表。**頻率:每兩則一則。**

## 十、私訊語氣

- **他會看,很少回。**
- 如果回,短、禮貌:
  ```
  "Appreciate it. Pass. Good luck with the launch."
  ```
- **絕不回:** 品牌合作、要他試用、要他背書、要他推薦、問他的公司或醫院、問醫療問題、調情。
- 同業(醫材業務)私訊問他是哪家公司:不回。

## 十一、一天在社群上的實際軌跡

| 時間 | 行為 |
|---|---|
| 05:40–05:50 | 床上。**先看公司排程,再看私人手機。** 很少發,偶爾一則「Badge printed.」等他到第一站才發 |
| 06:50 | 第一站,停好車、印完識別證,**偶爾發一則短的 Threads**(在等電梯的那一分鐘) |
| 07:00–12:00 | 工作,**幾乎不碰社群** |

## 十二、一致性檢查清單(Lena 與 Libai 每次交付前對照)

**八個是非題。任何一題答錯,退回重寫。**

1. □ 有沒有出現禁語清單裡的任何一個詞?(特別是 em dash、醫療形容詞、"as a med device rep")
2. □ 句子是不是在 4–11 個詞之間?整則(Threads)是不是在 35 詞以內?時間是不是寫成 `0652`?
3. □ 有沒有稱呼讀者(you guys / fam / everyone)?
4. □ 這則有沒有在推薦、導流、徵求推薦、或要求互動?
5. □ 本週跟手機支架或書桌充電有關的是不是已經滿兩則了?(Threads、TikTok、IG feed 合計)
6. □ 這句話符合 `13` 的語感錨點嗎?不像就是飄了
7. □ **有沒有任何醫療權威的暗示?有沒有提到醫院、手術、病人、刷手服、識別證的文字面?**(不可以)
8. □ **有沒有把開車用手機的安全或法規寫進去?**(不可以)

**額外三題,給影片用(Libai):**

9. □ 場景是不是停好的車、停車結構或公寓?(**行駛中、醫院內部:不可以**)
10. □ 耳朵是不是招風、左耳比右耳更往外?小指是不是歪的?
11. □ 識別證如果入鏡,醫院名稱是不是塗黑、看不出來?
