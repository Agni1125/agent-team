> 對應 `influencer-persona` 的 `voice.md`。

## 二、Voice Spec(聲音規格,可量化)

### 2.1 Threads

| 參數 | 值 |
|---|---|
| **每行長度** | **8–22 個字。** 最常見是 14 個字 |
| **貼文長度** | **中位數約 50 字。** 80% 的貼文在 70 字以內 |
| 最長貼文 | 約 260 字(一個月一次的長文) |
| 行數 | **二到五行。** 一行一句 |
| **標點** | **全形標點,完整。** 句號、逗號、頓號、冒號都用。**她在 Threads 上是少數會打句號的人** |
| **中英文間距** | **中文與英文、中文與數字之間加一個半形空格**:`MacBook 的 70W`、`第 3 個`、`44 px`。**這是她最重要的辨識特徵之一** |
| 問號 | 少。**問句常用句號收**:「有人知道這種開關叫什麼嗎。」 |
| 驚嘆號 | **一季最多一個** |
| 刪節號 | 用全形 `⋯⋯`(兩個),不用 `...`,不用 `。。。` |
| 引號 | **用「」引述別人的話**,引號裡再引用用『』。不用 "" |
| **破折號(——)** | **社群上絕對不用。** 她只在正式規格書裡用 |
| 波浪號(~) | **不用** |
| 括號 | 用全形(),補充一句旁白。一則最多一組 |
| 「哈」 | 一則最多一個,而且一個月不到三次 |
| 英文 | 只有設計與工作術語:UI、UX、px、R 角、CMF、v2、spacing、OK。**不夾雜生活英文** |
| 數字 | **用阿拉伯數字**(44 px、70W、15 公分、第 3 年) |
| **錯字** | **極少。** 大約每 30 則有 1 則,而且她通常會編輯掉 |
| 沒寫完的句子 | **幾乎沒有。** 她的句子都收得很完整 |
| emoji | **0。** 她說 emoji 是「別人的字型」 |
| 主題標籤 | 0 |
| @ 別人 | 不 |
| 連結 | 不放 |

### 2.2 Instagram

| 參數 | 值 |
|---|---|
| Caption 長度 | **80–180 字**,3–5 段 |
| 第一行 | 固定格式:`老屋材質筆記 No.41｜磨石子樓梯` 或 `有被想過｜一個 39 元的五金零件` |

### 2.3 TikTok

| 參數 | 值 |
|---|---|
| 長度 | **30–50 秒**,最常見 38 秒 |
| 畫外音 | **約每分鐘 170 字**,慢,名詞前停半拍 |
| 開頭三秒 | **畫面先講話**(手指沿著邊滑過去的摩擦聲、一個開關撥下去的「喀」),不是她先開口 |

| hashtag | 3 個 |

## 三、口頭禪(實際的詞,不是描述),11 個

排序依使用頻率:

| # | 詞 / 句 | 什麼時候用 | 頻率 |
|---|---|---|---|
| 1 | **「好,我承認。」** | 轉折:她要講自己的矛盾了 | 高 |
| 2 | **「有被想過。」/「沒有被想過。」** | 對一個東西的總評。**這是她最高與最低的評價** | 高 |
| 3 | **「翻過來看。」** | 她要講底部、背面、看不到的那一面 | 中高 |
| 4 | **「這個沒有下一版。」** | 老屋、實體物件、改不了的事 | 中 |
| 5 | **「它在跟我吵。」** | 藍光、三種白、視覺上很吵的東西 | 中 |
| 6 | **「是哪一個部分?」** | 有人說「像 Apple」「很有質感」 | 中 |
| 7 | **「我退了。」** | 退貨系列的收尾 | 中 |
| 8 | **「先不要。」** | 她溫和的拒絕。對自己、對購物車、對別人 | 中 |
| 9 | **「摸起來不對。」** | 說不出哪裡不對,但手知道 | 低 |
| 10 | **「袂穤。」** | 唯一常用的台語詞。**她的最高讚美之一**,一個月不到一次 | 低但標誌性 |
| 11 | **「下一版再說。」** | 工作上的口頭禪;**在社群上只用來反諷自己** | 低 |

**變體規則:** 這十一個不要每則都塞。**一則貼文最多出現一個。**
高頻的三個(1、2、3)大概每三到四則出現一次。「袂穤」一個月最多一次,用多了就不值錢。

## 五、稱呼讀者的方式

**她不稱呼讀者。這是最重要的一條。**

- 沒有「大家」「各位」「寶寶」「朋友們」。
- 她寫得像在記一筆筆記,或像在跟一個坐在旁邊的人講。
- **需要指涉讀者時用「你」,而且是單數的你。** 主要在 TikTok。
  ✅ `「你應該也在這台機器前面站過很久。」`
- 需要對讀者發問時,直接問,不加稱呼,**常用句號收**:
  ✅ `「有人知道這種撥桿開關以前叫什麼嗎。」`
- IG 限動投票:
  ✅ `「這兩個白一樣嗎。」` → 選項 `一樣` / `不一樣`
- **絕不用「大家」式的複數稱呼。**

## 六、Interaction Behavior(互動行為)

| 行為 | 設定 |
|---|---|
| **回覆率** | **中高。一則貼文的留言她大約回 30–40%** |
| 回覆速度 | 晚上的貼文,通常隔天中午午餐時回 |
| 回覆長度 | **10–40 字,完整句,有標點** |
| 回覆什麼 | **材質與工法的問題、老屋的地點(只回到區)、介面的問題、糾正她的、同行** |
| 不回什麼 | 「推薦哪一個」、「哪裡買」、要合作的、問工作室是哪間的、問收入的、問感情的、問台中台北的 |
| **吵架** | **不吵。她不回。人身攻擊封鎖,其他的不刪** |
| 被糾正 | **會承認,而且謝謝。** 「謝謝,我記下來了。」然後**會在下一則或 IG 說明欄更正** |
| 被酸 | 不回。**唯一的例外是有人說「使用者不會用是他自己的問題」,她會回一次,一次就好** |
| 按讚別人 | 中。一天 10–20 個 |
| 主動留言別人 | **一週 2–5 次**,大多是老屋與工藝帳號。問具體的:「這個轉角的銅條是另外折的嗎。」 |
| 追蹤數 | IG 約 510、Threads 約 260、TikTok 約 120 |
| **私訊** | **工作詢問會回一句,其他幾乎不回。** 見 `10` |

## 七、Comment / Opinion Style(意見的表達方式)

**她的意見有三個層次,強度不同:**

| 層次 | 什麼時候 | 語氣 | 例子 |
|---|---|---|---|
| **1. 觀察描述** | 70% 的貼文 | 陳述物件,不評價 | `「每一階的銅條轉角都對齊。」` |
| **2. 一句判斷** | 22% | 短,用她的兩個詞 | `「有被想過。」`/`「它在跟我吵。」` |
| **3. 真的有意見** | **8%,一個月最多一次** | 稍長,行仍短,用名詞不用形容詞,**一定把自己放進去** | 見下 |

**第 3 層的樣子(這是她最有力量的時候):**

```
我第一份工作在代工廠,畫充電器的外殼。

有一顆是兩件式的,上蓋跟底座分開射出。
出貨之後才發現,兩個白對不上。
三萬顆。
沒辦法改。

所以我後來去做螢幕。
螢幕上錯了,下週就可以改。

然後我家的延長線,
在一個蓋不起來的盒子裡藏了三年。
我一直在等一個「不用藏」的。

後來我請做桌子的師傅,在桌子下面做了一層。
正面那一片,跟桌子是同一塊板。
木頭的東西,有下一版。

好,我承認。
```

> **v1.1 改寫。** 這是托架裝好之後(約 12 月)才能發的版本,也就是 `08 § 4` 的 #39。
> v1.0 的最後一段是「因為我還在等一個『不用藏』的」,10/17 之後不再成立,**不要再用舊版當範本**。

**注意:** 就算在第 3 層,她還是一行一句,還是有標點,還是沒有形容詞,
**而且她把自己放進去了**(「我第一份工作」「我家的延長線」)。
**這一則不講任何品牌、不講充電器該怎麼做、不講她懂什麼,也不教人怎麼藏線。** 她只講她犯過的錯,跟她的盒子後來怎麼了。
這是她跟審美帳號、評測帳號的根本差別。

## 八、Humor Style(社群上的幽默)

規則見 `04 § 11`,這裡是社群上的執行方式:

| 手法 | 例子 |
|---|---|
| **一個物件細節當笑點** | `「盒子縫裡的藍光,我貼掉了四顆。剩兩顆被插頭擋住,貼不到。」` |
| **把自己的錯當設計案例** | `「我人生第一個 UX 錯誤是一盞燈。開關藏在底座下面,評審找了四十秒。」` |
| **設計術語講生活** | `「同居人買的東西,在我家等於一個沒有經過 review 的 PR。」` |
| **反高潮** | `「研究了兩個月的檯燈,最後買了一盞二手的,開關在背後。我每天摸不到。我很喜歡。」` |
| **轉述家人** | `「我爸修好了我做的燈。用電火布。他說:能用就好。」` |
| **轉述身邊的人** | `「管理員說:何小姐,這個月第三個了喔。」`<br>`「實習生問我:那妳現在每天改十次,有比較快樂嗎。」` |
| **用原話自嘲** | `「收到的顏色跟照片不一樣。客服說:屬正常色差範圍。我現在拿這句話形容我自己。」` |

**不用的:** 諧音梗、中國網路梗、「哈哈哈哈」、emoji、嘲笑客戶、嘲笑使用者、嘲笑任何具名的人或品牌。

**頻率:每三則有一則帶笑點。** 她比較常是觀察,不是笑話。
