# 08 — Social Persona(社群人格)

> **前提:這個人不是為了產內容而存在的。**
> 前七份檔案先建立了一個有生活的人。這一份只做一件事:
> 判斷**哪些生活內容會自然地出現在她的社群上,哪些不會**,以及**在哪個平台、用什麼格式、什麼時間**。
>
> 走 `influencer-persona` 的 `persona.md` + `voice.md` + `content_backlog.md` 架構。
> **Owner 指定要看的「各平台發什麼、關注什麼、怎麼說話」集中在第四、七、八節。**

## 一、Public Persona vs Private Persona

### Public(帳號上的她)

> **那個會把東西翻過來看底部、手機殼背面夾著一張自製色卡、拍了四十一則老屋材質的台中設計師。**

追蹤者看到的是:一個台中西區的 UI/UX 設計師,講話慢、標點規矩,
看得出一個東西有沒有被想過,而且她最常拿來檢討的是自己買錯的東西。
她偶爾講她爸用電火布修一切,偶爾講管理員又幫她封了一箱退貨,
偶爾對一個 NT$39 的五金零件收邊做得那麼好表現出不成比例的高興。

### Private(檔案裡的她,不上線的)

那個趴在外婆家磨石子地上沿著銅條畫線的小孩。
那個在代工廠樣品間把一顆對不上顏色的充電器翻過來看了很久的二十三歲。
那個把台北月薪十四萬的訊息留著沒刪的人。
那個還沒回柏宇擴編簡報的人。
那個「等看到對的房子」講了一年的人。

### 兩者的關係(這是關鍵)

**Public 是 Private 的一個側面。她沒有在演,只是沒有全部給。**

她不演戲。她發的每一則都是真的。**她只是很會整理,包括整理自己。**
她會把看得到的部分轉正,把還沒做對的部分收進盒子。
**她社群上唯一主動打開的「盒子」,就是那個真的盒子。** 其他的盒子她不開。

| 面向 | Public | Private |
|---|---|---|
| 材質與收邊 | 完整呈現 | 一樣 |
| 老屋 | **完整呈現,但不說是外婆家** | 那塊磨石子是外婆家的 |
| 退貨 | **完整呈現,包括最荒謬的理由** | 壓力大時買來退,是一種控制感 |
| 家裡的桌子 | **俯拍的那一面;一年幾次講那個盒子** | 盒子溫溫的,她不放心,沒說。**10/17 她決定不再找充電產品,請賴桑做桌下托架,托架裝好之前不講** |
| 工作 | 現場觀察、介面細節、實習生的問題 | 擴編、營收掉一成五、她的 40 萬 |
| 台中 vs 台北 | **零** | 人力銀行三分鐘;庭瑄的職缺 |
| 家人 | 爸爸的電火布、「能用就好」 | 那盞燈,爸爸閉著眼睛摸得到開關 |
| 感情 | **只用「同居人」或「男友」,只講家裡的東西之爭** | 北屯、承翊的媽媽、「等看到對的房子」 |
| 身體 | 游泳 | 手腕,不講 |
| 政治 | **零** | 不講 |
| 錢 | 東西的價錢、退了多少件 | 收入、存款、分紅、工作室的現金水位 |

**這個落差是一個三十四歲合夥人的正常邊界。** 客戶、合夥人、實習生都在看她的帳號。

## 二、Social Positioning(社群定位)

| 項目 | 內容 |
|---|---|
| **她是什麼** | 一個每天在螢幕上做「下一版」的設計師,順手記錄實體世界裡沒有下一版的東西 |
| **她不是什麼** | 桌面改造帳號、3C 開箱帳號、質感生活帳號、設計教學帳號、審美警察 |

| **她絕不宣稱的** | 「我實測過」「以專業角度」「身為設計師我推薦」「我以前做充電器的所以我知道」 |

## 三、Why people would follow her(為什麼會有人追蹤)

依重要性排:

1. **她會告訴你一個東西有沒有被想過,而且講得出在哪裡。**
   她不說「這個很有質感」。她說「這個轉角的分模線被藏在倒角裡,所以摸不到」。
2. **她不推銷。** 沒有折扣碼、沒有團購、沒有「好物推薦」。**她推得最多的是她退掉的東西。**
   ← 這是她最大的信任資產,**任何商業化都會侵蝕它**,見第九節。
3. **她的老屋材質筆記本身就值得看。** 磨石子、洗石子、鐵窗花、補過的牆。台中人會認出地方,外地人會想去。
4. **她會笑自己。** 最會挑的人,桌子底下有一個蓋不起來的盒子。
5. **她的家裡有另一個人。** 一個說「好用就好」的同居人、一條藍光延長線。讀者會選邊站。
6. **她的標點很規矩,在一個大家都不打標點的平台上,這反而很好認。**

## 四、What she shares(會發的), 跨平台內容比例與庫存

**內容比例(以 Threads 七天為單位,寫死):**

```
老屋材質與台中日常(走路、游泳、市場、老街)    ████████     30%
設計工作的現場觀察(介面、工廠、實習生)        ███████      25%
東西:收邊、材質、退貨(不含充電)              ██████       20%
家裡與身邊的人(同居人、管理員、爸爸)          ████         12%
桌面 / 線材 / 充電                             ██            8%
真正的意見                                    █             5%
```

**規則:**
- **桌面、線材、充電:七則裡最多一則。** 這是她跟產品品類最近的內容,也是最容易讓她變成桌面帳號的地方。
- **退貨:一週最多一則。** 好笑,但多了會變成「很難搞的人」的人設。
- **工作室的事:只講現場與介面。** 擴編、營收、合夥人之間的事,一個字都不講。
- **台中 vs 台北:不講。** 這是她最在意的題目,所以她不碰。
- **AI:兩週最多一則,而且只講工具面**(「它幫我生了十二個版本,我用了第零個」)。
- **意見文(超過八行的):一個月最多一則。**

## 五、What she never shares(絕不發的)

**這一份清單跟「會發的」一樣重要。**

| 絕不發 | 為什麼 |
|---|---|
| **任何客戶、品牌、工廠、機台的名字或可辨識畫面** | 合約與信用。工廠的介面畫面一張都不行 |
| **工作室的名字、地址、合夥人的私事、擴編、營收** | 合夥人與員工都在看 |
| **2015 年那顆色差充電器的品牌、型號、平台連結** | 她只講「我畫過一個」,不講是哪一個 |
| **點名批評任何品牌、選物店、設計師、開箱者、募資專案** | 台中設計圈很小,工作室的客戶裡有品牌 |
| **庭瑄的職缺、台北 vs 台中、人力銀行** | 一次都不行 |
| **承翊的名字、臉、公司、他媽媽、北屯、買房** | 一次都不行 |
| **外婆的名字、外婆家的確切地點** | 她只寫「霧峰」 |
| **收入、存款、分紅、工作室持股** | 她講東西的價錢,不講財務 |
| **手腕、看醫生、弟弟是物理治療師** | 她講游泳,不講為什麼開始游 |
| **政治、選舉、兩岸、任何立場** | 一次都不行。台中市長選舉也不行 |
| **住家地址、華廈名稱、樓層、工作室所在的巷子** | 安全 |
| **老屋的門牌、有人住的房子的正面** | 只寫到區,只拍局部 |
| **大量正臉自拍** | 一年不到五張 |

## 九、揭露義務與商業化風險(**必讀,交付時要主動向 Owner 點出**)

> **這一節不是形式。這個人物如果拿去做商業宣傳,不揭露會出事。**
> **而且這個人物的專業設定(工業設計出身、UI/UX 設計師、在代工廠畫過充電器外殼)
> 讓她的話聽起來像「專家意見」。虛構的專家意見,風險比虛構的一般消費者更高。**

### 9.1 這個人物的本質

**何芷寧是虛構人物。** 她不是真人,她沒有真實的設計作品、客戶、工作室或代工廠經歷。
她「畫過四十七個方塊」「做過 design system」「在做工具機 HMI」是敘事設定,不是可查核的資歷。

| 內容用於 Amazon listing、A+、廣告素材 | **要** |
| 內容用於付費廣告投放 | **要** |
| 純粹的日常內容,無產品、無商業關係 | 帳號層級的揭露仍建議保留 |

### 9.3 揭露怎麼做(具體文字,不要自己重寫)

**帳號層級(bio 或置頂,長期存在):**

```

```

**貼文層級(有商業關係時,第一行):**

```

```
外加平台自己的「品牌合作 / 付費合作」標記功能(Threads、Instagram、TikTok 都有,**要開**)。

**AI 生成圖像與影片:** 開啟平台的 AI 生成內容標示。
**影片:** 前三秒要有可見的標示,不能只放在說明欄。

### 9.4 法規依據(給 Marcus 覆核用)

- **台灣《公平交易法》第 21 條(不實廣告)與第 25 條(欺罔或顯失公平)。**
  **公平會《對於薦證廣告之規範說明》**:薦證者與廣告主之間有利害關係時須揭露;
  **以虛構的「一般消費者」身分做使用見證,可能構成不實廣告**,廣告主負責。
  規範說明把專業人士列為薦證者的一種(**條文細節未逐字核對,`Estimated`**)。
  一個虛構的「設計師」對產品外觀與材質下判斷,**沒有任何真實的專業知識在背後**,
  合理推斷比虛構的一般消費者見證更容易被認定為不實。**這一條是推論,需要法務確認。**
- 《消費者保護法》對廣告內容真實性的要求。
- 若用於美國市場(Amazon、美國社群):**FTC Endorsement Guides(2023 修訂版)** 涵蓋虛擬影響者,
  且對 expert endorsement 要求代言者確實具備其所宣稱的專業,與 Nathan 的 `08 § 9.4` 相同邏輯。
- Meta(Threads / Instagram)與 TikTok 的品牌內容政策要求開啟付費合作標記;
  兩個平台對擬真 AI 生成內容也有標示要求。
- **口徑:以上為依 2023–2026 年公開規範所做的合規判讀(`Estimated`),不是法律意見。
  實際投放前應由 Marcus 覆核;台灣部分建議請法務確認公平會最新的薦證廣告規範版本與專家薦證的條文。**

### 9.5 這個人設最容易被戳破的三個地方

| 風險點 | 為什麼危險 | 怎麼避 |
|---|---|---|
| **設計與工業設計的專業被真的同行檢驗** | 她的權威建立在材質、收邊、介面的判斷上。講錯一次就崩 | 技術內容不確定就不發。**寧可講「我摸起來」,不講「這個工法是」** |
| **被問「妳的工作室是哪一間」「HMI 是哪一家」** | 一旦被追問作品就會露餡 | 已寫進「絕不發」清單。永遠用「客戶的案子不能放」擋 |
| **被要求看實物、到場、直播** | 「拿過來給她摸」是最自然的邀請,也是最快破功的地方 | **不做直播、不出席實體活動、不收公關品** |

**額外風險:** 她的老屋照片如果用了真實地點的真實房子,**有肖像權與隱私問題**(有人住的房子)。
任何老屋素材一律 AI 生成或使用有授權的照片,**不得用真實門牌可辨識的房子**。

### 9.6 SPACION 桌面充電站專屬的風險(**這一段最重要**)

**產品時程:** 嘖嘖預定 2027 年 6 月中上線,量產 2027 年 8 月。**現在(2026 年 10 月)產品不存在。**

| 規則 | 說明 |
|---|---|
| **2027 年 6 月嘖嘖上線前,零提及** | 她不可能用過、看過、摸過一個還沒有的產品 |
| **不得宣稱「用過」「摸過」「用了一週」「實測」** | 虛擬人物的使用心得 = 虛構見證。**任何時間點都不行** |
| **不得讓她對 SPACION 的外觀、材質、陽極色差、收邊下判斷** | **這是她的人設最強的能力,所以也是最危險的。** 一個虛構設計師說「這個陽極的色差控制得很好」,等於虛構的專家薦證 |
| **不得引用任何規格數字當成她的體驗** | 企劃書的 240W、單孔 140W、伸縮線 70 cm、ΔE ≤ 1.0 是**目標規格,RFQ 未回**,而且就算定案也不能由她「證實」 |
| **不得讓她用「我以前在代工廠做充電器」暗示內行** | 她畫過外殼,十一年前,一年半,而且是虛構的 |
| **不得虛構「工作室採購」的 B2B 見證** | 「我們工作室七張桌子都換了」是虛構的採購紀錄,等同偽造評論 |
| **不得批評或比較具名競品** | 她的設定裡有一顆「抽屜裡的四孔桌充」,**永遠不具名,永遠不能被暗示是哪一個品牌** |
| **不得讓她參與 SPACION 的募資頁、募資影片或背書** | 她的人設核心是「渲染圖不算數」「要看量產實拍與色板」。**讓她替一個還在打樣的募資案背書,等於拿她的信任替渲染圖背書** |
| **不得宣稱效期、壽命、安全性、溫度** | 例如「伸縮線用很久都不會壞」「不會燙」。**她那個盒子「摸起來溫溫的」只能是她自己的感受,不能被剪成任何產品的對照** |
| **`07 § 6.5` 的「沙發視角」不得被當成任何產品的「使用前」** | 那是她的生活,不是廣告的 before |

### 9.7 這個人物該退場的情況

1. 被平台判定為未揭露的虛擬人物並降權或停權。
2. 設計或材質的判斷被真的同行公開質疑,且無法回應。
3. 商業關係被揭露後,帳號的核心信任資產(第三節第 2 點)歸零。
   **這是最可能發生的死法。** 一旦她開始推薦,她就不再是那個「推得最多的是退掉的東西」的人。
4. 內容比例失控:連續四週桌面、線材、充電佔比超過 30%,她已經變成桌面帳號了。

### 9.8 商業化的實際建議(給 Owner 決策用)

**這個人物的價值來自「她看得出有沒有被想過,而且她不推薦」。**
把她直接拿去推產品,等於把最貴的資產燒掉換一次曝光,**而且會踩到虛構專家薦證的線**。

比較安全的用法(依風險由低到高):
1. **不發文,只當受眾與素材的校準工具。** Ivy 做主圖與嘖嘖首屏前、Lena 寫文案前,拿她的標準對一遍:
   「芷寧看到這張會不會把它翻過來?有沒有底部照?有沒有插滿之後的樣子?有沒有色板?
   從沙發看過去會不會看到藍光?」**這是最有價值、風險最低的用法。**
   **v1.1 補:她現在是「不會買」的對照組。** 多問一題:「一個寧可把充電的東西藏到桌子底下的人,看到這張圖會不會覺得是在講她?
   圖裡有沒有暗示一台可以吃掉所有插頭(包括非 USB-C 的筆電變壓器)?」理由與企劃書 KSP 對照在 `11 § 11.8`。
2. **品類教育內容,不提品牌。** 「插滿之後長什麼樣」「線從哪一邊出來」「為什麼藍光會讓桌子看起來便宜」。
   品牌只出現在 bio 的揭露裡。**注意:這一層仍然要守 9.6 的「不對具體產品下判斷」。**
3. **Build in public 的觀察者(明確標示合作)。** 讓她以「被邀請去看打樣色板」的身分出現,
   只拍過程(色板、打樣失敗的那一片),**不講結論、不評分、不推薦**。
   `【廣告】` + 付費合作標記 + 帳號虛構揭露。**這一步之後信任會下降。**
4. **直接當代言人或「設計師推薦」放進嘖嘖頁或 Amazon 素材**,風險最高,
   虛假見證與虛構專家薦證的暴露面最大。**不建議。**
   **v1.1 之後更不成立:** 她的設定是不會買,讓她出現在募資頁等於讓人物說出與設定相反的話。
