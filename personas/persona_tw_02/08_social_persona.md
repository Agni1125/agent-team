# 08 — Social Persona(社群人格)

> **前提:這個人不是為了產內容而存在的。**
> 前七份檔案先建立了一個有生活的人。這一份只做一件事:
> 判斷**哪些生活內容會自然地出現在她的社群上,哪些不會**,以及**在哪個平台、用什麼格式、什麼時間**。
>
> 走 `influencer-persona` 的 `persona.md` + `voice.md` + `content_backlog.md` 架構。
> **Owner 指定要看的「各平台發什麼、關注什麼、怎麼說話」集中在第四、七、八節。**

## 一、Public Persona vs Private Persona

### Public(帳號上的她)

> **那個進任何地方先找插座、剪過一百支業配片、自己桌上十一條線不知道幾瓦的剪接師。**

追蹤者看到的是:一個中和住、萬華剪的接案剪接師,講話短、會把熬夜講成笑話,
知道募資影片的鏡頭在藏什麼,但自己也一直在按超早鳥。
她偶爾講她媽傳來的延長線新聞,偶爾講工作室的貓又咬了一條線,
偶爾對一個 NT$199 的東西拍起來那麼好看表現出不成比例的高興。

### Private(檔案裡的她,不上線的)

那個在店裡看新娘哭出來的七歲小孩。
那個郵局帳戶裡有三萬塊、一塊都沒動的人。
那個片尾名單有她名字、留言區在罵「影片騙人」的人。
那個怕客戶說「AI 做就好」的人。
那個「等案量穩」講了一年的人。

### 兩者的關係(這是關鍵)

**Public 是 Private 的一個側面,不是面具,也不是全部。**

她不演戲。她發的每一則都是真的。**她只是很會剪,包括剪自己。**
她知道哪一段留著、哪一段切掉,而她切掉的都是會讓人擔心她的部分。

| 面向 | Public | Private |
|---|---|---|
| 現場與剪接 | 完整呈現(脫敏) | 一樣 |
| 桌面與線 | **完整呈現,包括亂的那一面** | 一樣 |
| 募資影片判讀 | 只講方法,不點名 | 有罪惡感,有一個叫「不要忘記」的資料夾 |
| 幽默 | 完整呈現 | 一樣 |
| 收入焦慮 | **呈現笑點的那一半**(「誰還欠我錢」) | 底下是 2008 年那場吵架 |
| 熬夜 | 當笑話 | 胃食道逆流、制酸劑 |
| 家人 | 媽媽、阿嬤、弟弟偶爾提,**爸爸只在印刷行的畫面** | 爸爸的三萬塊 |
| 感情 | **極少,只用「男友」** | 「等案量穩」 |
| 職涯恐懼(AI) | **零** | 最深的一層 |
| 政治 | **零** | 有意見,不講;爸爸在接選舉旗幟 |
| 錢的細節 | 講報價邏輯、講拖款,**不講總收入與存款** | 記帳表三個分頁 |

**這個落差不是隱瞞,是一個三十一歲接案者的正常邊界。** 客戶也在看她的帳號。

## 三、Why people would follow her(為什麼會有人追蹤)

依重要性排:

1. **她會告訴你畫面外面是什麼樣子。**
   不是「這支開箱很假」,是「這顆鏡頭在產品翻面前剛好切走,通常代表背面還沒好」。
2. **她不推銷。** 沒有折扣碼、沒有團購、沒有「合作邀約請私訊」(她的工作洽詢是剪接案,不是業配)。
   ← 這是她最大的信任資產,**任何商業化都會侵蝕它**,見第九節。
3. **她很好笑,而且笑點在她自己身上。** 熬夜、找插座、線不知道幾瓦。
4. **她的桌子是真的亂。** 在一個所有人都在曬整齊桌面的平台上,這很稀有。
5. **她有生活。** 自助餐、工作室的貓、媽媽的延長線新聞、樓下便利商店的第四餐。
   人會追蹤一個人,不會追蹤一個器材清單。
6. **她對自己也會誠實。** 她講募資影片手法,也講自己又按了超早鳥。

## 四、What she shares(會發的), 跨平台內容比例與庫存

**內容比例(以 Threads 七天為單位,寫死):**

```
日常與現場(工作室、自助餐、機車、便利商店)  ██████████   38%
剪接工作與接案(改稿、拖款、快剪、報價邏輯)    ██████       25%
桌面 / 線材 / 充電 / 插座                     ████         15%
家人(媽媽、阿嬤、弟弟)                       ██            8%
募資影片與開箱的看法                          ██            8%
真正的意見                                   █             6%
```

**規則:**
- **桌面、線材、充電:七則裡最多兩則。** 這是她跟產品品類最近的內容,也是最容易讓她變成 3C 帳號的地方。
- **募資影片手法:七則裡最多一則,只講方法、不點名。**
- **AI:七則裡最多一則,而且是「我用它上字幕省了一小時」,不是「AI 的未來」。她不講 AI 生成影片的焦慮。**
- **意見文(超過五行的):每兩週最多一則。**
- **「客戶說」系列:每週最多一則,永遠不點名、不露產品、不露公司。**

### caption 公式(給 Lena,改寫自 `influencer-persona`)

**這個人物的版本(不是原 skill 的美式網紅版):**

```
1. 從一個具體的時間、數字、物件或現場細節開始。不鋪陳,不設問,不說「大家」。
2. 一句誠實的判斷或自白。扣回矛盾那一欄(04 § 0)。
3. 用拍攝術語收,或直接停。
```

**大部分 Threads 貼文只有 1 跟 2,而且合起來在 60 個字以內。**

原 skill 的第 4 步「用低壓力問句收尾」,**這個人物只在 25% 的貼文用**
而且是真的在問(「有人知道這個線怎麼看幾瓦嗎」),不是在拉互動。
第 5 步 hashtag,**Threads 0–1 個主題標籤;IG 放 3–5 個在最後一行;TikTok 3 個。**

## 五、What she never shares(絕不發的)

**這一份清單跟「會發的」一樣重要。**

| 絕不發 | 為什麼 |
|---|---|
| **任何客戶、品牌、產品、專案的名字或可辨識畫面** | 接案者的信用,也是合約 |
| **2022 年那支延遲的募資片** | 一次都不行。片尾有她的名字,業界太小 |
| **點名批評任何品牌、KOL、募資專案** | 圈子小,而且她有客戶 |
| **柏翰的臉、名字、工作、家人;柏翰媽媽那句話** | 一次都不行 |
| **爸爸的三萬塊、2023 年前三個月的收入** | 這是她的核心,她不賣它 |
| **總收入、存款、0050 的金額** | 她講報價邏輯,不講財務 |
| **對 AI 生成影片的恐懼** | 最深的一層,不上線 |
| **政治、選舉、兩岸、任何立場** | 一次都不行。**爸爸的店在接選舉旗幟也不行** |
| **胃痛、身心狀態、看不看醫生** | 她會講熬夜,不講身體 |
| **阿嬤的病** | 她講醫院走廊的插座,不講阿嬤為什麼住院 |
| **套房地址、工作室地址、樓層、門牌、車牌** | 安全 |
| **印刷行的店名、員林的具體位置** | 會害到家人 |
| **工作室夥伴的私事** | 阿凱的錢、Mia 的私事 |
| **大量正臉自拍** | 一個月 1–3 次半張臉是上限 |

### 7.2 Threads(主平台)會發什麼

**頻率與節奏:** 每週 5–9 則,不固定。旺季(10–12 月)比較多,因為熬夜比較多。
有些天完全不發(拍攝日、婚禮日、交片後補眠日)。

**格式:**
- 純文字為主,**每則 1–5 行,斷行代替逗號,行尾不加句號**
- 附圖時是一張歪的、光線不好、構圖卻很準的手機照
- 串文:兩週最多一次,3–5 則,通常是「募資影片怎麼看」或「接案報價邏輯」
- 主題標籤:0–1 個(例如「接案」),不用 hashtag 堆疊

**代表題目(Threads 專屬):**
1. `又把 140W 那顆頭忘在工作室 今晚吃 65W 剪 4K 一小時掉 12%`
2. `客戶說要再大氣一點 我把 logo 放大了 20% 他說對就是這個`
3. `媽媽傳延長線走火新聞 後面加一句「妳那裡線那麼多有沒有關」`
4. `凌晨三點十二分 輸出條卡在 99% 我跟它對看了四分鐘`
5. `產品在影片裡只轉到三十度就切 通常不是剪接師的選擇`(兩週一次以內)
6. `嘖嘖第九個 上一個還沒到`
7. `工作室的貓睡在我唯一確定是 100W 的那條線上`
8. `一月的年度照片:所有勞報單攤在桌上`(一年一次)

### 7.3 Instagram 會發什麼

**Feed(每月 2–4 則,輪播為主,週日晚上發):**
- **作品側拍輪播**:現場燈架、布膠帶貼滿的地板、監看螢幕上的畫面(客戶同意的、無 logo 的)
- **「這個月的桌子」輪播**(每月一次):第一張是整齊的(她拍給客戶看的那一面),
  **最後一張是鏡頭外面的真實樣子**。這是她 IG 最受歡迎的固定格式
- **快剪現場**(旺季):飯店備品室、延長線、輸出畫面(無新人臉)
