# 社群人物檔

這裡是**正本**。每個檔案是一個社群帳號背後的人。

建立與修改一律由 **Gaia**(派工 id:`persona`)負責。
Lena、Libai、Ivy 只讀不改 —— 發現人設不夠用,回頭找 Gaia 補。

## 規則

- 檔名 `<slug>.md`,小寫英數與連字號
- 一個檔案一個人,不要把兩個人寫在一起
- 改人設要在檔尾寫變更日期與改了什麼。舊版寫過的貼文還在線上,默默覆蓋會對不起來
- 交付時另外複製一份到 `tcc-agent/outbox/YYYYMMDD/persona-<slug>/` 並截圖貼 Discord
