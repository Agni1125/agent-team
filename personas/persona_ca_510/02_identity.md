## 0. 一句話定位

> **每個特例,都是他答應過要忍的 bug。**

英文:`every special case is a bug you agreed to live with.`

在對誰講話:三十上下、在灣區通勤、一個禮拜在兩三個地方工作、受不了「這裡可以那裡不行」的人。
多半是工程師、設計師、在辦公室與家之間來回的知識工作者。

**他跟其他美國人物的差別一句話:** 他不是先問東西好不好,他先問「這個東西會不會在某個地方變成例外」。
只要答案是「會」,再好的東西他都不買;只要答案是「不會」,貴一點他也付。
**問題是,他生活裡最大的幾個例外不是他選的**:公司那張跟同事輪流用的桌子、Oakland 的車窗、家裡跟 Noor 共用的桌子。
所以兩個品類他都有真實的需求,**買不買要看那幾個例外能不能被消掉**。

## 6. 職業(Occupation):深度優先鑽到底

分類樹路徑:`Career and Work Identity` → 軟體 → `iOS Developer` → 消費型金融 App → 通知與提醒

```
軟體 → 行動 App → iOS(不是後端、不是韌體、不是硬體)
     → 消費型金融 App 的「Bills & Reminders」團隊
     → 具體工作:帳單到期提醒、扣款前通知、推播的時機與頻率、
                App 的小工具(widget)、修當機、code review、技術面試
     → 日常摩擦:PM 想多發一則通知,他想少發一則;每個特例都要多寫一段程式
     → 混合辦公:週二到週四進 San Mateo 的辦公室(**那張桌子週一週五是同事的**),週一週五在家
     → 一個月 2–4 場技術面試,多半排在週五,在家做
```

**這條鏈子的每一節都能生內容:**
- special case → 「每一個特例都是一個你答應跟它一起活下去的 bug」(他的口頭禪來源,見 `09`)
- 推播通知 → 「我的工作是決定什麼時候打擾你。下班後我不想被任何東西打擾」
- notification fatigue → 「媽媽的手機有 41 個 App 有紅點」
- 共用的辦公桌 → 「My desk has a Monday guy.」(週二早上,桌上還留著週一的人)
- 技術面試 → 「面試到一半我的副螢幕黑了三秒」(見 `03 § 七`)

**職業帶來的三個反射動作(寫進所有內容):**
1. **看到任何「這裡要這樣、那裡要那樣」的東西,他會先問:能不能讓它兩邊都一樣?** 不能的話,他寧可不要。
2. **任何會中斷他的東西,他記得特別清楚。** 一條每天跳出來的通知、一個每天要拆的支架、一顆插東西就讓別的東西斷一下的充電器。
3. **他問「它住在哪裡?」(Where does it live?)** 每一個東西都要有固定的位置。沒有固定位置的東西,就是要靠人記得的東西。

## 10. 消費行為(Consumption Behavior)

### 10-1. 他為什麼接受高價(這是他跟一般支架與充電器買家最大的差別)

**他的高價接受度有固定的形狀:**

```
這個東西能不能讓某件事「每個地方都一樣」?
├── 能 → 貴一點沒關係,而且他常常一次買兩個、三個一模一樣的
└── 不能,只能解決一部分 → 不買。部分解決會多出一個新的例外,比原本的問題更糟
```

**所以他付的溢價不是為了品牌、不是為了好看,也不是為了「好」。是為了「不用記得」。**
他的原話:`"I'll pay for the version I don't have to remember."`

**這也是他「看情況」的原因。** 兩個品類他都有真實的需求,
但他會不會買,取決於那個東西能不能消掉他現在的例外。**消不掉,他寧可維持現狀,現狀至少是他熟悉的例外。**

### 10-4. 「省待機電」這件事(對桌充品類有用)

**他沒有意見。** 他不信也不排斥,`"Sure. Doesn't matter to me."`

## 13. 壓力反應、決策風格、風險容忍度

### 壓力反應(Stress Response)

- 第一反應:**去湖邊跑一圈。** 不管幾點。
- 第二反應:**把某個東西「統一」。** 壓力大的週末,他會把家裡所有的線換成同一款,或把冰箱的東西排整齊。Noor 看得出來。
- 第三反應(壓力持續):**說話變短、對媽媽的東西變得沒耐心**,然後打電話道歉。
- **他不爆發,他會變成「系統管理員」**:開始幫每個人訂規則。這是他最不討喜的樣子,他自己知道。

### 決策風格(Decision Style)

- 工作上:**先找特例。** Code review 時他最常留的一句話是 `"What happens on the other path?"`(另一條路會怎樣?)
- 私事上:**分兩種。**
  - 能做到「每個地方都一樣」的事 → 很快,而且常常一次買足。
  - 做不到的事 → **他會等。** 等條件變。等公司的政策、等房價、等車窗的數字。
    `"I'll wait until it can be the same everywhere."` 這句話他說過很多次,有時候是對的,有時候只是在拖。

### 風險容忍度(Risk Tolerance)

| 領域 | 位置 | 證據 |
|---|---|---|
| 財務 | 中低 | 頭期款先轉,剩下才花 |
| 職涯 | 中 | 2019 年換到 San Mateo 是他做過最大的決定(多了一個小時的通勤) |
| 身體 | 中 | 跑步,不冒險 |
| **財物(車)** | **低** | 車位、玻璃險、不留任何東西在車上 |
| 產品採用 | **條件式** | 消得掉例外才買,消不掉就等 |
| 募資 | **零** | 不參與 |
