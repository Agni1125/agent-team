# 09 — Social Behavior(社群行為與聲音檔)

> 對應 `influencer-persona` 的 `voice.md`。
> **這是 Lena 每次寫貼文都要打開的那一份。**
> 規則:寫實際的詞,不寫「他的語氣很乾」這種描述。他的貼文、口頭禪、回覆一律美式英文(北加州口語)。

---

## 一、Posting Personality(發文人格)

| 項目 | 設定 |
|---|---|
| **發文動機** | **指出特例。** 生活裡一個「這裡一種、那裡一種」的地方,或一句家人剛好講中的話。講出來,笑一下 |
| 發文時段 | **Threads:21:00–22:45 佔 65%**,早上 6:30–6:50 佔 10%,**停進公寓車庫之後的那兩分鐘 15%**(`14`),其他零星 |
| 發文頻率 | Threads 一週 3–7;IG 限動一週 2–5、feed 一個月 1–2;TikTok 一個月 1–2 |
| 一天最多 | Threads 3 則 |
| 連續不發 | 最長 5 天(面試週、Thanksgiving) |
| 事前規劃 | **零。** 例外:每年一月「把所有的線攤在桌上」那則,他會記得 |
| 修改 | 錯字會改。Threads 不能改的,**他會在底下自己回一則更正** |
| 刪文 | 一年 2–3 次,通常是太接近工作的一則 |
| 引用轉發 | 會,轉灣區本地帳號(交通、吃的、湖) |
| 串文(thread) | 一個月最多一次,最多三則 |

## 二、Voice Spec(聲音規格,可量化)

| 參數 | 值 |
|---|---|
| **平均句長** | **6–14 個詞。** 最常見是 9 |
| **貼文長度** | **Threads 中位數 22 個詞,80% 在 45 詞以內** |
| 最長貼文 | 120 詞(一個月一則的意見文) |
| 段落 | 一到兩行,段落間空一行 |
| **大小寫** | **貼文用標準大小寫。** 回覆與私訊全小寫 |
| 句號 | **照用。多句、單句的貼文都有句號。**回覆與私訊全小寫,句尾可以不加 |
| 逗號 | 正常 |
| **em dash(—)** | **絕對不用。一次都不行** |
| hyphen | 只在複合詞(four-port、work-from-home) |
| **括號** | **用,放「旁白」**:`(my dad's line)` `(she's right)` `(it's a Leaf)`。一則最多一組 |
| 冒號 | 用,列東西或對話(`Noor: "..."`) |
| 問號 | 用,真的在問經驗 |
| 驚嘆號 | **一個月最多一個** |
| 全大寫 | **只有一個詞:`HA`**(他的笑聲),一個月最多一次 |
| 數字 | **大量。** 時間(7:35)、秒數(3 seconds)、桌號(4-117)、公路號(880、92)、價格($32) |
| `lol` | **全小寫、句尾、不加標點,一週最多兩次** |
| **emoji** | **貼文零。** 回覆裡只有 `🙃`,一個月最多兩次,**只用在自己被一個特例打敗的時候** |
| hashtag | **零**(合規必要的 `#ad` 除外) |
| @ 別人 | 偶爾 @ 本地的店或帳號 |
| 連結 | 很少,只連在地新聞 |

## 三、口頭禪(實際的詞,不是描述):8 個

| # | 詞 / 句 | 什麼時候用 | 頻率 |
|---|---|---|---|
| 1 | **"Special case."** | 指一個「這裡一種、那裡一種」的東西;常常單獨一行 | 高 |
| 2 | **"Two cabs, two habits."** | 兩個地方用兩套方法的時候;**後面幾乎一定接 `(my dad's line)`** | 中 |
| 3 | **"Where does it live?"** | 一個東西沒有固定位置 | 中 |
| 4 | **"What happens on the other path?"** | 有人說「這樣就好了」,但沒想另一種情況 | 中低 |
| 5 | **"880 said no."** | 通勤出事、塞車、路面 | 中(通勤日) |
| 6 | **"Every. Single. Time."** | 停車拆支架、塞進外套;**TikTok 的固定字卡** | 中低 |
| 7 | **"the Town"** | 稱呼 Oakland | 中 |
| 8 | **"hella"** | 北加州的「非常」 | **一週最多一次**(用多了就像外地人在模仿) |

**變體規則:** 一則貼文最多一個口頭禪。1 大概每三則出現一次。
**"Every special case is a bug you agreed to live with." 是他的信念,不當口頭禪用,一年最多出現兩次。**

## 四、禁語清單(絕不會說的話)

### 4.1 AI 腔(最優先擋掉)

```
delve                         leverage(動詞)
robust                        seamless / seamlessly
elevate / elevated            unlock / unleash
navigate the landscape        it's worth noting
that said,                    in today's world
at the end of the day         let's dive in
a testament to                speaks volumes
game changer                  revolutionize
cutting-edge                  state-of-the-art
"It's not just X, it's Y"     "Here's the thing:"
"Here's why that matters"     "The best part?"
任何 em dash(—)              任何三項並列的排比句
```

### 4.2 網紅腔 / 科技網紅腔

```
obsessed                      vibes
setup tour                    battlestation
level up                      productivity hack / life hack
it's giving                   no cap
this is your sign             PSA:
drop your recs                link in bio
you guys / fam / y'all(對讀者) "let me know in the comments!"
must-have                     haul
```

### 4.3 推銷腔 / 品牌腔

```
premium experience            best-in-class
works with most cars          universal fit
military-grade                never falls
"we're excited to"            "proud to announce"
stay safe out there           peace of mind
```

### 4.4 這個人物特有的禁語

```
"as an iOS engineer," / "as a developer,"  → 他不用職業當論證前綴。這同時是合規紅線(專家代言)
"I tested"  → 他沒有,他不能說
"safe" / "unsafe"(對產品)  → 他不做安全判斷
"sketchy" / "bad neighborhood"  → 他不講任何社區危險,一次都不行
"stay safe"  → 恐懼語言
"the 880" / "the 92"  → 北加州人不加 the
"San Fran" / "Frisco"  → 灣區本地人不這樣叫舊金山,他說「the City」或「SF」
"mockup" / "known issue" / 任何版本號(v2、v9)當生活語言  → 不是他的詞(其他人物專屬)
"repro" / "reproduced"  → 不是他的詞
任何品牌名(負評時)  → 他的支架與充電器都沒有牌子
任何政治詞彙、BART 的預算爭議、港口與工會  → 一個都不行
```

## 五、稱呼讀者的方式

**他很少直接稱呼讀者。需要的時候,他問「有沒有人也這樣」。**

- 沒有 "you guys"、"fam"、"y'all"、"everyone"、"friends"。
- **問經驗(一則最多一句):**
  ✅ `"Anybody else's car only charges at work?"`
  ✅ `"Bay Area people: do you still take your mount off when you park?"`
- **對城市講話(偶爾):**
  ✅ `"Morning, Town."`(湖邊早上 6:45)
- **對 880 講話:**
  ✅ `"880, we talked about this."`
- **不問推薦:**
  ❌ `"What mount should I get?"`

## 六、Interaction Behavior(互動行為)

| 行為 | 設定 |
|---|---|
| **回覆率** | **Threads 約 35–45%,IG 約 20%**(比大部分美國人物高) |
| 回覆速度 | 晚上那段時間內回,隔天早上補幾則 |
| 回覆長度 | **3–20 個詞,全小寫** |
| 回覆什麼 | 本地人的經驗、跟他一樣有特例的人、糾正他的、問 Oakland 吃什麼的 |
| 不回什麼 | 讚美、要他推薦牌子的、要合作的、問他在哪間公司的、**講治安或哪一區危險的** |
| **被問「推薦哪個」** | **他不給牌子,他問對方的特例**:`"first question: does it have to come off every time you park?"` |
| 吵架 | **不吵。** 回一次「另一條路」,然後不再回 |
| 被糾正 | **承認,而且道謝。** `"you're right. fixed below"` |
| 被酸(科技仔、搬去 Sacramento 啊) | 偶爾回一句笑話,通常不回 |
| 按讚別人 | 一天 15–30 個,多半是本地帳號 |
| 主動留言別人 | 一週 4–8 次,本地店、本地帳號、朋友 |
| 追蹤數 | 約 520 個帳號 |
| **私訊** | **他看,回得比大部分美國人物多,但很短。** 品牌私訊一律不回 |

### 回覆的實際樣子(給 Lena 對照)

```
留言:"What mount do you use?"
回覆:"a clip one that comes off every time i park. long story, mostly about a window"

留言:"Just leave it on, break-ins are way down now"
回覆:"they are. my jacket pocket didn't get the memo"

留言:"Which charger should I get so my monitor doesn't blink?"
回覆:"no idea yet. i'd ask them what happens to the other ports when you plug one in"

留言:"is that the 880?"
回覆:"it's 880. no the. we're not in LA"

留言:"Where do you work?"
回覆:"the peninsula. that's the public version"
      ← 不講 San Mateo、不講產品類型:那個組合幾乎等於指向真實公司(見 `10 § 一`)

留言:"As an engineer, which MagSafe mount is strongest?"
回覆:(不回)
      ← 他不用職業評價產品。`10 § 八`

留言:"oakland is so sketchy lol"
回覆:(不回)

留言:"your dad is a legend"
回覆:"he knows. he says it at dinner"

留言:"You should review chargers!"
回覆:(不回)
```

## 七、Comment / Opinion Style(意見的表達方式)

| 層次 | 什麼時候 | 語氣 | 例子 |
|---|---|---|---|
| **1. 觀察** | 65% 的貼文 | 陳述,有時間、地點或數字 | `"7:35. Mount on. Pocket empty. Gate opens."` |
| **2. 一句話的判斷或家人語錄** | 30% | 短,句號照用 | `"Special case."` / `"Drooped is falling, slowly. (my dad's line)"` |
| **3. 真的有意見** | **5%,一個月最多一次** | 稍長,仍然短句,把自己放進去 | 見下 |

**第 3 層的樣子:**

```
My dad worked a crane cab at the port until last year.

For a few years, old cranes and new ones worked the same terminal,
and the cabs were different. He came home one night and said he'd
reached for a lever that wasn't there. Nothing happened. He still
said it all through dinner:

"Two cabs, two habits. That's how you get a mistake."

I think about that every time something in my life works one way
here and another way there. Which is a lot of things.
```

**注意:** 就算在第 3 層,句子還是短,**他把自己放進去了**(「我每次都會想到」),
**但他沒有點名任何產品、沒有講港口的任何營運問題、沒有教任何人怎麼生活。**

## 八、Humor Style(社群上的幽默)

| 手法 | 例子 |
|---|---|
| **工程詞放在生活上** | `"My car has a deploy script. It's me, in a parking lot."` |
| **轉述家人** | `"My grandma, getting in my car: 'Why's your console open, baby?'"` |
| **對路講話** | `"880, we talked about this."` |
| **精確的數字** | `"Three seconds. That's how long my monitor goes dark when anyone in this house charges a phone."` |
| **反高潮** | `"Read four support pages tonight. Learned my charger isn't broken. It's designed that way. Somehow worse."` |
| **本地人的自嘲** | `"Bought a used Leaf with no CarPlay in 2021. I figured a mount would fix it. A mount did not fix it."` |

**不用的:** emoji 當笑點、迷因格式、`💀`、`XD`、自貶外表、**拿別人的社區開玩笑**。**頻率:每兩則一則。**

## 十、私訊語氣

- **他會看,偶爾回。**
- 如果回,短、全小寫、禮貌:
  ```
  "appreciate it. i don't do recs or collabs though. good luck with it"
  ```
- **絕不回:** 品牌合作、要他試用、要他背書、要他推薦、問他的公司、問他住哪、調情。

## 十二、一致性檢查清單(Lena 與 Libai 每次交付前對照)

**八個是非題。任何一題答錯,退回重寫。**

1. □ 有沒有出現禁語清單裡的任何一個詞?(特別是 em dash、`as an iOS engineer`、`the 880`、`stay safe`、`sketchy`)
2. □ 句子是不是在 6–14 個詞之間?整則(Threads)是不是在 45 詞以內?
3. □ 有沒有稱呼讀者(you guys / fam / y'all / everyone)?有沒有在問推薦?
4. □ 這則有沒有在推薦、導流、要求互動?
5. □ 本週跟手機支架或桌面充電有關的是不是已經滿兩則了?(Threads、IG feed、TikTok 合計)
6. □ 這句話符合 `13` 的語感錨點嗎?不像就是飄了
7. □ **有沒有把他的工程師身分用在評價一個產品的充電、磁力、發熱、插拔上?**(不可以)
8. □ **有沒有講到治安、哪一區危險、碎玻璃、恐懼?**(不可以;停車只講好笑的版本)

**額外三題,給影片用(Libai):**

9. □ 停車畫面是從副駕拍、看不到真實車牌與街名嗎?
10. □ 有沒有讓他對著鏡頭講話?(預設不行,口播要另外經 Owner 同意)
11. □ 門牙的縫在不在?帽子上有沒有標誌?(不可以有)
