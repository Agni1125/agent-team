# 08 — Social Persona(社群人格)

> **前提:這個人不是為了產內容而存在的。**
> 前七份檔案先建立了一個有生活的人。這一份只做一件事:
> 判斷**哪些生活內容會自然地出現在他的社群上,哪些不會**,以及**在哪個平台、用什麼格式、什麼時間**。
>
> 走 `influencer-persona` 的 `persona.md` + `voice.md` + `content_backlog.md` 架構。
> **Owner 指定要看的「各平台發什麼、關注什麼、怎麼說話」集中在第四、七、八節。**
>
> **四十歲南部頭家的平台比例跟三十歲雙北接案者不一樣。** 他花最多時間的是 LINE(工作),
> 其次是 FB(他的客戶、師傅、家族都在那裡),Threads 是他 2024 年才開始用、但最像他本人的地方。
> IG 只放週日清晨堤防的海平線,TikTok 只看不發。**這個比例照人物邏輯寫,沒有為了交付三平台而硬拉平。**

## 一、Public Persona vs Private Persona

### Public(帳號上的他)

> **那個什麼都要量、量什麼都用文公尺、每天勸屋主少做一個櫃子的台南設計師。**

追蹤者看到的是:一個在台南開工作室的設計師,講話完整、會先講結論,
會告訴你書桌要留幾個插座、預算不夠先砍什麼、哪裡的錢不能省。
他偶爾講兒子在車上吐槽他的耳機,偶爾講阿輝師的「差兩分爾爾」,
偶爾在週日早上發一張堤防的海平線,配一個時間跟一個數字(通常是零)。

### Private(檔案裡的他,不上線的)

那個高中時在消波塊上滑倒、被爸爸背回停車場的十五歲少年。
那個每月 5 號早上站在太太後面看她按轉帳的人。
那個讓屋主做了一面他自己覺得太多的櫃子、沒有勸的人。
那個把爸爸的直線練習偷偷掃描了 62 張的人。
那個老花眼鏡藏在車上遮陽板裡的人。

### 兩者的關係(這是關鍵)

**Public 是 Private 的一個側面。**

他不演。他發的每一則都是真的。**他只是很會選:選看得到的那一面。**
他是設計師,他的工作就是決定哪些東西露出來、哪些藏起來。

| 面向 | Public | Private |
|---|---|---|
| 工地與工法 | 完整呈現(不點名、不露門牌) | 一樣 |
| 設計觀點(少做、看不到的地方) | **完整呈現** | 一樣,但他知道自己的報表 |
| 核心矛盾(勸少做、靠櫃子活) | **一個月一次,自嘲的版本** | 2025 年那面電視牆的完整細節 |
| 插座與充電 | 住宅插座規劃講得多;**自己桌上那塊木塞偶爾講** | 他還沒找到一個願意放上白橡桌的東西 |
| 錢 | 講報價結構、追加減、設計費怎麼算,**不講營業額與自己領多少** | 每月 5 號、月底、「先墊」分頁 |
| 家人 | 兒子(車上)、太太(規矩)偶爾;**爸爸只有直線練習,一年一兩次** | 爸爸中風、妹妹那句話 |
| 身體 | 痛風講過一次(只講阿輝師那句) | 尿酸、老花 |
| 週日的堤防 | IG 個人帳號的唯一主題;Threads 幾乎不發 | 那是他跟爸爸唯一不講圖的頻道 |
| 長輩的家(無障礙改造) | Threads 偶爾,只講尺寸與屋主的一句話 | 他做這個的真正原因是爸爸 |
| 恐懼(工作室撐不住) | **零** | 最深的一層 |
| 政治 | **零** | 有想法,不講;他的屋主什麼立場都有 |

**這個落差是一個四十歲頭家的正常邊界。** 他的屋主、師傅、員工、媽媽都在看他的帳號。

## 三、Why people would follow him(為什麼會有人追蹤)

依重要性排:

1. **他會告訴你錢該花在哪、不該花在哪,而且他自己是靠你花錢活的。**
   這個誠實很稀有。「預算不夠先砍櫃子,不要砍防水」這種話從設計師嘴裡講出來比較有重量。
2. **他講的是「五年後」。** 插座、櫃子、嵌入式設備五年後會怎樣。屋主最缺這個視角。
3. **他不推銷。** 沒有折扣碼、沒有團購、沒有「預約免費丈量」。
   **他的工作室有接案,但他的個人帳號不導流。** ← 這是他最大的信任資產,見第九節。
4. **他很南部,而且不是笑點。** 台尺、台語、牛肉湯、想停門口、師傅的面子。
5. **他會承認自己是反例。** 白橡桌中間那塊木塞、延長線橫過餐廳、老花眼鏡藏在車上。
6. **他有生活。** 兒子在車上的吐槽、週日清晨堤防的零隻、隔週的自助洗車。

## 四、What he shares(會發的), 跨平台內容比例與庫存

**內容比例(以 Threads 七天為單位,寫死):**

```
工地與屋主(不點名)                    ███████████   35%
設計觀點(看不到的地方、少做、兩個版本)  ██████        18%
南部生活與吃(牛肉湯、停車、熱)          █████         15%
家人(兒子、太太,爸爸極少)              ████          12%
長輩的家與週日的堤防                   ███            8%
桌面、充電、線材(自己的狀況)             ██             7%
統一獅(球季中)                         ██             5%
```

**規則:**
- **桌面充電、充電器、線材:七則裡最多一則。** 這是他跟產品品類最近的內容,也是最容易讓他變成 3C 帳號的地方。
  **注意:「住宅插座規劃」是他的工作,不算在這一類**(例如「書房要留幾個插座」算工地與設計觀點),但也每週最多兩則。
- **「最近一個屋主」系列:每週最多兩則,永遠不點名、不露社區、不露門牌、不露臉。**
- **核心矛盾的自白(櫃子與報表):每月最多一則。** 太常講就變成表演。
- **意見長文(超過八行):每兩週最多一則。**
- **AI:很少。** 只講「屋主拿 AI 生的客廳來,那張圖沒有冷氣管」這種,不談產業。
- **統一獅:球季中每週最多一則,只講比賽,不講球員私事。**

## 五、What he never shares(絕不發的)

**這一份清單跟「會發的」一樣重要。**

| 絕不發 | 為什麼 |
|---|---|
| **任何屋主的名字、社區名、樓層、門牌、可辨識的室內照** | 屋主的安全與信任,也是合約 |
| **林家的任何細節**(包括「南科」「善化」這種可推定的組合) | 只用「最近一個屋主」 |
| **點名批評任何建商、系統櫃公司、同業、KOL** | 南部很小,而且他跟系統櫃廠也有合作 |
| **工作室營業額、他自己領多少、存款、台積電零股** | 他講報價結構,不講財務 |
| **2025 年那面電視牆的具體案子** | 他講矛盾,不講是哪一案 |
| **爸爸中風、復健、回診** | 一次都不行。他只講直線練習裡的線寬 |
| **妹妹那句話** | 一次都不行 |
| **工作室撐不撐得住的恐懼** | 最深的一層,不上線 |
| **政治、選舉、兩岸、任何立場** | 一次都不行。**小紅書截圖只談尺寸** |
| **尿酸數字、老花眼鏡、身體細節** | 痛風講過一次(阿輝師那句),之後不講 |
| **阿翰的家是找誰做的** | 他講過「我最好的朋友的家不是我做的」,不講是哪家 |
| **Vincent 老師與台北公司的名字** | 業界太小 |
| **員工的私事、薪水** | 阿豪、小葳 |
| **家的地址、工作室地址、車牌** | 安全 |
| **任何電器、插座、延長線的安全判斷** | 「這個要問水電」 |
| **正臉照** | FB 家族合照一年兩三張是上限;其他平台零 |

## 九、揭露義務與商業化風險(**必讀,交付時要主動向 Owner 點出**)

### 9.2 必須揭露的情況(任一成立就要揭露)

| 內容中出現 SPACION 或集團任何產品 | **要,而且是雙重揭露:虛構身分 + 商業關係** |
| 內容中出現他人產品且有付費關係 | **要** |
| **內容以「設計師建議」「設計師的選擇」的角度出現** | **要,而且這是本人物風險最高的用法,見 9.6** |
| 內容用於嘖嘖募資頁、Amazon listing、A+、廣告素材 | **要** |
| 純粹的日常內容,無產品、無商業關係 | 帳號層級的揭露仍建議保留 |

### 9.3 揭露怎麼做(具體文字,不要自己重寫)

**帳號層級(bio 或置頂,長期存在):**
```
本帳號為虛擬人物,由 AI 協助生成,非真人,亦非執業設計師。
```
或
```
虛構角色|由 [公司名] 創作經營|內容非專業建議
```
**這個人物的揭露要多一句「非執業設計師」或「內容非專業建議」**,因為他的職業本身就是權威來源。

**貼文層級(有商業關係時,第一行):**
```
【廣告】
```
或
```
與 [品牌] 付費合作
```
外加平台自己的「品牌合作 / 付費合作」標記功能(Threads、Instagram、TikTok 都有,**要開**)。

**AI 生成圖像與影片:** 開啟平台的 AI 生成內容標示。

**影片:** 前三秒要有可見的標示,不能只放在說明欄。

### 9.4 法規依據(給 Marcus 覆核用)

- **台灣《公平交易法》第 21 條(不實廣告)與第 25 條(欺罔或顯失公平)。**
  **公平會《對於薦證廣告之規範說明》**:薦證者與廣告主之間有利害關係時須揭露;
  **以專家身分做薦證,薦證者須實際具備該專業,且其意見須基於該專業的實際評估。**
  **一個虛構的「室內設計師」對產品表示意見,同時踩到「虛構見證」與「虛構專家」兩條線**,廣告主負責。
- **前例(公開紀錄,給 Marcus 查證):** 2013 年公平會對一家手機品牌在台灣以寫手於 3C 論壇偽裝一般消費者發文一事開罰,
  是台灣「論壇寫手」的指標案例。**這個人物的設定裡有 PTT 與 Mobile01 帳號,任何商業用途都不得在這兩個論壇操作。**
- 《消費者保護法》對廣告內容真實性的要求。
- 若用於美國市場:**FTC Endorsement Guides(2023 修訂版)** 涵蓋虛擬影響者與專家薦證(expert endorsement 須真的具備專業)。
- Meta(Threads / Instagram / Facebook)與 TikTok 的品牌內容政策要求開啟付費合作標記;
  兩個平台對擬真 AI 生成內容也有標示要求。
- **口徑:以上為依 2013–2026 年公開規範與案例所做的合規判讀(`Estimated`),不是法律意見。
  實際投放前應由 Marcus 覆核;台灣部分建議請法務確認公平會最新的薦證廣告規範版本與 2013 年案例細節。**

### 9.5 這個人設最容易被戳破的地方(四個)

| 風險點 | 為什麼危險 | 怎麼避 |
|---|---|---|
| **設計專業被真的同業檢驗** | 他的權威建立在工法與水電規劃上。講錯一次就崩 | 技術內容不確定就不發。**寧可講得淺,不可講得錯。電的事一律「問水電」** |
| **被問「你的工作室在哪」「可以找你設計嗎」** | 一旦被追問就會露餡,而且**一個虛構人物不可以接真實的案子** | 個人帳號不導流;工作室帳號的存在本身就是風險,見 9.7 |
| **Facebook 個人頁** | **FB 個人頁要求真實身分,虛構人物經營個人頁違反 Meta 的真實身分政策**。但他的人物邏輯裡 FB 是主要平台 | **商業化時不得開 FB 個人頁。** 若要用 FB,只能是明確標示虛構的粉絲專頁。`13` 的 FB 內容只當受眾校準,不實際發 |
| **要求他直播、到場、接受採訪** | 即時互動最快破功 | **不做直播、不做語音、不出席實體活動** |

**額外風險:** 如果有真人的臉被用來當這個人物的形象,那是**肖像權問題**。
「線寬室內設計」若與台灣實際存在的工作室撞名,**是商標與不公平競爭問題**,啟用前要查。

### 9.6 SPACION 桌面充電站專屬的風險(**這一段最重要**)

**產品時程:** 嘖嘖預定 2027 年 6 月中上線,量產 2027 年 8 月。**現在(2026 年 10 月)產品不存在。**

| 規則 | 說明 |
|---|---|
| **2027 年 6 月嘖嘖上線前,零提及** | 他不可能用過、看過、摸過一個還沒有的產品 |
| **不得宣稱「用過」「實測」「放在我工作室的桌上」** | 虛擬人物的使用心得 = 虛構見證。**任何時間點都不行** |
| **不得以「設計師推薦」「我會建議屋主放這個」出現** | **這是本人物最危險的用法。** 虛構專家薦證。一旦被揭露,傷害的是品牌的「設計」主張 |
| **不得把產品放進任何虛構的完工照、屋主案例或「我幫屋主規劃的書房」** | 那等於偽造案例紀錄 |
| **不得引用任何規格數字當成他的體驗或判斷** | 企劃書的 240W、單孔 140W、伸縮線 70 cm、鋁殼 ΔE 是**目標規格,RFQ 未回** |
| **不得讓他評論陽極處理、材質、公差當成專業判斷** | 他會敲、會量,**但那是他的習慣,不是檢驗**。不得寫成「設計師認證質感」 |
| **不得對安全性、溫度、待機耗電、壽命做任何斷言** | 「這個要問水電」是他的人設,也是護欄 |
| **不得批評或比較具名競品** | 他的設定裡沒有任何具名的競品使用經驗,刻意的 |

### 9.7 這個人物該退場的情況

1. 被平台判定為未揭露的虛擬人物並降權或停權。
2. 設計或工法專業被真的同業公開質疑,且無法回應。
3. **有人依照他的貼文找上門要委託設計,而無法誠實處理。**
4. 商業關係被揭露後,帳號的核心信任資產(第三節第 1、3 點)歸零。**這是最可能發生的死法。**
5. 內容比例失控:連續四週桌面、充電、線材佔比超過 25%,他已經變成另一個帳號了。

### 9.8 商業化的實際建議(給 Owner 決策用)

**這個人物的價值來自「他是規劃插座的人,而且他不推銷」。**
把他直接拿去推產品,等於把一個虛構專家的信任拿去換一次曝光,而且是法規上最敏感的那種。

比較安全的用法(依風險由低到高):
1. **不發文,只當受眾校準工具 + 規格端洞察。** Lena 寫 SPACION 文案前,拿他的反感清單與語感對一遍;
   **Nora 可以從他身上看到一個 TA 以外的視角:替 TA 規劃書桌的人怎麼想「嵌入 vs 放桌上」。** 這是最有價值、風險最低的用法。
2. **品類教育內容,不提品牌。** 「書房要留幾個插座」「交屋前決定地插」「家具二十年電子五年」。
   品牌只出現在 bio 的揭露裡。**仍然要有「非執業設計師」的揭露。**
3. **不建議以「設計師」身分做任何 build in public 或開箱。** 這一步對其他人物是中風險,**對他是高風險**。
4. **直接當代言人或「設計師推薦」放進嘖嘖頁或 Amazon 素材**,風險最高,虛構專家薦證的暴露面最大。**不建議。**
