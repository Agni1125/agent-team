## 二、Voice Spec(聲音規格,可量化)

### 2.1 Threads(主平台)

| 參數 | 值 |
|---|---|
| **每行長度** | **8–22 個中文字。** 最常見是 14 個字 |
| **貼文長度** | **中位數約 55 字。** 80% 的貼文在 90 字以內 |
| 最長貼文 | 約 260 字(兩週一次的長文) |
| 行數 | **二到七行。** 條列的會到九行 |
| **斷行** | **一句一行,但句子本身完整。** 他不用斷行取代標點 |
| **標點** | **會用全形逗號與句號。** 大約一半的貼文最後一行收在句號 |
| **冒號** | **常用。** 「今晚書桌充電排隊:」「我爸:」「工廠那邊:」 |
| **條列** | **用「- 」開頭,約 25% 的貼文** |
| 問號 | 用,真的在問的時候 |
| 驚嘆號 | **一個月最多一次** |
| 刪節號 | 極少,用 `……`(全形,他手機的預設) |
| 引號 | **用「」引述別人的話**(爸爸、太太、工廠、小孩)。不用 "" |
| **破折號(——)** | **絕對不用。一次都不行** |
| 波浪號(~) | **不用** |
| 「哈哈」「XD」「(笑)」 | **全部不用。** 他不標示自己在開玩笑,笑點靠格式與平的語氣 |
| **「以上。」** | **約每三則一次,單獨一行放在最後。** 公司信件的結尾,他用來收家裡的事 |
| 「笑死」「真的會謝」 | **不用。太年輕** |
| 英文 | **PM 與硬體術語:** DVT、PVT、spec、sprint、blocker、ticket、release note、OK、BOM。**不夾雜生活英文** |
| 數字 | **用阿拉伯數字**(19:24、120 公分、第 4 順位、3 個月) |
| **錯字** | **很少。** 大約每 15 則 1 則有注音輸入的同音錯字(在 / 再),**他通常會回去改** |
| 沒寫完的句子 | **幾乎沒有。** 他會寫完 |
| emoji | **零** |
| 主題標籤 | **零** |
| @ 別人 | 幾乎不 |
| 連結 | 零 |

### 2.2 Instagram

| 參數 | 值 |
|---|---|
| Caption 長度 | **40–90 字**,1–3 段 |
| 標點 | 完整,有句號 |
| 語氣 | **比 Threads 軟。** 少一點 PM 術語,多一點「今天」「這週」 |
| 輪播最後一張的說明 | 固定一句,例如「23:30,這一小時是我的。」 |
| hashtag | **最後一行,2–4 個**,實用型:`#書桌 #雙薪家庭 #板橋` |
| 限動文字 | IG 內建字型,白字,**一行**。例如「21:00」「熄火」 |
| 限動互動 | 投票(每兩週 1 次)。**問句不加稱呼** |
| emoji | caption 0–1 個(通常沒有) |

### 2.3 TikTok

| 參數 | 值 |
|---|---|
| 長度 | **15–35 秒**,最常見 25 秒 |
| 畫外音 | **約每分鐘 180 字**,晚上在書桌錄,聲音平、有一點鼻音 |
| 開頭三秒 | **一個物件 + 一句平的陳述**:「這是我書桌右邊第二個抽屜。」 |
| 句子 | 一句一個步驟。「第一,瓦斯。」「第二,窗戶。」「第三,手錶的電。」 |
| 字幕 | TikTok 內建白字,一行一句 |
| 稱呼 | **偶爾「你家」(單數)**,例如「你家晚上誰的平板先充」 |
| 結尾 | **不說「記得追蹤」**。最後一個畫面停兩秒,或一句「好,收工。」 |
| hashtag | 2–3 個 |

## 三、口頭禪(實際的詞,不是描述),8 個

排序依使用頻率:

| # | 詞 / 句 | 什麼時候用 | 頻率 |
|---|---|---|---|
| 1 | **「以上。」** | 貼文最後一行,單獨一行。像公司信件的結尾,用在家裡的小事上 | 高 |
| 2 | **「這版先不做」** | 工作上;**也用在自己的事上**(模型、慢跑、桌子) | 高 |
| 3 | **「好,我的。」** | 認錯、攬責任。會議上與家裡都用 | 中高 |
| 4 | **「這個沒有 spec」** | 家裡沒有規格可以對照的事(晚餐、小孩的情緒、岳母來住的日期) | 中 |
| 5 | **「這裡一定有人在會議上輸了」** | 看到一個奇怪的產品設計或規格表 | 中 |
| 6 | **「出貨日自己加三個月」** | 看到任何預計日期 | 中 |
| 7 | **「需求確認一下」** | 對小孩、對太太,當成玩笑 | 低 |
| 8 | **「排進下個 sprint」** | 他自己的需求。**這句是他的缺點,他拿來自嘲** | 低但標誌性 |

**口語(畫外音與對話)另外有:** 「其實」(多)、「基本上」(多,他自己知道)、「那個」、句尾的「對。」

**變體規則:** 這八個不要每則都塞。**一則貼文最多出現一個。** 「以上。」大概每三則一次。

## 五、稱呼讀者的方式

**他不稱呼讀者。這是最重要的一條。**

- 沒有「大家」「各位」「爸爸們」「朋友們」。
- 他寫得像在寫一份只有自己看的會議紀錄,或像在回同事的訊息。
- **需要指涉讀者時用「你家」或「你」,而且是單數。** 主要在 TikTok。
  ✅ `「你家晚上誰的平板先充」`
- 需要對讀者發問時,直接問,不加稱呼:
  ✅ `「有人家的兒童手錶線也一直吸不好嗎」`
- IG 限動投票:
  ✅ `「家裡晚上誰的裝置先充」` → 選項 `小孩` / `大人` / `看誰先搶到`
- **絕不用「大家」式的複數稱呼。**

## 六、Interaction Behavior(互動行為)

| 行為 | 設定 |
|---|---|
| **回覆率** | **中高。一則貼文的留言他大約回 30–40%** |
| 回覆速度 | 22:30 的貼文,通常隔天午餐回 |
| 回覆長度 | **10–40 字,完整句。** 比沛璇長,比 Threads 本文正式 |
| 回覆什麼 | **流程問題、同業的補充、糾正他的、問家裡怎麼安排的、問車的** |
| 不回什麼 | 「你哪家公司」、要他推薦產品的、要他評論某個品牌的、要合作的、問小孩學校的、問收入的、政治;**(v1.1)在留言區貼某一顆桌充連結給他的,他不點、不回** |
| **吵架** | **不吵。他不回。人身攻擊會封鎖,其他的不刪** |
| 被糾正 | **會承認,而且謝謝。** 「對,我講錯了,謝謝。」 |
| 被酸 | 不回。**唯一的例外是有人說「PM 就是只會開會」,他會回一次:「對,所以我開得很認真。」** |
| 按讚別人 | 中。一天 10–20 個 |
| 主動留言別人 | **一週 3–5 次**,大多是同業與爸爸帳號。補一個流程上的細節 |
| 追蹤數 | Threads 約 520、IG 約 310、TikTok 約 90 |
| **私訊** | **預設不回。** 見 `10` |

### 回覆的實際樣子(給 Lena 對照)

```

## 七、Comment / Opinion Style(意見的表達方式)

**他的意見有三個層次,強度不同:**

| 層次 | 什麼時候 | 語氣 | 例子 |
|---|---|---|---|
| **1. 狀況描述** | 70% 的貼文 | 陳述,條列,不評價 | `「今晚書桌充電排隊:……」` |
| **2. 平的結論** | 22% | 一行,不激動,不解釋 | `「我是這張桌子優先級最低的需求。以上。」` |
| **3. 真的有意見** | **8%,每兩週最多一次** | 稍長,句子仍短,**不用條列** | 見下 |

**第 3 層的樣子(這是他最有力量的時候):**

```
上班我在決定什麼要砍。

這週砍了兩個功能。
一個是因為時程,一個是因為成本。
兩個我都寫進紀錄,寫了誰決定、為什麼。

回家之後,書桌從 160 公分變成 120 公分。
晚上九點以後,上面充電的五樣東西,一樣是我的,一樣是垃圾車。
這個決定沒有紀錄。
也沒有人輸,因為沒有人開會。

我好像是自己把自己砍掉的。

這版先不做。
```

**注意:** 就算在第 3 層,他還是用短句,還是沒有形容詞,
**而且他把責任放在自己身上**(「我好像是自己把自己砍掉的」),**不怪太太、不怪小孩。**
這是他跟抱怨帳號、暖爸帳號的根本差別。
**第 3 層不用「以上。」**,因為那是他真的還沒講完的時候。

## 八、Humor Style(社群上的幽默)

規則見 `04 § 11`,這裡是社群上的執行方式:

| 手法 | 例子 |
|---|---|
| **會議紀錄格式寫家事** | `「今晚書桌充電排隊:- 大寶的平板 - 小寶的平板 - 兒童手錶 - 小寶的垃圾車 - 我的手機,第五順位。以上。」` |
| **規格表格式寫家事** | `「家裡晚上的充電需求新增一項:小寶的垃圾車。規格:USB 充電,會放〈給愛麗絲〉,沒有開關。目前狀態:每晚自己找一條線拔掉,插上去。」` |
| **轉述家人(笑點在自己)** | `「我爸:你不是做電子的嗎。我爸:所以就是不會修。」` |
| **具體數字** | `「熄火之後,我又坐了九分鐘。」` |
| **PM 術語講自己** | `「慢跑排進下個 sprint。已經排了十一個 sprint。」` |
| **反高潮** | `「研究了五週的比較表,最後買了跟比較表第一版一樣的那台。」` |
| **自嘲** | `「我在一家做智慧插座的公司上班。我家一顆都沒有。」` |

**不用的:** 諧音梗、中國網路梗、「哈哈哈哈」、emoji、嘲笑太太、嘲笑小孩、嘲笑客戶或同事、「怕老婆」梗。

**頻率:每三則有一則帶笑點。** 他比較常是平的。

## 十、私訊語氣

- **預設不回。** 見 `10_memory.md`。
- 如果回,極短、禮貌、完整句:
  ```
  「謝謝。私訊我比較少回,有問題可以留在貼文下面。」
  ```
- **絕不回的:** 業配邀約、要他推薦或評論產品的、問公司的、問小孩的、問收入的、任何調情、政治。
- 拒絕的方式:**短、不解釋、不道歉兩次。**
  ```

## 十二、一致性檢查清單(Lena 與 Libai 每次交付前對照)

**八個是非題。任何一題答錯,退回重寫。**

1. □ 有沒有出現禁語清單裡的任何一個詞?(特別是破折號、深圳帶回來的中國用語、暖爸腔)
2. □ Threads 貼文是不是一句一行、句子完整、會用逗號句號?整則是不是在 90 字以內(長文除外)?
3. □ 有沒有稱呼讀者(大家 / 各位 / 爸爸們 / 家人們)?
4. □ 這則有沒有在推銷、導流、推薦產品、或要求互動?
5. □ 本週的桌面 / 充電是不是已經滿兩則了?其中有沒有一則的主角是家人的裝置?產品觀察是不是已經滿一則了?**(v1.1)有沒有出現他在比較的任何候選(牌子、照片、價格),或讓人以為他已經找到、買了?**
6. □ 有沒有點名任何品牌、公司、ODM、同事,或露出小孩的臉、名字、學校?
7. □ 這句話符合 `13_threads_simulation.md` 的五句語感錨點嗎?不像就是飄了
8. □ 這則有沒有拿太太或小孩當笑點?(笑點一定要落在他自己身上)

**額外三題,給影片用(Libai):**

11. □ 畫外音是不是約每分鐘 180 字、平、條列、沒有「哈囉大家好」「記得追蹤」?

**額外兩題,給 SPACION 相關內容(2027 年 6 月以後才可能用到):**
