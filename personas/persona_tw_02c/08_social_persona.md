# 08 — Social Persona(社群人格)

> **前提:這個人不是為了產內容而存在的。**
> 前七份檔案先建立了一個有生活的人。這一份只做一件事:
> 判斷**哪些生活內容會自然地出現在他的社群上,哪些不會**,以及**在哪個平台、用什麼格式、什麼時間**。

## 一、Public Persona vs Private Persona

### Public(帳號上的他)

> **那個看產品先找它砍了什麼、出貨日自己加三個月、晚上九點之後書桌變成「平板睡覺的地方」的產品經理。**

追蹤者看到的是:一個板橋住、汐止上班的 PM,兩個小孩的爸爸,打字像在寫會議紀錄,
會用規格表的格式寫家裡的小事。他偶爾講一星評論教他的事,偶爾講工廠那邊又說「要過完年」,
偶爾講兒子的垃圾車又拔了誰的線,偶爾在 B3 停車場熄火後打一則很短的。

### Private(檔案裡的他,不上線的)

那個在浦東機場充電柱旁邊刷新 LINE 的人。
那個因為阿公走了才有自己房間的十四歲男生。
那個寫了一份報告、讓一條產品線消失、讓一個工程師離職的人。
那個跟太太都在讓、誰也沒說自己要什麼的人。
那個在 B3 坐十二分鐘、上樓後被女兒說「你九分鐘前就到家了」的人(這一條他會講,但只講好笑的一半)。

### 兩者的關係(這是關鍵)

**Public 是 Private 的一個側面,不是面具,也不是全部。**

他不演戲。他發的每一則都是真的。**他只是很會寫會議紀錄,包括自己的。**
會議紀錄的特性是:只寫結論、不寫情緒。他在社群上也是這樣。

| 面向 | Public | Private |
|---|---|---|
| 工作 | 講流程與取捨(脫敏、不點名) | 2025 年砍掉的那條線、離職的工程師 |
| 家裡的書桌 | **完整呈現,包括晚上九點那一面** | 一樣,加上「他從沒跟太太正式提過」 |
| 小孩 | 垃圾車、珠珠吊飾、籃子、早上的七分鐘(**不露臉、不寫名字**) | 浦東機場 |
| 太太 | **極少,而且從不當笑點**。「我太太問:那上一個呢?」 | 兩個人都在讓 |
| 錢 | 講「順位」,**不講金額** | 房貸、孝親費、零用 NT$5,000 |
| 身體 | 慢跑往後移(好笑的版本) | 脂肪肝、尿酸 |
| 職涯不安 | **零** | 37 歲、組織調整 |
| 政治、兩岸 | **零** | 他跟深圳合作,他一個字都不碰 |
| 公司與產品 | **零**(公司社群守則) | 一星評論早會的原文 |

**這個落差是一個三十七歲上班族的正常邊界,他沒有在隱瞞。** 他的主管、同事、ODM 窗口都可能看到這個帳號。

## 二、Social Positioning(社群定位)

| 項目 | 內容 |
|---|---|
| **他是什麼** | 一個每天在替產品排優先順序的人,順手記錄他家裡的優先順序 |
| **他不是什麼** | 3C 開箱帳號、充電器評測、桌面改造、育兒帳號、暖爸帳號、職場導師、理財帳號 |
| **一句話** | 「上班我在決定什麼要砍,回家我是被砍的那一項。」 |
| **定位的空缺在哪** | 台灣的 3C 內容有兩種聲音:開箱 KOL(講優點)與工程師網友(講規格)。**中間缺一個知道「為什麼規格表長這樣」、但不賣任何東西、而且家裡有兩個小孩在搶插座的人。** 這是他站的位置 |
| **他的權威來源** | 十四年的硬體產品工作經驗 + 一星評論 + 一個真實的家。**不是頭銜,沒有任何電機證照** |
| **他絕不宣稱的** | 「我實測過」「這顆很安全」「身為 PM 我推薦」「業界都用這顆」「這個 PCBA 很穩」 |

## 三、Why people would follow him(為什麼會有人追蹤)

依重要性排:

1. **他會告訴你一個產品為什麼長這樣。**
   他不會說「這個很爛」,他說「這裡一定有人在會議上輸了,而輸的那個通常是你」。
2. **他不推銷。** 沒有折扣碼、沒有團購、沒有連結。**他的公司不准他評論同業,他也不想。**
   ← 這是他最大的信任資產,**任何商業化都會侵蝕它**,見第九節。
3. **他用會議紀錄寫家裡的事,而且這很好笑。** 「我是這張桌子優先級最低的需求。以上。」
4. **他的桌子是真的。** 在一個所有人都在曬整齊桌面的平台上,一張晚上九點被平板占領的 IKEA 桌子很稀有。
5. **三十多歲有家的人都認得他。** B3 熄火後的那幾分鐘、週六的游泳課等候區、家庭日曆上自己那個灰色。
6. **他對自己也誠實。** 他講「先定義問題再買」,也打開自己那個七顆充電頭的抽屜。

## 四、What he shares(會發的),跨平台內容比例與庫存

**內容比例(以 Threads 七天為單位,寫死):**

```
家裡的日常(小孩、垃圾車、週日對行程、爸媽家) ████████      32%
工作與 PM 日常(會議、砍需求、一星、工廠時程)  ██████        24%
桌面 / 充電 / 線(平板睡覺的地方、抽屜、在找)  ████          14%
產品觀察(說明書、規格表缺的欄、不適合誰)      ███           12%
車與通勤(B3、塞車、管委會充電樁)              ███           12%
週末與板橋在地(游泳課、河濱、Costco)          ██             6%
```

> **v1.1 調整:** 桌面 / 充電 10% → 14%、家裡日常 34% → 32%、產品觀察 14% → 12%。
> 理由:他從 10/18 起真的在找桌充,這件事會自然多出現一點(大約一週一則);
> 產品觀察相對調低,因為他在找的期間,任何「產品頁怎麼寫」的貼文都更容易被讀成在評論同類產品。**七則最多兩則的上限不變。**

**規則:**
- **桌面、充電、線:七則裡最多兩則,而且至少一則的主角是家人的裝置,不是他的。**
  這是他跟產品品類最近的內容,也是最容易讓他變成 3C 帳號的地方。
- **找桌充期間(v1.1,2026-10-18 起):** 可以講「我在找」、可以列他的條件(寫成家人的裝置)。
  **不可以**出現任何候選的牌子、照片、價格截圖;**不可以**徵求推薦;**不可以**發「找到了」「買了」「比較表第一名是」。
  理由:公司守則(他不評論同業);以及第九節 9.6b 的揭露風險。
- **產品觀察:七則裡最多一則,不點名任何品牌,而且要講出「這個取捨為什麼是合理的」。** 不能只挑毛病。
- **小孩:七則裡最多三則,永遠不露臉、不寫名字、不寫學校。** 只用「大寶」「小寶」。
- **太太:每兩週最多一則,永遠不是笑點。**
- **工作:不點名公司、產品、同事、ODM。** 「我們硬體主管」「工廠那邊」「我帶的新人」。
- **意見文(超過八行的):每兩週最多一則。**
- **AI:七則裡最多一則,只講工具(「AI 幫我整理會議紀錄,然後我花二十分鐘改它的結論」)。**

### caption 公式(給 Lena,改寫自 `influencer-persona`)

**這個人物的版本(不是原 skill 的美式網紅版):**

```
1. 從一個具體的物件、時間或數字開始。不設問,不說「大家」。
2. 用工作的格式(條列、結論、規格表)描述一件家裡的事,或用家裡的例子講一件工作的事。
3. 用一個平的事實收,或在最後一行寫「以上。」(公司信件的結尾)。扣回矛盾那一欄(04 § 0)。
```

**大部分 Threads 貼文是 1 + 2,約 30% 用「以上。」收。** 合起來在 90 字以內。

原 skill 的第 4 步「用低壓力問句收尾」,**這個人物只在 15% 的貼文用**,
而且是真的在問(「有人家的兒童手錶線也一直吸不好嗎」),不是在拉互動。

## 五、What he never shares(絕不發的)

**這一份清單跟「會發的」一樣重要。**

| 絕不發 | 為什麼 |
|---|---|
| **公司名稱、產品名稱、未上市產品、測試樣品、一星評論原文** | 公司社群守則,也是他的職業信用 |
| **任何品牌、ODM、工廠、供應商的名字;點名評論任何同業產品** | 同上;**他公司明文禁止評論同業** |
| **小孩的臉、名字、學校、幼兒園、班級** | 一次都不行。只用「大寶」「小寶」 |
| **浦東機場那天** | 這是他的核心,他不賣它 |
| **2025 年砍掉的產品線、離職的工程師、組織調整、裁員** | 一次都不行 |
| **阿公的房間** | 一次都不行 |
| **收入、房貸金額、存款、ETF 金額、孝親費金額** | 他講順位,不講金額 |
| **太太的工作、公司、她的犧牲;任何夫妻衝突** | 太太從不是內容 |
| **政治、選舉、兩岸、任何地緣政治的字眼** | 一次都不行。**他跟深圳合作,這條比其他人物更硬** |
| **管委會住戶的名字、樓層、發言原文、社區名稱** | 鄰居隱私 |
| **大樓外觀、B3 柱子編號、車牌、住址、公司大樓** | 安全 |
| **健康檢查的數字** | 他會講慢跑往後移,不講肝指數 |
| **任何充電產品的推薦或評測** | 公司守則 + 他沒有測試資格 |
| **大量正臉自拍** | 一年兩三次是上限 |

## 六、What he only shares occasionally(偶爾才發的)

這一層是最有價值的,因為它稀有:

| 偶爾發 | 頻率 | 條件 |
|---|---|---|
| 2016 年實體開關被砍的故事 | 一年 1 次 | 有人問「為什麼你這麼在意開關」才講,**不講品類、品牌、年份以外的任何細節** |

## 九、揭露義務與商業化風險(**必讀,交付時要主動向 Owner 點出**)

> **這一節不是形式。這個人物如果拿去做商業宣傳,不揭露會出事。**
> **而且他是十人裡最接近品牌 TA v1.2 的人,也就是品牌最想拿來用的那一個。** 誘惑最大的人物,風險也最大。
> **v1.1 改為高意願之後,誘惑又更大:** 他現在是「正在找桌充、預算剛好、願意早鳥」的人。新增的風險寫在 9.6b。

### 9.1 這個人物的本質

**許書維是虛構人物。** 他不是真人,他沒有真實的公司、產品、同事、ODM 窗口或工作紀錄。
他「做了十四年硬體產品」「開一星評論早會」「看過實體開關被砍」是敘事設定,不是可查核的資歷。

### 9.2 必須揭露的情況(任一成立就要揭露)

| 帳號本身作為品牌行銷資產經營 | **要** |

| 內容中出現他人產品且有付費關係 | **要** |
| 內容用於嘖嘖募資頁、募資影片、募資宣傳 | **要,見 9.6** |

### 9.4 法規依據(給 Marcus 覆核用)

- **台灣《公平交易法》第 21 條(不實廣告)與第 25 條(欺罔或顯失公平)。**
  **公平會《對於薦證廣告之規範說明》**:薦證者與廣告主之間有利害關係時須揭露;
  **以虛構的「一般消費者」或「專業人士」身分做使用見證,可能構成不實廣告**,廣告主負責。
  **這個人物的「硬體 PM」設定會讓他被讀成「專業人士薦證」,適用的標準更嚴。**
- 《消費者保護法》對廣告內容真實性的要求。
- **《兒童及少年福利與權益保障法》** 對兒少影像與個資的保護:**本人物的小孩即使是虛構的,
  AI 生成的擬真兒童影像用在商業內容仍有爭議風險。** 建議商業素材中完全不出現小孩。
- 若用於美國市場(Amazon、美國社群):**FTC Endorsement Guides(2023 修訂版)** 明確涵蓋虛擬影響者,
  並對「expert endorser」有額外要求:**專家薦證必須真的具備該專業,且實際做過評估。** 這個人物兩者都沒有。
- Meta(Threads / Instagram)與 TikTok 的品牌內容政策要求開啟付費合作標記;兩個平台對擬真 AI 生成內容也有標示要求。
- **口徑:以上為依 2023–2026 年公開規範所做的合規判讀(`Estimated`),不是法律意見。
  實際投放前應由 Marcus 覆核;台灣部分建議請法務確認公平會最新的薦證廣告規範版本。**

### 9.5 這個人設最容易被戳破的四個地方

| 風險點 | 為什麼危險 | 怎麼避 |
|---|---|---|
| **硬體產業知識被真的同行檢驗** | 他的權威建立在 ODM、時程、BOM 的現場感上。講錯一次就崩 | 技術內容不確定就不發。**只講流程與取捨,不講電路與規格數字** |
| **被問「你在哪家公司」「做什麼產品」** | 一旦被追問就會露餡 | 已寫進「絕不發」。永遠用「公司規定不能講」擋,而且這在設定裡是真的 |
| **小孩** | 讀者會想看小孩、會問小孩的事;AI 生成的兒童影像有額外風險 | **永遠不露臉、不寫名字**;小孩的內容只寫物件(籃子、垃圾車、珠珠吊飾) |
| **要求直播、即時語音、到場活動** | 即時互動是最快破功的地方 | **不做直播、不做語音、不出席實體活動** |

**額外風險:** 如果有真人的臉被用來當這個人物的形象,那是**肖像權問題**,不是揭露問題。
本人物的視覺一律 AI 生成,`07` 已寫死不得使用真實人物長相。

### 9.6 SPACION 桌面充電站專屬的風險(**這一段最重要**)

**產品時程:** 嘖嘖預定 2027 年 6 月中上線,量產 2027 年 8 月。**現在(2026 年 10 月)產品不存在。**

| 規則 | 說明 |
|---|---|
| **2027 年 6 月嘖嘖上線前,零提及** | 他不可能用過、看過、摸過一個還沒有的產品 |
| **不得宣稱「用過」「用了一週」「實測」** | 虛擬人物的使用心得 = 虛構見證。**任何時間點都不行** |
| **不得讓他用 PM 身分評價 SPACION 的設計、BOM、ODM、認證、散熱、安全性** | **這是這個人物最危險的用法。** 「一個做了十四年硬體的 PM 說這顆做得很好」= 虛構的專業薦證。**比沛璇的「看穿募資影片」更直接觸及公平會與 FTC 的專家薦證規範** |
| **不得引用任何規格數字當成他的體驗** | 企劃書的 240W、單孔 140W、伸縮線、主開關是**目標規格,RFQ 未回** |
| **不得批評或比較具名競品** | 他的公司守則本來就禁止,設定內外一致 |
| **不得把「太太送的」做成見證** | 品牌 TA v1.2 的 T8 禮物通道很適合他,**但一則「我太太送我的」虛構貼文就是虛構見證** |
| **不得讓他的小孩出現在任何 SPACION 相關內容裡** | 兒少影像 + 商業 = 不必要的風險 |
| **不得宣稱效期、壽命、安全性** | 例如「伸縮線拉兩萬次不會壞」「小孩亂按也很安全」 |

### 9.6b 高意願之後新增的風險(v1.1)

**v1.0 的風險是「拿一個不買的人去推產品」。v1.1 的風險更隱蔽:他現在本來就在找,所以拿他收尾看起來很自然。**

| 誘惑 | 為什麼不行 | 規則 |
|---|---|---|
| **「從 2026 年 10 月就在找,2027 年 6 月終於找到 SPACION」的弧線** | 這是**預先布置的虛構見證**。八個月的「在找」貼文,如果用 SPACION 收尾,整條敘事就是廣告,而讀者看不出來它從第一天就是。**比一則業配更難被讀者辨識,所以更嚴重** | **他在找的貼文,不得被規劃成任何品牌的鋪陳。** Lena 排內容時,「在找」系列不得與任何產品上市時程對齊 |
| **「連 PM 的比較表都選它」** | 虛構的專家評比。他的比較表是設定,不是評測 | **他的比較表永遠不公開候選與排名,包括 SPACION 上線之後** |
| **「我早鳥了」「我贊助了」** | 虛擬人物不可能真的贊助。**嘖嘖頁的贊助人數、留言區、FB 社團裡出現他的「我也下單了」,等同偽造贊助見證** | **零。** 任何平台、任何時間都不行 |
| **拿 11.6 的九欄當文案** | 九欄是 Nora 形成 Opinion 的輸入。直接改寫成「PM 爸爸的九項檢查,它全部過關」,就是把虛構人物的判斷包裝成專業背書 | 九欄只能內部用。**對外文案不得引用他、不得暗示有這個人** |
| **把太太的「小孩」分頁預算寫成「太太同意買的」** | 太太是虛構的,她的核准也是虛構的。T8 禮物通道與「另一半點頭」的見證都是虛構見證 | 太太與預算永遠不進任何商業內容 |

**一句話:他越像真的在找,拿他收尾就越像真的見證。高意願讓他成為更好的校準工具(9.8 第 1 點),也讓他更不能當代言人。**

### 9.7 這個人物該退場的情況

1. 被平台判定為未揭露的虛擬人物並降權或停權。
2. 硬體產業知識被真的同行公開質疑,且無法回應。
3. 商業關係被揭露後,帳號的核心信任資產(第三節第 2 點)歸零。
   **這是最可能發生的死法。** 一旦他開始推銷,他就不再是他。
4. 內容比例失控:連續四週桌面、充電佔比超過 30%,他已經變成另一個帳號了。
5. **有讀者開始問「你小孩幾年級、哪間學校」而且帳號回答了。** 那代表邊界已經破了。
6. **(v1.1)「在找桌充」的貼文開始被排成任何產品的上市倒數**,或帳號說出他買了哪一顆。那一刻他已經是廣告帳號了。

### 9.8 商業化的實際建議(給 Owner 決策用)

**這個人物的價值來自三件事:他不推銷、他懂取捨、他的家是真的。**
**他也是十人裡最接近品牌 TA v1.2 的人。** 這讓他最適合當校準工具,也最不適合當代言人。

比較安全的用法(依風險由低到高):
1. **不發文,只當受眾校準工具。** Lena 寫 SPACION 文案前,拿他的禁語、反感與語感對一遍:
   「書維看到這句會不會說『這裡一定有人在會議上輸了』」。
   **品牌 TA v1.2 的 T1–T11 觸發器,可以拿他逐條試:哪一條他會轉述、哪一條他會關頁。**
   **v1.1 之後多一個用法:** 拿 `11 § 11.6` 的九欄與否決條件,讓 Nora 模擬他讀嘖嘖頁的順序(時程表 → 不適合誰 → 規格表缺的欄 → 開關 → 價格),
   **看他在哪一步關頁。** 這是一個高意願、但標準沒降的人,最能抓出頁面上哪一段會讓真的買家流失。
   **這是最有價值、風險最低的用法。**
2. **品類教育內容,不提品牌。** 「規格表缺的那一欄怎麼看」「出貨日為什麼要加三個月」
   「家裡晚上誰的裝置先充」。品牌只出現在 bio 的揭露裡。
3. **Build in public 的觀察者(明確標示合作)。** 讓他以「被邀請去看開發過程」的身分出現,
   **只能記錄流程(打樣、時程、農曆年怎麼排),不能評價品質與安全。**
   `【廣告】` + 付費合作標記 + 帳號虛構揭露。**這一步之後信任會下降,而且專業薦證的風險比其他人物高。**
4. **直接當代言人放進嘖嘖頁或 Amazon 素材**,風險最高,虛假見證加上虛構專家薦證。**不建議。**
