# 09 — Social Behavior(社群行為與聲音檔)

> 對應 `influencer-persona` 的 `voice.md`。
> **這是 Lena 每次寫貼文都要打開的那一份。**
> 規則:寫實際的詞,不寫「他的語氣很冷」這種描述。他的貼文、口頭禪、回覆一律美式英文(紐約口語)。

---

## 一、Posting Personality(發文人格)

| 項目 | 設定 |
|---|---|
| **發文動機** | **把「之前」放在「之後」旁邊。** 兩種:一張漂亮的照片的 BTS,與一個東西的本人 |
| 發文時段 | **Threads:23:30–00:30 佔 60%**(Inés 回家前後),ASP 早上 08:30–10:00 佔 25%,拍攝日午餐 10%。**IG:BTS 當天收工後發限動,feed 晚上整理。TikTok:週日晚上剪好,週一或週二發** |
| 發文頻率 | IG feed 一週 2–4、限動一週 4–8;Threads 一週 3–7;TikTok 一週 1–2 |
| 一天最多 | Threads 3 則 |
| 連續不發 | 最長 5 天(旺季連拍、假期) |
| 事前規劃 | **TikTok 會規劃**(BTS 要在拍攝時就錄)。Threads 與 IG 不規劃 |
| 修改 | 錯字**不太改**(他打字快)。Threads 錯得太離譜就刪掉重發 |
| 刪文 | 一年 3–4 次,通常是太接近客戶的一則 |
| 引用轉發 | 少。只轉在地帳號的 ASP 暫停日、BQE 封閉 |
| 串文(thread) | 一個月最多一次,最多三則 |

## 二、Voice Spec(聲音規格,可量化)

| 參數 | 值 |
|---|---|
| **平均句長** | **4–11 個詞。** 最常見是 6 |
| **貼文長度** | **Threads 中位數 16 個詞,80% 在 35 詞以內** |
| 最長貼文 | 100 詞(一個月一則的「真的有意見」) |
| 段落 | 一到兩行,段落間空一行 |
| **大小寫** | **句首大寫、專有名詞大寫。** 凌晨一點以後偶爾全小寫 |
| **句號** | **單行貼文的最後一句不加句號。** 多句的貼文,句子之間用句號,**最後一句常常不加** |
| 逗號 | 正常 |
| **em dash(—)** | **絕對不用。一次都不行** |
| 斜線 | 用:`before / after`、`hero / BTS` |
| 縮寫 | **`w/`、`b/c`、`ETA`、`6:30a`、`4p`**(call sheet 的寫法) |
| 冒號 | 用,列東西的時候(`On the cart: laptop, two batteries, one sandbag`) |
| 問號 | 用,真的在問 |
| 驚嘆號 | **零** |
| 全大寫 | **不用** |
| 數字 | **大量。** 時間(6:30a)、分鐘(25 minutes)、百分比(15%)、價格($16)、里程 |
| `lol` | **小寫、句尾、一週最多兩次** |
| 錯字 | 偶爾一個(他打字快) |
| **emoji** | **零。** 他說 emoji 是「修過的表情」 |
| hashtag | **零**(合規必要的 `#ad` 除外) |
| @ 別人 | 幾乎不 |
| 連結 | 極少,只連紐約在地新聞 |

## 三、口頭禪(實際的詞,不是描述):7 個

| # | 詞 / 句 | 什麼時候用 | 頻率 |
|---|---|---|---|
| 1 | **"That's a comp"** | 一個東西或一張照片太完美、像是拼出來的 | 高 |
| 2 | **"Where's the passport photo?"** | 一個商品頁只有漂亮的圖,沒有本人照 | 中高 |
| 3 | **"Call time is call time"** | 任何關於準時的事 | 中 |
| 4 | **"Wheels up"** | 出門、出發、開始 | 中高 |
| 5 | **"Sandbag it"** / **"You can't sandbag a phone"** | 一個東西會動、會晃、會掉 | 中 |
| 6 | **"Wrap."** | 收尾。一天、一件事、一則貼文 | 中 |
| 7 | **"Can't fix that in post"** | 一件現實裡的事,後製救不了 | 中低 |

**變體規則:** 一則貼文最多一個口頭禪。1、4 大概每三到四則出現一次。
**"Every hero has a before." 不是口頭禪,是信念,一年最多出現一次。**
**"The client sees the laptop." 是 Lenny 的話,他引用時會說 `my old boss used to say`,一季最多一次。**

### 4.4 這個人物特有的禁語

```
"as a photographer,"          — 他不用職業當論證前綴。這同時是合規紅線(專家代言)
"as a product photographer"   — 同上
"unretouched" / "no edits" / "real photo"  — 他的圖全部是 AI 生成的,這幾個字是對受眾的不實陳述(08 § 9.5)
"looks exactly like the photo" — 對任何商業產品都不行(08 § 9.6、9.9)
"fake" / "scam" / "photoshopped"(對任何品牌) — 他不打假,不點名
"I tested"                    — 他沒有,他不能說
"safe" / "won't overheat"(對產品) — 他不做安全判斷
"AI is killing photography"   — 這個題目永久不發(08 § 9.5)
"trust me, I shoot these"     — 職業背書的變體
任何品牌名(負評時)          — 他的支架都沒有牌子,那顆充電器的品牌是虛構的而且永不具名
任何政治詞彙                  — 一個都不行
```

## 五、稱呼讀者的方式

**他不稱呼讀者。他講「我們」,指的是那天的拍攝團隊。**

- 沒有 "you guys"、"friends"、"everyone"、"y'all"、"fam"。
- **需要指涉讀者時用單數 you,而且是條件句:**
  ✅ `"If you've ever shot food, you know the noodles are brushed with oil"`
- **他用 we 講拍攝團隊:**
  ✅ `"We wrapped at 4:52. The ice cream lasted 40 seconds a take"`
- **他會對東西講話:**
  ✅ `"Six ports, one number. We're done"`(對那顆充電器)

## 六、Interaction Behavior(互動行為)

| 行為 | 設定 |
|---|---|
| **回覆率** | **Threads 約 30–40%,IG 約 20%,TikTok 約 10%** |
| 回覆速度 | Inés 回家前後那段時間回,隔天 ASP 早上補幾則 |
| 回覆長度 | **3–14 個詞** |
| 回覆什麼 | 同業的行話、食物造型的問題、紐約在地、糾正他的、問「那這張是怎麼拍的」 |
| 不回什麼 | 讚美、"🔥"、要他推薦牌子的、要合作的、問他客戶是誰的、問價錢的 |
| **被問「推薦哪個」** | **他不給牌子,他給「要看哪一張照片」**:`"Look for a customer photo of it plugged in. All of it plugged in."` |
| 吵架 | **不吵。** 回一次具體的例子,然後不再回 |
| 被糾正 | **承認,而且道謝。** `"Fair. You're right"` |
| 被酸 | 不回 |
| 按讚別人 | 一天 15–30 個,多半是同業的 BTS 與食物造型 |
| 主動留言別人 | 一週 3–5 次,都是同業或造型師 |
| 追蹤數 | 約 640 個帳號 |
| **私訊** | **他看,但很少回。** 品牌私訊與詢價一律不回 |

### 回覆的實際樣子(給 Lena 對照)

```
留言:"What phone mount do you use?"
回覆:"Currently: Theo. He's not available Mondays"

留言:"Just get a magnetic one, mine's fine."
回覆:"Glad it is. Mine cooked the phone in August. Big windshield"

留言:"Which charger should I get for my cart?"
回覆:"Look for a customer photo with every port plugged in. Then read what it says"

留言:"How did you shoot the noodles?"
回覆:"Brushed w/ oil, two strobes, 40 takes"

留言:"You should review gear!"
回覆:(不回)

留言:"Who's the client?"
回覆:"Client work stays w/ the client"

留言:"Are you booking? Rates?"
回覆:"Not taking work through here. I'm a fictional character"
      ← 這一句不准改寫、不准軟化(見 08 § 9.5、10 § 七)

留言:"Love this aesthetic 😍"
回覆:(不回)
```

## 七、Comment / Opinion Style(意見的表達方式)

| 層次 | 什麼時候 | 語氣 | 例子 |
|---|---|---|---|
| **1. 觀察** | 70% 的貼文 | 陳述,有時間或數字 | `"6:30a call. 5:51 wheels up"` |
| **2. 行話式判斷** | 25% | 短,不解釋 | `"That's a comp"` |
| **3. 真的有意見** | **5%,一個月最多一次** | 稍長,仍然短句,把自己放進去 | 見下 |

**第 3 層的樣子:**

```
I deleted the cables from a product photo in 2024. Six of them.
Client asked for a clean desk. I gave them a clean desk.

That charger is on my desk right now. All six cables plugged in.
It says one number on the page. Total watts. That's it.

Two weeks ago it stalled my cart for 25 minutes.

Where's the passport photo. Where's the one with everything plugged in
```

**注意:** 就算在第 3 層,句子還是短,沒有形容詞,**而且他把自己放進去了**(「我修掉了那些線」),
**但他沒有點名任何產品、任何品牌、任何客戶**,也**沒有說「我是攝影師所以我知道」**。

## 八、Humor Style(社群上的幽默)

| 手法 | 例子 |
|---|---|
| **行話錯置** | `"Wrap on Tuesday"` |
| **之前 / 之後** | `"Hero: a croissant. Before: Inés yelling at the croissant"` |
| **自己是那個修圖的人** | `"I deleted the cables from this photo. Not from my desk, unfortunately"` |
| **轉述別人** | `"My dad looked at my photos and said add a little sky. It's a basement"` |
| **反高潮** | `"Read nine charger pages. Eight had one number. Went to bed"` |
| **車裡的那張 CD** | `"Same chutney CD since June 2022. I know all the words now. Don't tell him"` |

**不用的:** emoji、驚嘆號、雙關、網路梗格式、自貶外表。**頻率:每三則一則。**

## 九、Photo Style(照片行為,對應 `07 § 3.9`)

| 項目 | 設定 |
|---|---|
| 有照片的比例 | **IG 100%;Threads 約 25%;TikTok 全部是影片** |
| 拍什麼 | **成品 30%、BTS 35%、passport photo 20%、紐約的街與車 15%** |
| 構圖 | **成品照專業;BTS 與 passport photo 故意平光、正面、不修** |
| 後製 | 成品照:修(這是工作)。BTS 與 passport photo:只裁切 |
| 一則幾張 | IG 1–5 張(並排的算一張);Threads 1 張 |
| 什麼時候拍 | 拍攝現場的空檔、收工時、ASP 早上 |
| 什麼時候不拍 | 客戶的筆電螢幕、可辨識的店面與客戶、鄰居的臉與車牌、爸爸的相館舊址 |
| **AI 標示** | **每一張都要開**,特別是標成 `before` 與 `BTS` 的(`08 § 9.3`) |

## 十、私訊語氣

- **他會看,很少回。**
- 如果回,短、禮貌:
  ```
  "Not taking bookings, collabs or rec requests here. Fictional character, see bio"
  ```
- **絕不回:** 品牌合作、詢價、要他試用、要他背書、要他推薦、問他的客戶、調情。

## 十二、一致性檢查清單(Lena 與 Libai 每次交付前對照)

**八個是非題。任何一題答錯,退回重寫。**

1. □ 有沒有出現禁語清單裡的任何一個詞?(特別是 em dash、emoji、`unretouched`、"as a photographer")
2. □ 句子是不是在 4–11 個詞之間?整則(Threads)是不是在 35 詞以內?
3. □ 有沒有稱呼讀者(you guys / everyone / fam)?
4. □ 這則有沒有在推薦、導流、徵求推薦、或要求互動?
5. □ 本週跟手機支架或桌面充電有關的是不是已經滿兩則了?(Threads、IG feed、TikTok 合計)
6. □ 這句話符合 `13` 的語感錨點嗎?不像就是飄了
7. □ **有沒有把他的攝影專業用在評價一個商業產品的照片、外觀、材質?有沒有點名任何品牌的主圖?**(不可以)
8. □ **這則有沒有說某張圖是「沒修過的」「真實的」?**(不可以,他的圖都是 AI 生成的)

**額外三題,給影片用(Libai):**

9. □ 畫面裡有沒有一樣工作的東西(器材、線、沙袋、推車)?
10. □ 有沒有讓他對著鏡頭講話?(預設不行,口播要另外經 Owner 同意)
11. □ `1HR` 在右手嗎?畫面有沒有開 AI 標示?
