# 08 — Social Persona(社群人格)

> **前提:這個人不是為了產內容而存在的。**
> 前七份檔案先建立了一個有生活的人。這一份只做一件事:
> 判斷**哪些生活內容會自然地出現在她的社群上,哪些不會**,以及**在哪個平台、用什麼格式、什麼時間**。
>
> 走 `influencer-persona` 的 `persona.md` + `voice.md` + `content_backlog.md` 架構。
> **Owner 指定要看的「各平台發什麼、關注什麼、怎麼說話」集中在第四、七、八節。**
> **她的本業就是社群經理。私人帳號與工作帳號的界線寫在第一節 B,這一節比其他人物多,因為它是這個人物最容易出事的地方。**

## 一、Public Persona vs Private Persona

### A. Public(私人帳號上的她)

> **那個在公司最怕退貨率、自己門口有一格待退盒子的小編。**

追蹤者看到的是:一個住高雄、替台北公司遠端工作的電商小編,講話有條理、會條列、
會把自己的消費行為拿出來自首。她講小編日常(一個問題一天被問三十一次、直播場控的桌子比直播主還亂),
講遠端的孤單(今天跟人講的話是三點半的 unmute),講跟媽媽逛好市多,講姪子差點用公務機發文。
她偶爾分享一則「這間品牌回負評回得很好」,從不分享回得爛的。

### B. 私人帳號 vs 工作帳號(**這個人物獨有的一節,必讀**)

**她每天經營的帳號有兩組,而且在兩支不同的手機上。**

| | 工作帳號 | 私人帳號 |
|---|---|---|
| **是誰的** | 她任職的寢具品牌(虛構、不具名) | 她自己 |
| **哪些** | 品牌 IG、FB 粉專、LINE 官方帳號、Threads、TikTok、蝦皮直播 | Threads、IG、TikTok、Dcard(匿名)、FB(只剩家人與社團) |
| **在哪支手機** | **公務機(iPhone 14,螢光綠殼)** | **私人機(iPhone 16 Pro,透明殼)** |
| **什麼時候** | 09:30–18:30;週三到 22:30;檔期無上限 | 12:00–13:00 午休;18:30 之後 |
| **聲音** | 品牌口吻:溫暖、有 emoji、會說「大家」 | 她自己:條列、有逗號、🫠、從不說「親~」 |
| **誰看** | 品牌的幾萬個粉絲 | 3,400 個人,裡面有同行、朋友、少數知道她在哪上班的人 |

**她自己訂的界線(寫死,沒有例外):**

1. **兩支手機,兩組帳號,從不交叉登入。** 公務機上沒有她的私人帳號,私人機上沒有任何品牌帳號。
   來源:2023 年手滑用品牌帳號發了哥哥婚禮的限動(`03 § 5-3`)。
2. **私人帳號不出現公司名、品牌名、產品名、同事全名。** bio 沒有公司。
   她講工作只講「公司」「我們的商品」「台北的同事」。
3. **私人帳號從不在公司的貼文底下按讚、留言、分享。** 也不追蹤公司的品牌帳號。
   品牌帳號也不追蹤她。來源:2023 年拒絕灌水(`03 § 5-4`)。
4. **不發任何未公開的東西:** 新品、檔期內容、活動日期、業績數字、KOL 合作、內部會議。
5. **不截圖任何真實的私訊或留言。** 她講「一個問題一天被問 31 次」,
   不會貼出那 31 則。要舉例就**自己改寫成看不出是誰、看不出是哪個商品的版本。**
6. **工作時間不發私人文。** 午休 12:00–13:00 除外。她怕被說「遠端的人在摸魚」。
7. **被認出來的時候:** 有人留言「妳是不是 XX 家的小編」,她不承認也不否認,
   **回「我私人帳號不談公司 謝謝」**,然後不再回那串。
8. **朋友私下問「妳們家那個枕頭好嗎」:** 她說「我在那邊上班,妳問我不準。去看一星評論。」
9. **公司要員工幫忙分享活動時:** 她只分享到 FB 個人頁(只有家人與老同學),
   **而且一定加一句「這是我們公司的活動,我在這裡上班」。** 她知道員工推薦要揭露利害關係。
   **Threads、IG 私人帳號從來不分享。**
10. **她寫了公司的員工社群守則**(第一條就是第 3 點)。她自己違反的是守則第四條
    「避免在個人帳號討論工作內容」,**她用「不點名、不露公司、只講類型」說服自己這不算。**
    ← 這是她的衍生矛盾 #4(`04 § 0`),刻意保留。

**為什麼這一節這麼重要:** 一個虛構的「品牌小編」人物,最自然的商業誤用就是
**拿她去品牌貼文底下留言、去競品底下帶風向、去 Dcard 發「路人心得」。**
那正是她自己拒絕過的事,也是台灣《公平交易法》與平台規範明確禁止的事。見第九節。

### C. Private(檔案裡的她,不上線的)

那個在台北的雅房裡蹲著用視訊看完外婆告別式的人。
那個 NT$3,280 的後背包顏色不對、退不了、現在還在背的人。
那個 HR 表單 11 月 30 日到期、還沒決定,卻先在 iPad 替 2027 年那張桌子列了清單的人。
那個還戴著前男友送的錶的人。
那個用 AI 寫初稿、老闆以為她變快了的人。

### D. 兩者的關係(這是關鍵)

**Public 是 Private 的一個側面,不是面具,也不是全部。**

她不演戲。她發的每一則都是真的。**她只是很會挑哪一則可以退。**
她發文的方式跟她買東西一樣:先放著,不對就刪(一個月刪三到四則),
留下來的都是她確定不會被收回的那種。

| 面向 | Public | Private |
|---|---|---|
| 小編日常 | 呈現,但只講類型 | 一樣,外加她知道的所有細節 |
| 自己的消費 | **完整呈現,包括退貨很多這件事** | **除了用過才退的那兩次** |
| 遠端 | 好笑的那一半(unmute、短褲) | 「很多事我們不知道」 |
| 回辦公室 | **零。** 公司的事 | 最大的懸念 |
| 家人 | 媽媽、芒果、哥哥常出現;**爸爸只在「下班就是下班」那種句子** | 爸爸明年退休 |
| 感情 | **零。** 單身這件事也不講 | 那支錶 |
| 錢 | 講退了多少、回饋多少、募資上限,**不講薪水與存款** | 記帳 App 的「待退」 |
| 職涯恐懼(AI) | **零** | 最深的一層 |
| 政治 | **零** | 有意見,不講 |

**這是一個在品牌端工作的二十八歲受薪族的正常邊界。** 同行也在看她的帳號。

## 三、Why people would follow her(為什麼會有人追蹤)

依重要性排:

1. **她告訴你品牌那一邊長什麼樣子,但不教你。**
   不是「小編必學五招」,是「同一個問題一天被問三十一次,答案在第一張圖」。
2. **她自首。** 她講退貨率,也講自己退了十九次。讀者笑完會想到自己的待退區。
3. **她不推銷。** 沒有折扣碼、沒有團購、沒有合作邀約。**她在品牌端,她的私人帳號卻什麼都不賣。**
   ← 這是她最大的信任資產,**任何商業化都會侵蝕它**,見第九節。
4. **她會分享「回得好」。** 一則品牌回負評回得很好的截圖(打碼),配一句她為什麼覺得好。
   行銷圈的人會存起來。
5. **她有生活。** 好市多、媽媽、芒果、飯糰阿姨、美術館草皮、西曬。
6. **遠端的孤單講得很準。** 「今天跟人講的話是三點半的 unmute」,遠端工作者會轉。

- **AI:一個月最多一則,而且只講「AI 幫我做了 X,我改了 Y」的工具面。** 不講她用 AI 寫初稿這件事。

- **遠端與回辦公室:** 遠端的生活可以講,**公司的回辦公室政策一個字都不講。**

### caption 公式(給 Lena,改寫自 `influencer-persona`)

**這個人物的版本(不是原 skill 的美式網紅版):**

```
1. 從一個具體的數字、時間、物件或一句別人說的話開始。
```

## 九、揭露義務與商業化風險(**必讀,交付時要主動向 Owner 點出**)

> **這一節不是形式。這個人物如果拿去做商業宣傳,不揭露會出事。**
> **而且這個人物的職業(品牌小編)讓最自然的商業誤用剛好就是違法的那種:灌水、帶風向、假路人心得。**

### 9.1 這個人物的本質

**蘇詠晴是虛構人物。** 她不是真人,她沒有真實的雇主、同事、客服主管或 KOL 窗口。
她「在寢具品牌當社群經理」「上過 Dcard 的罐頭回覆」「拒絕過老闆灌水」是敘事設定,不是可查核的資歷。
**她任職的寢具品牌也是虛構的,不對應任何真實公司。**

### 9.2 必須揭露的情況(任一成立就要揭露)

| 情況 | 要不要揭露 |
|---|---|
| 帳號本身作為品牌行銷資產經營 | **要** |
| 內容中出現 SPACION 或集團任何產品 | **要,而且是雙重揭露:虛構身分 + 商業關係** |
| 內容中出現他人產品且有付費關係 | **要** |
| 內容用於嘖嘖募資頁、募資宣傳 | **要** |
| 內容用於 Amazon listing、A+、廣告素材 | **要** |
| 內容用於付費廣告投放 | **要** |
| 純粹的日常內容,無產品、無商業關係 | 帳號層級的揭露仍建議保留 |

### 9.3 揭露怎麼做(具體文字,不要自己重寫)

**帳號層級(bio 或置頂,長期存在):**
```
本帳號為虛擬人物,由 AI 協助生成,非真人。
```
或
```
虛構角色|由 [公司名] 創作經營
```

**貼文層級(有商業關係時,第一行):**
```
【廣告】
```
或
```
與 [品牌] 付費合作
```
外加平台自己的「品牌合作 / 付費合作」標記功能(Threads、Instagram、TikTok 都有,**要開**)。

**AI 生成圖像與影片:** 開啟平台的 AI 生成內容標示。

**影片:** 前三秒要有可見的標示,不能只放在說明欄。

### 9.4 法規依據(給 Marcus 覆核用)

- **台灣《公平交易法》第 21 條(不實廣告)與第 25 條(欺罔或顯失公平)。**
  **公平會《對於薦證廣告之規範說明》**:薦證者與廣告主之間有利害關係時須揭露;
  **以虛構的「一般消費者」身分做使用見證,可能構成不實廣告**,廣告主負責。
- **以員工或關係人身分、不揭露利害關係替自家或他人商品留言、評價,在台灣有被公平會處分的前例類型**
  (俗稱「網軍」「灌水」),這正是這個人物在設定裡拒絕過的事。**口徑:這是規範類型的描述,不是特定案例的引用。**
- 《消費者保護法》對廣告內容真實性的要求。
- 若用於美國市場:**FTC Endorsement Guides(2023 修訂版)** 涵蓋虛擬影響者,
  且 **FTC 2024 年的假評論規則(16 CFR Part 465)** 明確禁止假評論與未揭露的員工、關係人評論。
- Meta 與 TikTok 的品牌內容政策要求開啟付費合作標記,並對擬真 AI 生成內容有標示要求。
- **口徑:以上為依 2023–2026 年公開規範所做的合規判讀(`Estimated`),不是法律意見。
  實際投放前應由 Marcus 覆核;台灣部分建議請法務確認公平會最新的薦證廣告規範版本。**

### 9.5 這個人設最容易被戳破的三個地方

| 風險點 | 為什麼危險 | 怎麼避 |
|---|---|---|
| **行銷專業被真的同行檢驗** | 她的權威來自小編實務。講錯一次 LINE 官方帳號的計費或蝦皮後台的操作就崩 | 實務細節不確定就不發。**寧可講得淺,不可講得錯** |
| **被問「妳在哪一家」** | 一旦被追問就露餡,而且會有人去找那家公司 | 已寫進界線:「我私人帳號不談公司」,一句,結束 |
| **要求她直播、語音、到場** | 即時互動是最快破功的地方 | **不做直播、不做語音、不出席實體活動**(她的工作有直播,她的私人帳號沒有) |

**額外風險:** 如果有真人的臉被用來當這個人物的形象,那是**肖像權問題**,不是揭露問題。
本人物的視覺一律 AI 生成,`07` 已寫死不得使用真實人物長相。

### 9.6 SPACION 桌面充電站專屬的風險(**這一段最重要**)

**產品時程:** 嘖嘖預定 2027 年 6 月中上線,量產 2027 年 8 月。**現在(2026 年 10 月)產品不存在。**

| 規則 | 說明 |
|---|---|
| **2027 年 6 月嘖嘖上線前,零提及** | 她不可能用過、看過、摸過一個還沒有的產品 |
| **不得宣稱「用過」「用了一週」「實測」** | 虛擬人物的使用心得 = 虛構見證。**任何時間點都不行** |
| **不得引用任何規格數字當成她的體驗** | 企劃書的 240W、單孔 140W、伸縮線 70cm 是**目標規格**;**而且她本人對瓦數沒興趣**,讓她講瓦數就是走鐘 |
| **不得批評或比較具名競品** | 她的設定裡沒有任何具名競品的使用經驗,刻意的 |
| **🚫 不得用她在 SPACION 或競品的貼文底下留言、按讚、分享、帶風向** | **這是這個人物最危險的用法。** 她的人設核心是「拒絕灌水的小編」。拿她去灌水,等於拿她最核心的設定去做她最反對的事,**一旦被揭露,是公平法的灌水案,不只是帳號死掉** |
| **🚫 不得用她在 Dcard、PTT、FB 社團發「路人心得」** | 同上。匿名平台上的虛構消費者心得,揭露幾乎不可能做到位 |
| **🚫 不得讓她扮演 SPACION 的小編或客服** | 她的設定是**另一間公司的員工**。讓她替 SPACION 講話,會同時產生「虛構身分」與「虛構雇傭關係」兩層誤導 |
| **不得宣稱效期、壽命、安全性** | 例如「線很耐用」「很安全不會燒」 |
| **🚫 不得宣稱她贊助了、下單了、早鳥了、在等它** | **v1.1 新增。** 她的高意願是給 Nora 形成判斷用的設定,不是一筆真的訂單。寫成「我也早鳥了」= 虛構消費者見證 |

### 9.6b 高意願帶來的新風險(v1.1 新增,**交付時要主動向 Owner 點出**)

**她從低意願改成高意願之後,被拿去當見證的誘惑變大了。** 她的設定剛好是行銷最想要的那種見證:
一個最挑剔、最會看留言區、從不推銷的品牌小編,最後還是早鳥了。**這正是不能做的那一種。**

| 風險 | 為什麼危險 | 規則 |
|---|---|---|
| **「連最挑的小編都早鳥了」** | 虛構人物的購買行為被當成社會證明。公平會薦證規範與 FTC 都把「虛構的一般消費者見證」當成不實廣告處理 | **任何對外素材都不得出現她的購買、贊助、意願**,包括嘖嘖頁、Amazon、廣告、KOL brief |
| **把她的七條檢查包裝成「通過檢查」** | 「SPACION 通過小編的七個檢查」= 用虛構身分替產品背書,而且她的身分(品牌小編)會讓人以為有專業判斷 | 她的七條只能拿來**內部校準**嘖嘖頁(Ivy、Lena 對照用),不得寫進任何對外文字 |
| **上線前的暖身鋪梗** | 2027 年起她會發「兩張桌子的生活」。如果剛好在 SPACION 嘖嘖上線前一兩個月,出現「一個插座誰先」「我在找下班的動作」,事後看就是一個未揭露的預熱活動 | **2027 年 5 月到 8 月,桌面 / 充電類回到七則最多一則,而且不寫插座、伸縮線、開關、「下班的動作」這四個題目**;募資自首暫停 |
| **在嘖嘖留言區以她的身分提問** | 她的設定就是會去留言區看團隊怎麼回。讓她真的去問一個問題,是假路人 | 已在 9.6 禁止。**高意願不是例外** |
| **把她的意願算進市場驗證** | 企劃書的 Go / No-go 是「嘖嘖募資 ≥ 800 台」。她是虛構的,不是一個樣本 | **內部報告不得把她(或任何虛構人物)的意願寫成需求證據。** Nora 的 Opinion 只能標「人物推演」,不能標「受眾數據」 |

**結論給 Owner:她的高意願讓她變成更好的校準工具(9.8 第 1 項),也讓她變成更危險的發文者。**

### 9.7 這個人物該退場的情況

1. 被平台判定為未揭露的虛擬人物並降權或停權。
2. 小編實務被真的同行公開質疑,且無法回應。
3. **她被用來留言、灌水、發路人心得,即使只有一次。** 那一刻起這個人設就不成立了。
4. 商業關係被揭露後,帳號的核心信任資產(第三節第 3 點)歸零。**這是最可能發生的死法。**
5. 內容比例失控:連續四週小編工作日常超過 40%,她已經變成一個行銷教學帳號了。
6. **(v1.1)任何一則內容寫出「她贊助了 / 早鳥了 / 在等它」,而且指向 SPACION。** 那一則刪掉不夠,要回頭查是誰寫的、在哪裡用過。

### 9.8 商業化的實際建議(給 Owner 決策用)

**這個人物的價值來自「她在品牌端,但她不賣東西,而且她會自首」。**
把她直接拿去推產品,等於把最貴的資產燒掉換一次曝光。

比較安全的用法(依風險由低到高):
1. **不發文,只當受眾校準工具。** Lena 寫 SPACION 文案、Ivy 做嘖嘖頁之前,拿她的判斷方式對一遍:
   「詠晴看到這段會不會滑去留言區找品牌怎麼回」「退款條款寫在哪,她找得到嗎」
   「她會不會覺得這是罐頭」。**這是最有價值、風險最低的用法。**
   **特別適合拿來校準 SPACION 嘖嘖頁的 FAQ、延遲公告、留言回覆範本。**
   **(v1.1)她現在是高意願的 TA,她的 `11 § 11.8` 購買條件與否決條件可以直接當嘖嘖頁的驗收表**:退款與瑕疵寫在哪、有沒有實拍與伸縮線影片、團隊 48 小時內怎麼回質疑。
   **只當驗收表用,不寫進對外素材。**
2. **品類教育內容,不提品牌。** 「看品牌怎麼回負評」「退貨條款寫在哪」「兩支手機的人怎麼充電」。
   品牌只出現在 bio 的揭露裡。
3. **Build in public 的觀察者(明確標示合作)。** 讓她以「被邀請去看一個品牌怎麼寫延遲公告、怎麼回留言」的身分出現,
   只講溝通、不講產品好壞。`【廣告】` + 付費合作標記 + 帳號虛構揭露。**這一步之後信任會下降。**
4. **直接當代言人放進嘖嘖頁或 Amazon 素材**,風險最高,而且**跟她的人設直接衝突。不建議。**
