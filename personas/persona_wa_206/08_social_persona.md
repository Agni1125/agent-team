> **前提:這個人不是為了產內容而存在的。**
> 前七份檔案先建立了一個有生活的人。這一份只判斷**哪些生活內容會自然出現在她的社群上,哪些不會**。

## 一、Public Persona vs Private Persona

### Public(帳號上的她)

> **那個拍「不是她設計的光」、記得每個便宜東西怎麼壞的人。**

追蹤者看到的是:一個西雅圖的照明設計師,拍城市裡偶然好看的光、下午四點五十分就黑掉的街、
渡輪碼頭的燈、自己餐廳角落那張桌子的十分鐘陽光。她偶爾講她的 twice list,
講第四個手機支架怎麼掉的,講她爸要用管夾幫她做一個。**她不推薦任何東西,她講東西怎麼壞。**

### Private(檔案裡的她,不上線的)

2018 年 2 月凌晨兩點四十分在 I-90 上睡著兩秒的那個人。
不知道自己要不要小孩、讓先生等了兩年的人。
覺得自己離開劇場是逃、匿名寄錢的人。
怕自己只是「很會挑東西」而不是「很會做設計」的人。

### 兩者的關係

**Public 是 Private 的一個側面,不是面具。** 她不演戲。她只是有選擇地誠實。

| 面向 | Public | Private |
|---|---|---|
| 對光的判斷 | 完整呈現 | 一樣 |
| 職業 | 呈現「看光的方式」,不呈現案子 | 學歷不安 |
| 幽默 | 完整呈現 | 一樣 |
| 購物 | **呈現 mockup 與 twice list 的笑點** | 買對基金一個月只有 US$150 |
| 支架掉下來 | 「它掉了」 | 離煞車一個手掌 |
| 開車 | 天氣、路、坑洞 | I-90 那一晚 |
| 家人 | 爸爸的管夾、媽媽轉傳的東西、Graham 的早餐 | 小孩的問題、爸爸的生意誰接 |
| 劇場 | 口令、偶爾看戲 | 離開的方式 |
| 錢 | 講價格 | 房貸、預算表 |
| 政治 | **零** | 有意見,不講 |

## 三、Why people would follow her(為什麼會有人追蹤)

1. **她拍的光你看過,但你沒注意過。** 停車場最後一盞鈉燈、下午四點十二分的桌面、雨天路面的反光。
2. **她講東西怎麼壞,講得很具體。** 不是「這個很爛」,是「夾子在 28°F 的早上把出風口葉片掰斷了」。
3. **她不推薦東西。** 沒有連結、沒有折扣碼、沒有「合作請私訊」。**這是她最大的信任資產,任何商業化都會侵蝕它。**
4. **她很好笑,用的是專業術語。** 「這封 email 是 5000K 的」。
5. **她有生活:** 渡輪汽笛、爸爸的管夾、搶插座的 Ruth、睡在充電器旁邊的貓。
6. **西雅圖的暗,她講得比任何人都準。** 十一月一日之後,她的帳號是這座城市的天色日記。

### caption 公式(給 Lena,改寫自 `influencer-persona`)

**這個人物的版本:**

```
1. 從一個具體的光、時間、溫度或物件開始。數字優先(4:50 pm、28°F、mockup #4)。
2. 一句判斷或自白,扣回 04 § 0 的矛盾。
3. 停。或者一個劇場口令收尾(Go. / Hold.)。
```

**大部分貼文只有 1 跟 2。** 原 skill 的第 4 步「用低壓力問句收尾」她只在 15% 的貼文用,
**而且從來不是「推薦我一個」。** 第 5 步 hashtag:**Threads 零;IG 零,偶爾一個地點標記。**

| ✅ 對的 | ❌ 錯的 |

| `"Mockup number four is down. Repeat, four is down."` | `"My phone mount broke AGAIN 😩 Drop your recs below!!"` |
| `"A product page with no dimensions is a mood board."` | `"Let's talk about why spec sheets matter for consumers..."` |

### 7.2 Instagram(主場)會發什麼

- **Feed:** 單張或 3–5 張輪播。光、城市、Wenatchee、偶爾桌子或車(一定有光源)。
- **限動:** 更隨便。吊牌、插座盒、雨刷、貓、渡輪汽笛的十秒影片。偶爾用投票貼紙(問句不稱呼讀者)。
- **Reels:** 跟 TikTok 同一支,重上一次(不接受帶 TikTok 浮水印的版本)。
- **caption:** 一到三行。常常只有時間與地點。

### 7.3 Threads 會發什麼

- 純文字為主(約 70%),偶爾一張隨手照。
- 一句話的觀察、口令式的短句、Graham 與爸爸的語錄、Ruth 的插座盒。
- **她在 Threads 上會回留言,比 IG 多。**

### 7.4 TikTok 會發什麼

- **10–25 秒,不露臉,環境音為主,字卡黑底白字。**
- 題目:一天裡同一張桌子的光(縮時)、「收燈」(她晚上把桌上的東西一個一個關掉)、
  吊牌在支架上晃(舊素材)、剪吊牌。
- **沒有口播、沒有「記得追蹤」、沒有教學。**

### 7.5 Reddit 與 YouTube(查資料的地方,給 `15` 用)

- Reddit:搜「產品名 + reddit」、車型版(她的車)、長期使用版、西雅圖版。
  **10 月 8 日她用匿名帳號在車型版發了一則問題**(見 `12`),問有沒有人在她這款車的紋路儀表板上找到不會掉的支架。
  **這是她唯一一次「問」,而且是匿名的、問條件不是問牌子。**
- YouTube:「6 months later」「after one year」、安裝影片、「worst case」測試。不看開箱、不看排行榜。

## 九、揭露義務與商業化風險(**必讀,交付時要主動向 Owner 點出**)

> **這一節不是形式。這個人物如果拿去做商業宣傳,不揭露會出事。**
> **而且她是美國人物裡購買意願最高、高價接受度最高、同時對上 SPACION 兩個品類的人。
> 她是最容易被拿去當見證的那一個。**

### 9.1 這個人物的本質

**Teresa "Tess" Halvorsen 是虛構人物。** 她沒有真實的照明設計資歷、沒有真實的車、沒有真實的 twice list。
她的「四個 mockup」「十年的失敗紀錄」「照明設計師的眼睛」都是敘事設定,不是可查核的經驗或專業。

### 9.2 必須揭露的情況(任一成立就要揭露)

| 情況 | 要不要揭露 |
|---|---|
| 帳號本身作為品牌行銷資產經營 | **要** |
| 內容中出現 SPACION 任何產品 | **要,而且是雙重揭露:虛構身分 + 商業關係** |
| 內容中出現他人產品且有付費關係 | **要** |
| 內容用於 Amazon listing、A+、廣告素材 | **要**(而且見 9.6:**不建議做**) |
| 內容用於 Kickstarter / 官網 / 任何募資或預購頁 | **要**(而且見 9.6:**不得以支持者或購買者身分出現**) |
| 內容用於付費廣告投放 | **要** |
| 圖片或影片是 AI 生成的 | **要,開平台的 AI 標示** |
| 純日常內容,無產品、無商業關係 | 帳號層級揭露仍保留(已寫在 bio) |

**影片:** 前三秒要有可見的標示,不能只放在說明欄。口播影片要口頭說出來。

### 9.4 法規依據(給 Marcus 覆核用,**合規判讀 `Estimated`,不是法律意見**)

- **FTC Endorsement Guides(16 CFR Part 255,2023 年修訂)。**
  修訂版把虛擬影響者(virtual influencers)納入「代言人」的範圍。核心要求:
  1. 代言必須反映代言人**真實的意見與使用經驗**。**一個虛構人物沒有使用經驗**,所以任何「我用過」的陳述都不成立。
  2. 代言人與品牌之間的**重大關聯(material connection)**要清楚且顯著地揭露。
  3. **專家代言**要求代言人真的具備宣稱的專業,而且判斷要用到那個專業。
     **一個虛構的照明設計師對一個充電器螢幕的評價,是虛構的專家代言。**
- **FTC Rule on the Use of Consumer Reviews and Testimonials(16 CFR Part 465,2024 年 10 月 21 日生效)。**
  明文禁止:
  1. 由**不存在的人**撰寫的評論或見證,**包括 AI 生成的**;
  2. 由**沒有實際使用經驗**的人撰寫、或錯誤呈現其經驗的評論或見證;
  3. 公司內部人員的評論未揭露關係;
  4. 買賣或操作社群影響力指標(假追蹤、假觀看)。
  違反可被處以民事罰款,**每一次違規分開計**(金額依通膨年度調整,2025 年約五萬多美元一次,`Estimated`)。
- **Amazon:** 社群規範與賣家行為準則禁止操作評論、禁止與賣家有利害關係者撰寫評論。**這個人物不得出現在 Amazon 評論、Q&A、或「這則評論有幫助」的投票裡。**
- **州法:** 華盛頓州消費者保護法(不公平或欺騙性商業行為)等州級規範同樣適用(`Estimated`)。
  部分州對廣告中的 AI 合成表演者(synthetic performer)有新的揭露立法,**細節與生效日請 Marcus 查證**,本檔不做判讀。
- Meta(Instagram、Threads)與 TikTok 的品牌內容政策要求開啟付費合作標記,兩個平台對擬真 AI 內容也有標示要求。
- **口徑:以上為依 2023–2026 年公開規範所做的合規判讀(`Estimated`),不是法律意見。投放前由 Marcus 覆核。**

### 9.6 SPACION 兩個品類專屬的風險(**這一段最重要**)

**產品時程(以企劃書為準,2026-10-14):** 桌面充電站台灣嘖嘖 2027 年 6 月中、**Amazon 美國 2027 年 10 月底上架**、美國另有 DTC 官網。
**企劃書沒有美國 Kickstarter 的計畫。** 車用手機支架沒有規格與時程(本輪只有研究報告)。**現在(2026 年 10 月)兩個產品都不存在。**

| 規則 | 說明 |
|---|---|
| **上市前,零提及** | 她不可能用過、看過、摸過一個還沒有的產品 |
| **不得宣稱「用過」「用了三個月」「畢業了」** | **她的招牌儀式是「剪吊牌 = 這個東西畢業了」。** 讓她剪 SPACION 產品的吊牌 = 虛構見證,而且是她最有說服力的那一種。**任何時間點都不行** |
| **不得說「這是 mockup 5 號」「這是對的那一個」「它通過了我的 twice list」** | 把她的失敗紀錄當第三方驗證 = 虛構的消費者見證(16 CFR 465) |
| **不得讓她出現在 Kickstarter / 官網的支持者、評論、留言、FAQ 發問、「已有 N 位支持」** | 虛構支持者 = 偽造評論與偽造社群指標 |
| **不得讓她出現在 Amazon 評論、Q&A、評論投票** | 同上,另違反 Amazon 規範 |
| **不得讓她以照明設計師身分評價任何 SPACION 的螢幕、燈號、色溫、眩光、金屬質感** | **虛構的專家代言。**「連照明設計師都說這個螢幕晚上不刺眼」是這個人物最危險的一句話 |
| **不得讓她講任何電氣、溫度、安規的判斷** | 她不是電機工程師。她只會說「我看有沒有標章」,**不可以變成「我確認它安全」** |
| **不得引用任何規格數字當成她的體驗** | 企劃書的 240W、單孔 140W、伸縮線 70 cm、各孔瓦數顯示是**目標規格,RFQ 未回** |
| **不得宣稱效期、壽命、耐用天數** | 例如「這個支架三個月都沒掉」「這條線用很久都不會壞」 |

| **她的四個 mockup 不得被改寫成競品攻擊** | 那四個是沒有牌子的便宜貨,**不對應任何真實品牌或 ASIN**。不得拿來做「別牌會掉,我們不會」的比較素材 |
| **她的「在找」不得與上市時程對齊** | 見 9.9 |

### 9.7 這個人物該退場的情況

1. 被平台判定為未揭露的虛擬人物並降權或停權。
2. 照明設計的專業內容被真的同行公開質疑,且無法回應。
3. 商業關係被揭露後,帳號的核心信任資產(第三節第 3 點「不推薦東西」)歸零。**這是最可能的死法。**
4. 內容比例失控:連續四週「東西怎麼壞」與產品相關內容超過 40%,她已經變成評測帳號了。
5. **她的「在找」被寫成公開連載,之後又「找到」任何品牌的產品。** 這條一旦發生,整個帳號回頭看都是鋪陳,要直接退場,不是補揭露。

### 9.8 商業化的實際建議(給 Owner 決策用)

**這個人物的價值來自「她不推薦,她只記得東西怎麼壞」。**

比較安全的用法(依風險由低到高):
1. **不發文,只當受眾校準工具。** Lena 與 Ivy 寫 SPACION 文案前,拿她的反感清單與話語紅綠燈(`16`)對一遍:
   「Tess 看到這句會不會說『這是 mood board』」。**價值最高、風險最低。**
2. **給 Nora 當判斷模型。** 她的購買條件與否決條件(`11 § 十`、`11 § 十一`)就是「高價接受、但要證據」這群人的檢查表。
   **拿來寫產品頁的「誰不適合買」、多孔分配表、相容車款清單**,比拿來寫推薦有用。
3. **把她的 cut sheet 清單當產品頁驗收表。** 上市前逐條對:有沒有尺寸、有沒有多孔同時插滿的分配、
   有沒有寫不適用的儀表板材質、顯示能不能關、替換零件買不買得到。**內部工具,她的名字不出現在任何對外素材。**
4. **品類教育內容,不提品牌。** 「為什麼你的支架會在冬天掉」「為什麼『最高 140W』不等於四個孔都有」。品牌只在 bio 的揭露裡。
5. **直接當代言人放進 Amazon 素材或募資頁:風險最高,不建議。** 她的人設有三條規矩跟這件事衝突(不推薦、不開箱、剪吊牌只給真的撐過的東西),再加上虛構見證與虛構專家代言。
