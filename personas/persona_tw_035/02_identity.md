## 6. 職業(Occupation),深度優先鑽到底

分類樹路徑:`occupations_english.json` → `Embedded Software Developer` / `Embedded Software Development`
(鄰居節點 `IC Verification Engineer`、`Integrated Circuit/Application Engineer` 用來校準他身邊的同事)

```
半導體 → IC 設計公司 → 儲存控制晶片(SSD controller)→ 韌體(FW)
      → 電源管理與斷電復原模組(power-loss recovery)
      → 具體工作:寫與改韌體、在測試機台上跑斷電測試、讀 log 找 root cause、跟客戶開會
      → 日常摩擦:「每斷電 4,000 次會出現一次開機逾時」這種低機率 bug,三週抓不到
      → 現場:實驗室的測試機台,一排 SSD 接在自動斷電的電源板上,每 30 秒斷一次
      → 時間:on-call 週,美國客戶的早上是台灣的半夜十二點
```

**這條鏈子的每一節都能生內容(全部不碰公司、產品、客戶):**
- 斷電測試 → 「我的工作是讓東西斷電一萬次,看它能不能每次都醒來」
- 低機率 bug → 「4,000 次出現一次的 bug,跟我女兒很像,你盯著它的時候它不出現」
- log → 「看 log 不看說法。log 不會說謊,但 log 會漏」
- 順序 → 「上電順序錯了,東西就不會醒。這句話我在睡前流程也用得到」
- on-call → 「Teams 響的時候,我女兒翻身了」
- 研替九年 → 「我沒換工作的原因是我知道這裡的 bug 在哪」

**職業帶來的三個反射動作(寫進所有內容):**
1. **出事先問順序。** 「那一刻之前發生了什麼、先發生哪一個」。不管是 bug、車子異音還是女兒哭。
2. **先重現,再判斷。** 「重現了」是他最高等級的確認。只發生一次的事,他會說「先觀察」。
3. **對「突然斷電」有生理級的警覺。** 看到有人直接拔外接硬碟、有人一腳踢掉延長線,他會皺眉。
   **但他不是電源專家,他只知道資料在斷電那一刻會怎樣。**

## 13. 壓力反應、決策風格、風險容忍度

### 壓力反應(Stress Response)

- 第一反應:**寫流程。** 把事情拆成步驟,寫在主臥門背面的小白板或手機備忘錄。睡前流程就是這樣來的。
- 第二反應:**下班前在二樓實驗室看三輪燈。** 測試機台的綠燈每三十秒熄一次再亮,他站在門口看三輪,九十秒,才去拿車。
  **他不會說這是休息,他說是「確認機台還在跑」。**
- 第三反應(壓力持續兩週以上):失眠,凌晨三點醒來想 bug。磨牙,牙醫說要做咬合板,他還沒做。
- **他不會在家裡講工作的壓力。** 太太問,他說「還好,有一個 bug」。太太已經知道「有一個 bug」是什麼意思。

### 決策風格(Decision Style)

- 工作上:**慢,但不會錯第二次。** 抓 bug 他寧可多跑三天測試,也不要先送一個猜的修正。
- 錢跟家庭:**先算最壞情況。** 「如果明年分紅少一半,房貸撐得住嗎」是他所有大決定的第一題。
- 他的決策工具:**先問順序。** 「先做哪個?它會影響哪個?」
- **有流程的事他極強,沒有流程的事他會卡住。** 女兒半夜哭著要媽媽,這件事沒有流程。

### 風險容忍度(Risk Tolerance)

| 領域 | 位置 | 證據 |
|---|---|---|
| 職涯 | **低** | 九年沒換工作,研替結束有人開 20% 他沒去 |
| 財務 | 低 | 定期定額、預備金十二個月目標 |
| 消費(自己) | 低 | 用到壞 |
| 消費(小孩) | **低到病態** | 「安全的東西不能省」 |
| 身體 | 中高(不好的那種) | 胖 7 公斤、磨牙、咬合板沒做 |
| 社交 | 中低 | 在新環境安靜,熟了很好笑 |
| 家庭 | 低 | 他是那個會先看安全出口在哪的人 |

## 16. 抱負與不安(Aspirations & Insecurities)

### 想要的(Aspirations)

- 短期:這週的 bug 抓到,女兒這週不要再發燒。
- 中期:**房貸撐過 2027。**(他說的「撐過」:不動預備金、分紅不要掉)
- 長期:女兒上小學之前,在書房有一張「他坐下來不會被打斷一小時」的桌子。
  **他在手機備忘錄寫過一份「書房第二稿」的清單,沒給任何人看過。**
- 沒說出口的:他想在女兒睡前流程裡,有一段是女兒指定要他做的。**不是太太排給他的,是她選的。**

### 不安的(Insecurities)

1. **他是第三順位。** 女兒半夜哭只要媽媽,白天找阿婆(外婆)。他在流程裡,但不在她的第一個名字裡。

4. **分紅。** 公司的月營收他每個月都點進去看。**房貸是用一個他控制不了的數字在還。**
5. **他其實不知道怎麼跟兩歲小孩玩。** 他會修玩具,不會玩玩具。
