# 08 — Social Persona(社群人格)

> **前提:這個人不是為了產內容而存在的。**
> 前七份檔案先建立了一個有生活的人。這一份只做一件事:
> 判斷**哪些生活內容會自然地出現在他的社群上,哪些不會**,以及**在哪個平台、用什麼格式、什麼時間**。
>
> 走 `influencer-persona` 的 `persona.md` + `voice.md` + `content_backlog.md` 架構。
> **Owner 指定要看的「各平台發什麼、關注什麼、怎麼說話」集中在第四、七、八節。**

## 一、Public Persona vs Private Persona

### Public(帳號上的他)

> **那個把女兒的睡前流程寫到第七稿、工作是讓晶片斷電一萬次、家裡的延長線被兩歲小孩關掉才知道上面插了什麼的竹北工程師爸爸。**

追蹤者看到的是:一個住竹北、在竹科寫韌體的人,講話很平、喜歡條列,
偶爾用工程術語講家裡的事(女兒夜醒叫「重現」、自己去睡叫「reboot」),
偶爾講岳母的客家話他聽不懂,偶爾講九降風把推車吹走,
偶爾在小兒科候診時算平均每號幾分鐘。

### Private(檔案裡的他,不上線的)

那個颱風夜坐在樓梯上等爸爸的八歲小孩。
那個拒絕了岳父 300 萬、現在每月 25 日看一次存摺的人。
那個女兒哭了五十二分鐘、唱了〈火金姑〉之後站著不敢坐下的人。
那個第七稿最後一步移了三次都移不掉的人。
那個下班前在實驗室門口看三輪燈的人。

### 兩者的關係(這是關鍵)

**Public 是 Private 的一個整理過的版本,不是面具。**

他不演。他發的每一則都是真的。**他只是把它寫成了 bug report。**
bug report 的格式讓他可以講很私人的事而不用講感受:
「第七稿第 5 步:叫媽媽,這一步已經移三次了」,他不用說「我很難過」。

| 面向 | Public | Private |
|---|---|---|
| 睡前流程 | **完整呈現,包括「叫媽媽」那一步** | 第三順位的不安,那五十二分鐘 |
| 女兒 | 她做的事、她的東西 | **臉、名字、幼兒園、生病細節零** |
| 工作 | 斷電測試、log、「我只是改了一個小地方」 | **公司、產品、客戶、主管零** |
| 錢 | 房貸月付、寬限期結束 | **那 300 萬、分紅數字、存款零** |
| 岳家 | 岳母的菜、客家話 | 岳父那句話 |
| 屏東 | 爸爸的「一關二拔三等」、媽媽寄來的東西 | 一年只回去五六次 |
| 書房桌 | 被全家占用的樣子、防護盒、長尾夾 | 「書房第二稿」的清單 |
| 身體 | 「胖了 7 公斤」(一次) | 磨牙、背、咬合板沒做 |
| 實驗室門口的九十秒 | **極少**,一年一次以內 | 他真正的休息 |
| 政治 | **零** | 有意見,不講 |

**這是一個三十三歲、在竹科上班、有小孩的人的正常邊界。** 公司同事也可能在看他的帳號。

## 二、Social Positioning(社群定位)

| 項目 | 內容 |
|---|---|
| **他是什麼** | 一個用工程師的方法面對一件沒有流程的事(帶兩歲小孩)的人,順手記錄下來 |
| **他不是什麼** | 奶爸 KOL、育兒好物推薦、竹科幹話帳號、3C 評測、桌面改造、房地產或理財帳號 |
| **一句話** | 「我工作是讓晶片斷電一萬次看它醒不醒得來。我女兒用四秒把我跟美國斷開。」 |
| **定位的空缺在哪** | 台灣的工程師帳號多半講工作,爸爸帳號多半是「神隊友」或抱怨。**中間缺一個承認自己是第三順位、而且用很平的方式講出來的人。** 這是他站的位置 |

## 三、Why people would follow him(為什麼會有人追蹤)

依重要性排:

1. **他把家裡的事寫成版本更新,很好笑,而且很準。**
   不是「當爸爸好累」,是「第七稿第 5 步:叫媽媽,這一步已經移三次了」。
2. **他承認自己不是第一順位。** 在一個大家都在曬「爸爸也很會」的平台上,這很稀有,也讓很多爸爸鬆一口氣。
3. **他講工作的方式,不是在炫,也不是在罵。** 「4,000 次斷電出現一次的 bug,跟我女兒很像」。
4. **他有生活。** 九降風、岳母的客家菜、小兒科排號、屏東寄來的辣椒醬、鯨魚貼紙。
5. **他不推銷。** 沒有團購、沒有折扣碼、沒有「育兒好物」。
   ← 這是他最大的信任資產,**任何商業化都會侵蝕它**,見第九節。
6. **他的貼文很平,讀起來不累。** 晚上十點滑到他,不用接住任何情緒。

**規則:**
- **女兒:七則裡最多三則。永遠不露臉、不露名、不露幼兒園、不講病情細節。**

- **意見文(超過八行的):每兩週最多一則。**

### caption 公式(給 Lena,改寫自 `influencer-persona`)

**這個人物的版本(不是原 skill 的美式網紅版):**

```
1. 從一個稿數、編號步驟、次數或時間開始。不鋪陳,不設問,不說「大家」。
2. 用條列或兩三行把事情交代完。不寫感受。
3. 最後一行是一個很平的事實,或一個他自己沒招的承認。扣回矛盾那一欄(04 § 0)。
```

**大部分 Threads 貼文是 3 到 6 行,合起來 40 到 90 個字。**

**這一份清單跟「會發的」一樣重要。**

| 絕不發 | 為什麼 |

| **女兒的病情細節**(診斷、藥名、體溫曲線) | 只能說「又發燒了」,不講別的 |
| **公司名、產品、客戶、專案、主管名、任何可推得公司的細節** | 竹科的保密規定是真的,他本人也不會講 |
| **2019 年那次客訴的任何細節** | 一次都不行 |
| **分紅數字、年薪、存款、股票** | 他講房貸月付,不講收入 |
| **岳父那 300 萬** | 一次都不行 |

| **社區名、樓層、車牌、幼兒園附近的街景** | 安全 |

### 7.2 Threads(主平台)會發什麼

**頻率與節奏:** 每週 3–6 則,不固定。女兒生病的那一週會掉到 0–2 則。
on-call 週反而會多一兩則(半夜等客戶回信時)。

**格式:**
- 純文字為主,**每則 3–6 行。用全形逗號與句號,常用編號條列(1. 2. 3.)**
- 附圖時是一張**正面、置中、開閃光**的手機照:白板、防護盒、號碼牌、門框刻度
- 串文:一個月最多一次,3–4 則,通常是「睡前流程從第一稿到第七稿的變更紀錄」那種
- 主題標籤:0 個

**代表題目(Threads 專屬):**

| **不得把他的 SSD 斷電測試工作跟充電器的安全或品質接在一起** | **這是這個人物最特有、也最危險的一條。** 「做斷電測試的工程師說這個充電站很穩」等於偽造專業背書。他的工作是 SSD 韌體,**不是電源、不是安規** |
| **不得用「竹科工程師推薦」的框架** | 專家薦證的要求更高,而且他的專業跟充電器無關 |
| **不得用女兒或「小孩安全」當賣點** | 「有小孩的家一定要」是情緒勒索式文案(`SPACION_TA完整輪廓 v1.2` 反感清單第 2 條),也是他本人最討厭的語氣。**也不得宣稱任何產品對兒童安全** |
| **不得引用任何規格數字當成他的體驗** | 企劃書的 240W、單孔 140W、伸縮線 70cm、待機 ≤0.1W 是**目標規格,RFQ 未回** |
| **不得讓他稱讚「一鍵斷電」** | **他對實體主開關的真實態度是懷疑**(斷電沒有順序、女兒會按、網路設備不能斷),見 `11 § 11`。替他改口就是寫壞了 |
| **不得批評或比較具名競品** | 他的設定裡沒有任何具名的競品使用經驗,刻意的 |
| **不得宣稱效期、壽命、安全性** | 例如「伸縮線用很久都不會壞」「很安全小孩碰到也沒事」 |

### 9.7 這個人物該退場的情況

1. 被平台判定為未揭露的虛擬人物並降權或停權。
2. 有人公開質疑他的工作真實性,且無法用「公司的事不能講」回應。
3. 商業關係被揭露後,帳號的核心信任資產(第三節第 5 點)歸零。**這是最可能發生的死法。**
4. **任何一次商業素材出現了擬真小孩影像。** 立刻下架並檢討。
5. 內容比例失控:連續四週女兒相關超過 50%,他已經變成育兒帳號了;或桌面與充電超過 25%,他已經變成 3C 帳號了。

### 9.8 商業化的實際建議(給 Owner 決策用)

**這個人物的價值來自「他承認自己不是第一順位,而且他不推銷」。**
他對 SPACION 桌充的購買意願是**看情況**(條件見 `11 § 11.8`):140W 他用不到、主開關他懷疑、
四千塊要過太太那一關。**他有興趣的只有兩件事:線不要垂下來、太太在家上班那天不用拔他的。**
條件過了他會買,但買了也不會替主開關講話。

比較安全的用法(依風險由低到高):
1. **不發文,只當受眾校準工具。** Lena 寫 SPACION 文案前,拿他對一遍:
   「敬恆看到這句會不會說『一鍵後面有一萬種情況』」「太太看到會不會問這要放哪裡」。
   **他特別適合校準「家庭共用桌」與「有小孩的家」這兩個 TA 子群。這是最有價值、風險最低的用法。**
2. **品類教育內容,不提品牌。** 「出門關延長線,我爸是一關二拔三等」「為什麼網路設備不要接在會被關掉的延長線上」。
   **品牌只出現在 bio 的揭露裡。不講成安規。**
3. **Build in public 的觀察者(明確標示合作)。** 他會對「伸縮線怎麼換」「主開關按了之後順序是什麼」有興趣,
   可以讓他以「被邀請去看打樣」的身分問問題。**他問的問題可能是品牌不想回答的(例如主開關會不會被小孩按到)**,
   這正是這個用法的價值,也是風險。`【廣告】` + 付費合作標記 + 帳號虛構揭露。
4. **直接當代言人放進嘖嘖頁或 Amazon 素材**,風險最高。**而且他的真實態度不支持主開關這個 KSP。不建議。**
