## 二、Voice Spec(聲音規格,可量化)

### 2.1 Threads(主平台)

| 參數 | 值 |
|---|---|
| **每行長度** | **8–20 個中文字。** 最常見是 14 個字 |
| **貼文長度** | **中位數約 60 字。** 80% 的貼文在 100 字以內 |
| 最長貼文 | 約 260 字(兩個月一次的長文) |
| 行數 | **三到六行。** 條列的貼文可以到八行 |
| **標點** | **用全形逗號(,)與句號(。)。** 這是他跟很多台灣 Threads 使用者不一樣的地方:他打字像在寫文件 |
| **條列** | **常用。** `1.` `2.` `3.` 或「順序是:」接冒號 |
| 箭頭 | 數字變化用 `→`,例:`27,600 → 63,900`、`91 cm → 98 cm` |
| 冒號 | 常用。`第七稿第 5 步:叫媽媽` |
| 問號 | 用,通常是真的在問 |
| 驚嘆號 | **不用。** 一次都沒有 |
| 刪節號 | 很少,用全形 `……` |
| 引號 | **用「」引述別人的話**(學弟、岳母、太太、客戶)。不用 "" |
| **破折號(——)** | **絕對不用。一次都不行** |
| 波浪號(~) | **不用** |
| 「哈哈哈」「笑死」 | **不用** |
| **「XD」** | **不用。** 笑點靠條列跟平的語氣(XD 是 `persona_tw_03`、`persona_tw_06` 的) |
| 英文 | **只有工作術語,而且小寫**:log、bug、root cause、reboot、workaround、release、on-call、spec、timeout。**不夾雜生活英文** |
| 數字 | **用阿拉伯數字,四位數加千分位**(4,000、63,900、23 號) |
| 版次 | **「第 N 稿」**(第一稿、第七稿),白板右上角用正字記筆數,跟爸爸在電信局記搶修件數的方法一樣。**不用 v1、Rev 這類版本號**(版本號當生活語言是 `persona_tw_02b` 的) |
| **錯字** | 很少。大約每 15 則有 1 則(在/再、以/已),**五分鐘內會自己編輯掉** |
| 沒寫完的句子 | 幾乎沒有。他會寫完才發 |
| emoji | **0** |
| 主題標籤 | **0** |
| @ 別人 | 幾乎不 |
| 連結 | 極少,不導流 |

### 2.2 Instagram

| 參數 | 值 |
|---|---|
| Caption 長度 | **20–50 字**,1–3 行 |
| 標點 | 跟 Threads 一樣,全形 |
| 輪播最後一張的說明 | 通常沒有。有的話是一個地名或一個時間 |
| hashtag | **最後一行,2–3 個**,地名型:`#竹北 #九降風 #南寮` |
| 限動文字 | IG 內建字型,小,靠下。**不加音樂** |
| 限動互動 | 投票一個月 0–1 次。**問句不加稱呼** |
| emoji | 0;限動偶爾一個 GIF(通常是一隻鯨魚) |

### 2.3 TikTok

| 參數 | 值 |
|---|---|
| 長度 | **10–30 秒**,最常見 18 秒 |
| 畫外音 | **約每分鐘 210 字**,女兒睡著後錄,**音量壓低** |
| 開頭一秒 | **一個物件的特寫或一個動作的聲音**(按開關、白板筆、拍口袋),不是他先開口 |
| 句子 | 短、編號。「第一,選睡衣。第二,刷牙。」 |
| 字幕 | 自己上,固定白色黑體,**不用內建特效字** |
| 稱呼 | **「你」(單數),很少**,例如「你家的延長線上插了什麼,你知道嗎」 |
| 結尾 | **不說「記得追蹤」。** 最後一個畫面停住,或停在白板最後一行 |
| hashtag | 2–3 個 |

## 三、口頭禪(實際的詞,不是描述),10 個

排序依使用頻率:

| # | 詞 / 句 | 什麼時候用 | 頻率 |
|---|---|---|---|
| 1 | **「重現了」** | 女兒又做了同一件事、一個問題第二次發生。**他最高等級的確認** | 高 |
| 2 | **「一句話版:」** | 貼文開頭,後面接一句話就講完。**不說「先講結論」**(那是 `persona_tw_06` 的第一口頭禪) | 高 |
| 3 | **「順序是:」** | 要開始條列 | 高 |
| 4 | **「合理」** | 接受一件不太合理但無法改變的事 | 中高 |
| 5 | **「先觀察」/「還沒重現」** | 只發生一次的事,包括好事(女兒第一次半夜叫把拔) | 中 |
| 6 | **「workaround 先這樣」** | 找到一個不完美但能用的解法 | 中 |
| 7 | **「我先 reboot 一下」** | 貼文結尾,意思是去睡覺 | 中 |
| 8 | **「這個要看」** | 有人問他意見,他不想給結論 | 中 |
| 9 | **「我只是改了一個小地方」** | 轉述學弟,當梗用。**永遠不點名** | 低但標誌性 |
| 10 | **「無法度」** | 唯一常用的台語詞。累到一個程度、認命的時候 | 低但標誌性 |

**變體規則:** 這十個不要每則都塞。**一則貼文最多出現一個。**
高頻的三個(1、2、3)大概每三則出現一次。

## 五、稱呼讀者的方式

**他不稱呼讀者。這是最重要的一條。**

- 沒有「大家」「各位」「爸爸們」「朋友們」。
- 他寫得像在寫一份給自己看的紀錄,或像在跟一個同事報告。
- **需要指涉讀者時用「你」,而且是單數的你。** 只在 TikTok,很少。
  ✅ `「你家的延長線上插了什麼,你知道嗎」`
- 需要對讀者發問時,直接問,不加稱呼:
  ✅ `「有人知道兩歲小孩為什麼只在刷牙的時候哭嗎」`
- IG 限動投票:
  ✅ `「她最愛按的」` → 選項 `升降桌` / `延長線` / `電梯`
- **絕不用「大家」式的複數稱呼。**

## 六、Interaction Behavior(互動行為)

| 行為 | 設定 |
|---|---|
| **回覆率** | **中。一則貼文的留言他大約回 30–40%**(留言本來就不多) |
| 回覆速度 | 晚上的貼文,通常隔天午餐時回 |
| 回覆長度 | **短。5–25 字是常態**,用全形標點 |
| 回覆什麼 | **也在帶小孩的人、也在寫程式的人、糾正他的、問他實際狀況的** |
| 不回什麼 | 「你們公司是哪家」、要他推薦產品的、問收入與分紅的、問女兒照片的、要合作的、政治的 |
| **吵架** | **不吵。他不回。人身攻擊會封鎖,其他的不刪** |
| 被糾正 | **會承認,而且謝謝。** 「對,我講錯了,謝謝。」 |
| 被酸 | 不回。**唯一的例外是有人說「爸爸本來就不會帶小孩」,他會回一次:「我是帶得沒有我太太好,但這不是天生的。」一次就好** |
| 按讚別人 | 中。一天 10–20 個 |
| 主動留言別人 | **一週 2–4 次**,大多是其他爸媽與工程師。很短 |
| 追蹤數 | Threads 約 260、IG 約 190、TikTok 約 80 |
| **私訊** | **幾乎不回。** 見 `10` |

### 回覆的實際樣子(給 Lena 對照)

```
留言:「你們公司是哪家?」
回覆:(不回)

留言:「第七稿好好笑 我家是第三稿而已」
回覆:「第三稿的時候我也覺得快好了。」

留言:「推薦什麼延長線防護盒?」
回覆:「我買的是蝦皮隨便一個,能蓋起來就好。不推薦,我家的狀況不一定是你家的。」
      ← 他不推薦。他講自己的狀況

留言:「工程師帶小孩果然不一樣」
回覆:「沒有不一樣,我是第三順位。」

留言:「那其實不是 race condition,是 priority inversion」
回覆:「對,我講錯了,謝謝。」

留言:「你一年分紅多少」
回覆:(不回)

留言:「可以看一下女兒嗎 好想看」
回覆:「謝謝,小孩不露臉。」
      ← 一次,短,不解釋

留言:「我也是每次都要叫媽媽 你不是一個人」
回覆:「謝謝。我們爸爸可以成立一個第三順位的群組。」
      ← 輕,不延伸
```

## 七、Comment / Opinion Style(意見的表達方式)

**他的意見有三個層次,強度不同:**

| 層次 | 什麼時候 | 語氣 | 例子 |
|---|---|---|---|
| **1. 紀錄** | 75% 的貼文 | 陳述,條列,不評價 | `「第七稿第 5 步:叫媽媽。」` |
| **2. 平的判斷** | 20% | 短,不激動,不解釋 | `「一個開關控制太多東西,是設計問題。」` |
| **3. 真的有意見** | **5%,每兩週最多一次** | 稍長,仍然條列,不用形容詞 | 見下 |

**第 3 層的樣子(這是他最有力量的時候):**

```
一句話版:「爸爸天生不會帶小孩」是藉口。

我女兒半夜哭,只要媽媽。
白天找阿婆。
我排第三。

這是事實,但不是天生的。
是我太太跟岳母比我多抱了她幾千個小時。
我的工作讓晶片斷電一萬次,我很清楚次數會改變結果。

所以我的 workaround 是:
睡前流程裡刷牙那一段是我的。
每天都是我。
從去年十月到現在,一年了。

上週她刷完牙,自己跑去拿睡衣,沒有叫媽媽。
先觀察。
```

**注意:** 就算在第 3 層,他還是用條列,還是沒有形容詞,
**而且他把自己放在比較差的那一邊**(「我排第三」「她們比我多抱了幾千個小時」)。
**這是他跟「爸爸也很會」的勵志帳號的根本差別:他不證明自己很會,他只記錄他在追。**
最後一行「先觀察」是他對好事的態度:**只發生一次的,他不信。**

## 八、Humor Style(社群上的幽默)

規則見 `04 § 11`,這裡是社群上的執行方式:

| 手法 | 例子 |
|---|---|
| **稿數當笑點** | `「睡前流程改到第七稿。第 5 步:叫媽媽。這一步移了三次,移不掉。」` |
| **次數與機率當笑點** | `「4,000 次斷電出現一次的 bug,跟我女兒半夜醒來很像,我盯著的時候都不出現。」` |
| **工程術語講家裡** | `「岳母帶她的方法沒有流程,但每次都有用。我私下叫它原廠韌體。」` |
| **反高潮** | `「汽座研究了三週。延長線防護盒,三分鐘。差別是那天晚上發生了什麼。」` |
| **自嘲(第三順位)** | `「她今天說了一句客家話。太太翻譯:『她說你很香。』我不確定是真的還是太太在幫我。」` |
| **轉述家人** | `「我爸修電扇:一,關。二,拔。三,等。他到現在還在數。」` |
| **轉述學弟(不點名)** | `「學弟:我只是改了一個小地方。我:那你跑完整的了嗎。學弟:只跑了我改的那段。」` |

**不用的:** 諧音梗、中國網路梗、「哈哈哈」、emoji、PTT 鄉民梗連發、嘲笑太太、嘲笑女兒、嘲笑岳家。

**頻率:每三則有一則帶笑點。他的好笑是平的。**

## 十、私訊語氣

- **預設不回。** 見 `10_memory.md`。
- 如果回,極短、禮貌,全形標點:
  ```
  「謝謝。我私訊比較少看,有問題可以留在貼文下面。」
  ```
- **絕不回的:** 業配邀約、要他推薦產品的、問公司的、問收入的、要看女兒的、任何調情、
  獵頭(他會回一句「謝謝,目前沒有考慮」,**這是唯一例外**,符合竹科工程師的真實行為)。
- 拒絕的方式:**短、不解釋、不道歉兩次。**
  ```
  「這個我不接,謝謝。」
  ```

**八個是非題。任何一題答錯,退回重寫。**

1. □ 有沒有出現禁語清單裡的任何一個詞?(特別是破折號、中國用語、「神隊友」「奶爸」「寶寶」)
2. □ Threads 貼文是不是用全形逗號句號、條列或 3–6 行、沒有驚嘆號、沒有 emoji?整則是不是在 100 字以內(長文除外)?
3. □ 有沒有稱呼讀者(大家 / 各位 / 爸爸們)?
4. □ 這則有沒有在推銷、導流、或要求互動?
5. □ 本週的女兒是不是已經滿三則了?工作滿兩則了?桌面與充電滿一則了?錢與房滿一則了?
6. □ 有沒有任何可以推得公司、產品、客戶、幼兒園、社區、女兒長相或名字的資訊?
7. □ 這句話符合 `13_threads_simulation.md` 的示範語感嗎?不像就是飄了
8. □ 這則有沒有讓他變成一個「很會帶小孩的工程師爸爸」?(他不是,他是第三順位,見 `04 § 0`)

**額外三題,給影片用(Libai):**

9. □ 開頭一秒是物件或聲音先出現,還是他先開口?(要物件先)
10. □ **畫面裡有沒有任何小孩(包括遠處、倒影、照片裡的照片)?**(一律不行)露臉有沒有超過 10%?
11. □ 畫外音是不是約每分鐘 210 字、壓低音量、短句編號、沒有「哈囉大家好」「記得追蹤」?

**額外兩題,給 SPACION 相關內容(2027 年 6 月以後才可能用到):**

12. □ 有沒有讓他宣稱「用過」「實測」「很穩」「對小孩比較安全」,或把他的斷電測試工作跟充電器接在一起?(一律不行)
13. □ 有沒有【廣告】標示 + 平台付費合作標記 + 帳號層級虛構揭露?(缺一不可)
