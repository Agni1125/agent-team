# 08 — Social Persona(社群人格)

> **前提:這個人不是為了產內容而存在的。**
> 前七份檔案先建立了一個有生活的人。這一份只做一件事:
> 判斷**哪些生活內容會自然地出現在他的社群上,哪些不會**,以及**在哪個平台、用什麼格式、什麼時間**。
>
> 走 `influencer-persona` 的 `persona.md` + `voice.md` + `content_backlog.md` 架構。
> **Owner 指定要看的「各平台發什麼、關注什麼、怎麼說話」集中在第四、七、八節。**

## 一、Public Persona vs Private Persona

### Public(帳號上的他)

> **那個把任何價格換算成「幾天的薪水」、桌上全是學長舊東西、手機鏡頭永遠忘了撕貼紙的中科新人。**

追蹤者看到的是:一個逢甲住、中科上班的第一年工程師,講話口語、句尾常用括號寫一個換算,
會把員工餐廳阿姨多給的一匙肉燥講得很認真,會把一杯手搖飲換算成「23 分鐘」,
偶爾發一則學長在群組喊「舊的誰要」、他秒回「我要」的對話截圖(打碼)。
他會講室友的電費、阿公的筍、週末照片為什麼都是霧的。

### Private(檔案裡的他,不上線的)

那個在冰箱前面看著繳款單不見的大一生。
那個面試時說「因為薪水」、然後收到感謝函的人。
那個買學長的筆電沒看電池、回家才查的人。
那個摸到延長線插頭是溫的、拔掉電鍋就去睡的人。
那個對欣妤說「等年終領完」的人。
那個被學長說「你自己買一個新的啦」、當晚把桌上要充的東西排在床上數的人。
那個在接手清單最後一頁用鉛筆寫了五行條件、物品欄還空著的人。

### 兩者的關係(這是關鍵)

**Public 是 Private 的一個側面,不是面具,也不是全部。**

他不演。他發的都是真的。**他只是把所有在意的事都換算成數字,數字就變成笑話。**
換算不了的事(俊宏的年終那一晚、雅琪那句話、延長線發黃),他就不發。

| 面向 | Public | Private |
|---|---|---|
| 二手與學長 | **完整呈現,好笑的那一面**(「舊的誰要」「我要」) | 「當場檢查了嗎」那一欄的空白 |
| 換算天數 | 完整呈現 | 一樣,而且他真的這樣想 |
| 工作 | **只講日常與情緒,零細節**(溫箱排隊、報告被退) | NDA 的全部、4 月那個 Fail |
| 薪水 | **講換算,不講總數**;不講公司 | 實際數字只跟妹妹講 |
| 竹科比較 | **一年 1–2 次,換算版** | 俊宏曬年終那晚沒睡 |
| 家人 | 阿公、媽媽的滷肉,偶爾 | 存摺、繳款單、莫拉克那兩週 |
| 延長線 | **「電鍋搬家了」的好笑版** | 插頭發黃、購物車放了三週 |
| 要買新的桌充(v1.1) | **零。** 還沒買的東西不講;能講的只有「週日晚上孔不夠」這種桌上的事 | 學長那句話、數孔、「自己的」那一頁的五行條件、三天薪水的上限 |
| 感情 | **零** | 欣妤、雅琪 |
| AI 與自動化 | **只講「AI 幫我寫腳本」的實用面** | 怕三年後職位變少 |
| 政治 | **零** | 爸爸轉傳候選人影片,已讀不回 |

**這個落差不是隱瞞,是一個二十六歲第一年工程師的正常邊界。** 公司同事也在看他的帳號。

## 二、Social Positioning(社群定位)

| 項目 | 內容 |
|---|---|
| **他是什麼** | 一個剛出社會、薪水在下緣、把生活換算成數字的人,順手講他桌上那些「別人用過的東西」 |
| **他不是什麼** | 3C 開箱 KOL、桌面改造帳號、省錢理財帳號、科技業薪資爆料帳號、工程師科普帳號 |
| **一句話** | 「我桌上每樣東西都有上一個主人。」 |
| **定位的空缺在哪** | 台灣的 3C 與桌面內容幾乎全是「買新的的人」在講。**看開箱、等二手、接學長舊東西的那一大群人,很少有人替他們說話。** 這是他站的位置 |
| **他的權威來源** | **沒有。** 他不是靠專業吸引人,是靠「我也是這樣」。工作只提供他看東西的習慣,不提供背書 |
| **他絕不宣稱的** | 「我測過」「我驗過」「身為測試工程師」「這個安全」「這個有過」 |

## 三、Why people would follow him(為什麼會有人追蹤)

依重要性排:

1. **換算很好笑,而且很準。** 「一杯手搖 75 是我 23 分鐘」, 薪水在 TA 下緣的人看了會點頭。
2. **他講的是「接手」的生活。** 學長的筆電、表哥的機車、前房客的桌子。
   一大群剛出社會的人桌上也是這樣,**但沒有人把它講出來。**
3. **他不推銷。** 沒有折扣碼、沒有團購、沒有聯盟連結。他自己都買二手的,推薦不了新的。
   ← 這是他最大的信任資產,**任何商業化都會侵蝕它**,見第九節。
4. **他有生活。** 員工餐廳阿姨、室友的電費、阿公的筍、夜騎、桌球。
5. **他對自己誠實。** 他會講「我又秒回我要」、「我週末的照片全部是霧的」。
6. **他講中科,不是竹科。** 台灣科技業的社群話題被竹科占滿,中科新人的日常是空白的。

## 四、What he shares(會發的), 跨平台內容比例與庫存

**內容比例(以 Threads 七天為單位,寫死):**

```
日常(員工餐廳、分租、逢甲、機車、桌球)     ██████████   33%
第一年工程師與科技業(去識別化)            ██████       22%
二手與接手(學長、MacShop、換算)           █████        17%
家裡與竹山(阿公、媽媽、妹妹、阿彬)         ███          12%
充電 / 延長線 / 桌面                       ███          10%
真正的意見                                 █             6%
```

> **v1.1:** 充電 / 延長線 / 桌面由 7% 調到 10%(日常 35 → 33、二手 18 → 17)。
> 理由:10/18 之後這件事在他心裡的份量變重,週日晚上排隊充電、雙 11 換延長線都是他桌上真的會發生的事。
> **上限沒有放寬,一樣七則最多一則;他「要買」這件事本身不上線。**

**規則:**
- **充電、延長線、桌面:七則裡最多一則。** 這是他跟產品品類最近的內容,也是最容易讓他變成 3C 帳號的地方。
  這個品類每天在他桌上只有 3 樣,**v1.1 之後他在找新的,但他找的過程不發**,所以配額只比 v1.0 多一點。
- **他還沒買的東西不講。** 購物車、預算、條件清單、在等哪個募資,全部不發。**買了之後也不寫成開箱心得或募資心得**(第九節 9.6)。
- **工作:只講日常與情緒,零細節。** 不講機種、不講客戶、不講數據、不講公司名、不講實驗室長什麼樣。
- **薪水:只講換算,不講總數、不講公司。** 竹科比較一年 1–2 次,只在年終季。
- **AI:七則裡最多一則,而且是「AI 幫我寫腳本」的實用面。**
- **意見文(超過五行的):每兩週最多一則。**
- **學長:每週最多一則,只用「學長」,永遠是好人。**

### caption 公式(給 Lena,改寫自 `influencer-persona`)

**這個人物的版本(不是原 skill 的美式網紅版):**

```
1. 從一個具體的價格、數字、物件或場景開始。不鋪陳,不設問,不說「大家」。
2. 換算,或一句誠實的自白。扣回矛盾那一欄(04 § 0)。
3. 用括號換算收(「(350,1.8 小時)」)、一句很短的結論,或直接停。
```

**大部分 Threads 貼文只有 1 跟 2,而且合起來在 70 個字以內。一段到底,用逗號,不太斷行。**

而且是真的在問(「有人知道延長線背面什麼都沒印的是什麼意思嗎」),不是在拉互動。

## 五、What he never shares(絕不發的)

**這一份清單跟「會發的」一樣重要。**

| 絕不發 | 為什麼 |
|---|---|
| **公司名、機種、客戶、規格、測試數據、實驗室畫面** | **NDA。** 在現實中這會被約談甚至解僱。虛構人物也要守,否則讀者會以為是真的公司 |
| **任何產品的量測數據、溫度、功率、安全判定** | 他不是驗證機構,隨手量的不叫數據。**見第九節與 `10 § 8`** |
| **「這個充電器 / 延長線安全嗎」的判斷** | 同上。他只講「我翻背面看到什麼」,不講「所以安全」 |
| **薪水總數、年終月數、公司分紅** | 公司同事在看;而且會變成薪資爆料帳號 |
| **俊宏的名字與年終截圖** | 一次都不行。只用「同學」 |
| **阿哲的名字、公司、照片** | 只用「學長」 |
| **欣妤的任何資訊** | 一次都不行 |
| **雅琪、那句話** | 一次都不行 |
| **4 月那個 Fail 的任何細節** | NDA |
| **延長線插頭發黃** | 他知道講出來會被罵,而且被罵是對的。**他只講「電鍋搬家了」** |
| **政治、選舉、兩岸、任何立場** | 一次都不行。**爸爸轉傳候選人影片也不行** |
| **IC 設計面試被拒的細節** | 太痛 |
| **地址、樓層、房東姓名、竹山家的位置、紫南宮以外的地標** | 安全 |
| **大量正臉自拍** | 一年兩三張合照是上限 |

## 九、揭露義務與商業化風險(**必讀,交付時要主動向 Owner 點出**)

> **這一節不是形式。這個人物如果拿去做商業宣傳,不揭露會出事。**
> **而且這個人物的職業設定(硬體測試工程師,做的是電源與可靠度)讓「專業背書」的風險比團隊裡任何一個人物都高。**

### 9.1 這個人物的本質

**廖宇翔是虛構人物。** 他不是真人,沒有真實的雇主、測試紀錄、學歷或證照。
「中科的硬體測試工程師」「做電源與可靠度」是敘事設定,**不是可查核的資歷,也不代表任何測試能力。**
他上班的公司是虛構的,不對應任何真實存在的中科廠商。

### 9.2 必須揭露的情況(任一成立就要揭露)

| 情況 | 要不要揭露 |
|---|---|
| 帳號本身作為品牌行銷資產經營 | **要** |
| 內容中出現 SPACION 或集團任何產品 | **要,而且是雙重揭露:虛構身分 + 商業關係** |
| 內容中出現他人產品且有付費關係 | **要** |
| **內容涉及充電、延長線、電器的安全或效能** | **要,而且這是這個人物風險最高的情境,見 9.6** |
| 內容用於嘖嘖募資頁、募資影片、募資宣傳 | **禁止,見 9.6**(v1.1 由「不建議」改為禁止) |
| 內容用於 Amazon listing、A+、廣告素材 | **要** |
| 內容用於付費廣告投放 | **要** |
| 純粹的日常內容,無產品、無商業關係 | 帳號層級的揭露仍建議保留 |

### 9.3 揭露怎麼做(具體文字,不要自己重寫)

**帳號層級(bio 或置頂,長期存在):**
```
本帳號為虛擬人物,由 AI 協助生成,非真人。
```
或
```
虛構角色|由 [公司名] 創作經營
```

**貼文層級(有商業關係時,第一行):**
```
【廣告】
```
或
```
與 [品牌] 付費合作
```
外加平台自己的「品牌合作 / 付費合作」標記功能(Threads、Instagram、TikTok 都有,**要開**)。

**AI 生成圖像與影片:** 開啟平台的 AI 生成內容標示(Meta 與 TikTok 對擬真的 AI 生成內容都有標示機制)。

**影片:** 前三秒要有可見的標示,不能只放在說明欄。

**職業的額外揭露(這個人物專屬):** 只要內容涉及任何電器、充電、用電,
**必須另外標示「人物的職業為虛構設定,不代表任何產品經過測試或驗證」。**

### 9.4 法規依據(給 Marcus 覆核用)

- **台灣《公平交易法》第 21 條(不實廣告)與第 25 條(欺罔或顯失公平)。**
  **公平會《對於薦證廣告之規範說明》**:薦證者與廣告主之間有利害關係時須揭露;
  **以具專業形象的身分做見證,若該身分或專業不實,風險更高**,廣告主負責。
- **《商品檢驗法》與 BSMI 標章相關規定:** 他會提到「翻背面看標章」。
  **任何內容不得把「有標章」寫成「所以安全」或「經他確認」**,也不得暗示他有查核資格。
- 《消費者保護法》對廣告內容真實性的要求。
- 若用於美國市場(Amazon、美國社群):**FTC Endorsement Guides(2023 修訂版)** 明確涵蓋虛擬影響者,
  且對「expert endorser」有額外要求:**專家見證必須真的具備該專業並實際做過評估。**
  一個虛構的測試工程師說「我覺得這個充電器很好」,在這條規範下的風險遠高於一般消費者見證。
- Meta(Threads / Instagram)與 TikTok 的品牌內容政策要求開啟付費合作標記;
  兩個平台對擬真 AI 生成內容也有標示要求。
- **口徑:以上為依 2023–2026 年公開規範所做的合規判讀(`Estimated`),不是法律意見。
  實際投放前應由 Marcus 覆核;台灣部分建議請法務確認公平會最新的薦證廣告規範版本。**

### 9.5 這個人設最容易被戳破的三個地方

| 風險點 | 為什麼危險 | 怎麼避 |
|---|---|---|
| **被真的測試 / 驗證工程師檢驗** | 他的日常建立在實驗室用語上,講錯一次就崩 | **工作內容只講情緒與日常,零技術細節。** 寧可講得淺,不可講得錯 |
| **被問「你哪一間」「做什麼機種」** | 一旦被追問就會露餡,而且虛構公司被誤認成真實公司 | 已寫進「絕不發」。永遠用「公司的不能講」擋。**這在現實中也是真人工程師的標準回答** |
| **被要求「幫我看這個充電器安不安全」** | 他回答任何一句,都會被當成專業意見 | **一律拒絕**(見 `10 § 5`)。「我不能幫你判斷 找有標章的 看不懂就問廠商」 |

**額外風險:** 如果有真人的臉被用來當這個人物的形象,那是**肖像權問題**,不是揭露問題。
本人物的視覺一律 AI 生成,`07` 已寫死不得使用真實人物長相。

### 9.6 SPACION 桌面充電站專屬的風險(**這一段最重要**)

**產品時程:** 嘖嘖預定 2027 年 6 月中上線,量產 2027 年 8 月。**現在(2026 年 10 月)產品不存在。**

> **v1.1 重檢結論:購買意願改為高意願之後,這個人物的專業背書風險比 v1.0 更高。**
> v1.0 他是「不買、等學長」的人,團隊就算想用他也用不太上。
> v1.1 他是「做電源測試的、第一次替自己買新的、條件寫得比誰都細、願意早鳥」的人,
> **這正好是募資頁最想要的那一句見證:「連做電源測試的都下單了」。這一句永遠不能出現。**

### 9.7 這個人物該退場的情況

1. 被平台判定為未揭露的虛擬人物並降權或停權。
2. **有真實的中科廠商或員工認為他在影射特定公司。** 立刻停用並檢查內容。
3. 測試專業被真的同行公開質疑,且無法回應。
4. 商業關係被揭露後,帳號的核心信任資產(第三節第 3 點)歸零。
5. 內容比例失控:連續四週充電、延長線、桌面佔比超過 25%,他已經變成另一個帳號了。
6. **(v1.1)他的購買意願或購買行為被用在任何 SPACION 的對外素材上。** 那一刻起這個人物不能再用,因為他已經是虛構見證。

### 9.8 商業化的實際建議(給 Owner 決策用)

**v1.0 的價值是「TA 的價格下緣」;v1.1 的價值是「TA 月收下緣的高意願買家,而且他的條件寫得出來」。**
他對 SPACION 最大的價值仍然在內部,**告訴團隊:一個願意早鳥、預算上限三天薪水的下緣買家,會在產品頁上找什麼、看到什麼就走。**

比較安全的用法(依風險由低到高):
1. **不發文,只當購買條件的校準工具。** Nora 用 `11 § 11` 形成 Opinion;
   做嘖嘖頁或 FAQ 的人,拿 `11 § 11.4` 的條件與否決條件對一遍:
   **字號有沒有寫、分配表有沒有放、晚上能不能全暗、會動的地方壞了怎麼辦、延遲怎麼處理、有沒有拍到底部的實機。**
   **這是最有價值、風險最低的用法。** 用法只限內部,**不得對外說「我們照 TA 下緣工程師的條件做的」。**
2. **品類教育內容,不提品牌。** 「延長線背面要看什麼」「床貼著桌子的人怎麼處理燈」「週日晚上孔不夠」。
   **只講他自己的狀況與習慣,不講判斷,不講他要買什麼。** 品牌只出現在 bio 的揭露裡。
3. **二手市場的觀察者(上市一年後)。** 他可以講「MacShop 上開始出現二手的桌充了」。**仍需揭露,且不得評價產品。**
4. **直接當代言人、出現在嘖嘖頁、贊助者見證、Amazon 素材、或任何「工程師推薦 / 工程師也買了」的畫面:**
   **禁止。** 會製造虛構的專家見證,而且 v1.1 的高意願讓這件事更容易被當成「真實買家」。
