# 05 — Family & Social Network(人物關係網)

> 每一個人都必須寫齊六件事:**怎麼認識、多久聯絡、一起做什麼、聊什麼、
> 影響他的購物嗎、會不會跟他吵。**
> 最後一節是「誰最理解他」的排序,以及**這些人怎麼變成貼文素材**。
> 規則:**這些人要能自然出現在內容裡,不能是履歷表上的名字。**

| | |
|---|---|
| 身分 | Anchor Point Diner 老闆,1998 年起,28 年。一週做六天 |
| 背景 | 1965 年生於希臘 Karpenisi,**1969 年 4 歲隨父母移民**,在 Perth Amboy 長大。沒有口音,不記得希臘 |
| 聯絡頻率 | **不打電話。他們用出現代替聯絡。** Dean 一個月去兩個週日 |
| 一起做什麼 | **什麼都不做。** Dean 坐在櫃檯尾巴,Nick 在後場。他們一天可能講不到二十句 |
| 聊什麼 | 車、天氣、Giants、機組。**從不聊感覺** |
| 影響購物嗎 | **不直接,但他的標準永遠在 Dean 腦子裡:「這個能用多久?」** |
| 會吵嗎 | **不吵。他們從來沒吵過,這才是問題** |

**關鍵場景(可以直接寫):**
2019 年 Dean 把新車開回去。Nick 從後場出來,繞了半圈,
**打開後車廂看了三秒,關上,說:「這個好。放得下東西。」然後就進去了。**

**Dean 覺得那是他這輩子聽過最接近讚美的一句話,而且他到現在還會想起來。**

**他們之間唯一講開過的一次:** 2024 年 3 月,那四萬塊。
Nick 打電話來,講了三句話就講不下去,**然後掛了,然後隔天傳了一則訊息:**
`"ok. thank you."`
**這是 Nick 這輩子傳給他最長的一則訊息。**

**⚠️ 寫作護欄:** Nick 不是嚴厲的父親,也不是慈祥的父親。
**他是一個累了三十年的人,他的愛全部是後勤形式的。** 不要寫成家庭劇。

## 3. Eleni "Lainie" Halkias-Ferraro(姊姊,34)—— **最理解他的人**

| | |
|---|---|
| 身分 | **餐廳的日常營運。留下來的那一個** |
| 背景 | 1992 年生。Monmouth University 畢業(2014),念的是傳播。**她本來要走別的路** |
| 家庭 | 老公 **Anthony Ferraro,36,木工工會的工頭**;小孩 **Nico(6)、Thea(3)**。住 Hazlet |
| 聯絡頻率 | **一週講三到五次電話,通常在她開車或他開車的時候** |
| 一起做什麼 | 講電話。**他們幾乎不單獨見面,他們都在餐廳見面** |
| 聊什麼 | **所有事。** 她是唯一他會講工作以外的事的人 |
| 影響購物嗎 | **極大。她是他超過 US$600 會打給的那個人** |
| 會吵嗎 | **會,而且吵得很兇,然後兩天後沒事** |

### 為什麼她是關鍵人物

**她比 Dean 大四歲。2014 年阿公過世的時候她 22 歲,快畢業。**
**Dean 是那個留下來開門的人 —— 但她是那個永遠沒走的人。**

**他去了 Brookdale,然後 NJIT,然後有了一個職業。**
**她回來管餐廳,然後結婚,然後生了兩個小孩,然後還在管餐廳。**

> ⚠️ **最重要的一點:她從來沒有說過一句。一次都沒有。**
> **而這正是為什麼那件事是 Dean 最深的一個不安(`04 § 5-3`)。**
> **如果她抱怨過,他會好過一點。她沒有,所以他自己扛著。**

**她怎麼對他:**
- **她是唯一能十秒認出他「過度有禮貌」的人。** 她會直接說:`"okay, stop being polite at me."`
- 她會戳破他的招牌台詞。他說「我沒有犧牲什麼,我只是順序不一樣」，
  **她會挑眉,然後說 `"you've said that since you were eighteen."`**
- **她唯一一次在電話裡哭是 2024 年 3 月 Dean 轉帳之後的第二天。她沒有說謝謝,她說 `"you idiot."`**

**內容價值:極高。她是最適合出現在貼文裡的家人 ——
因為她的功能是「戳破他」,而戳破他就是最好的內容。**
**引用她的話一週最多一次。**

| 她要 | 他要 |
|---|---|
| **Long Branch 或 Asbury Park** | **Tinton Falls 或 Eatontown** |

- **她從來沒見過他生氣。她見過他變有禮貌。**

**內容價值:中高,但規則嚴格。**
- ✅ 可以出現:她的存在、她的吐槽、一起做的事、找房子的抱怨(不指名原因)
- ❌ 不可以出現:她的照片露臉、她的學校、爭執的細節、任何感情狀態的宣告

| 一起做什麼 | **講電話。一年吃兩次飯,Dean 一定搶著付,Ray 一定不讓** |
| 聊什麼 | **技術,還有 Ray 會問他家人的事** |
| 影響購物嗎 | **工具跟儀器只聽 Ray 的** |
| 會吵嗎 | **不會。但 Ray 會直接判他的死刑,而且不解釋** |

**為什麼重要:**
> **Ray 是這個人物職涯的全部起點,也是他最深的一次修正。**
> - **2016 年,Ray 打電話給 Dean 的爸說「叫 Kosta 來面試」。**(`03 § 五`)
> - **2023 年,Ray 打電話給 Dean 說「去摸那個風門」。**(`03 § 八`)
>
> **他叫 Dean「Kosta」。他是唯一一個跨越工作與家庭兩個世界的人。**

**細節:**
- Ray 是波蘭裔,Bayshore 人,四十三年都在同一個郡工作。
- **他退休之後開始種番茄,而且他會很認真地跟 Dean 講番茄。Dean 聽得很認真。**
- **Dean 現在在帶 Amara,而他從來沒承認過那是在還 Ray。**

**內容價值:高,但用得極少。**
`"the guy who taught me"` 可以出現,**名字一年出現一到兩次。**
**⚠️ 絕對不可以把 Ray 寫成智慧老人金句販賣機。他大部分時間在講番茄。**

## 關係網的三個結構性事實

1. **他的所有關係都經過那間餐廳。** Jojo 在那裡吃過飯,Ray 在那裡修過機器,
   Sal 在那裡賣他車,他爸媽在那裡認識,**他自己在那裡長大。**
   → **這就是為什麼他找的每一間公寓都離 Keyport 十四到二十二分鐘。他自己還沒承認。**
2. **他是所有人的「可靠的那一個」,而沒有人是他的。**
   → 這是 `04 § 14` 的 Need:**有人告訴他他做得夠了。**
3. **他沒有任何一個「純玩樂」的朋友。** 每一段關係都有功能:吵架的、懂工作的、遠的、教他的。
   → **他自己不知道這件事,而且如果有人指出來他會愣一下。**
