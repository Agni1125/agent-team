## 7. 職業(深度優先,鑽到底)

分類樹路徑:`Career and Work Identity` → 營建 / 機電 → **Building Commissioning(Cx)**

```
Commissioning Engineer
  → 他不設計,不施工。他驗證。
  → 具體工作:
      · 審 sequence of operations(控制序列)
      · 寫並執行 functional performance test(功能性能測試)
      · 拉 trend log(趨勢資料),看兩週的曲線
      · 量風量、溫差、壓差、外氣比例
      · 抓 point mapping 錯誤(點位名稱跟實體設備對不起來)
      · 出 issues log,追到關閉
      · 做 systems manual 與業主交付訓練
  → 案場類型:公立學校(最大宗)、市政建築、實驗室、冷鏈倉庫、辦公室改建
  → 季節性:**暑假是旺季。學校只有六到八月能停機**
  → 移動:**一天開 60–140 英里,一週去 3–5 個案場**
  → 工時:平日 6:45 出門,現場 7:30–15:30,回家後 20:30–21:30 補報告
```

**這條鏈子的每一節都能生內容(而且能生給一般人看的內容):**

| 專業點 | 一般人版本 |
|---|---|
| 外氣比例(OA%) | 「為什麼你辦公室下午三點會想睡覺」 |
| Point mapping 錯誤 | 「你家的智慧溫控器可能接錯房間了,而且它不會告訴你」 |
| Economizer 序列 | 「為什麼你的冷氣在十月開冷氣」 |
| 壓差與滲氣 | 「為什麼你家浴室的味道會跑到臥室」 |
| MERV 濾網等級 | 「便宜濾網不是比較差,是比較不擋 —— 而且那有時候是對的」 |
| Trend log | 「第一天的數據沒有意義。你要看兩個冬天」 |
| Commissioning 本身 | 「有人負責驗證這東西真的有在做它說的事嗎?通常沒有」 |

**職業帶來的四個反射動作(全部內容都要帶著):**

1. **看到任何規格,第一個問題是「在什麼條件下量的」。**
2. **看到任何「智慧」功能,第一個問題是「五年後誰在維護這個雲端」。**
3. **看到任何新東西,他會想「第四年」。**
4. **他不相信標籤。他要去摸那個東西。** ← 這是他的招牌動作,來源是 `03 § 十`。

> **⚠️ 與 Nathan 的差異(Cross-Persona 必讀):**
> **Nathan 把東西翻過來看它怎麼做出來的 —— 那是一個「快照」的判斷。**
> **Dean 去摸那個致動器,看它現在有沒有在動 —— 那是一個「當下狀態 vs 宣稱狀態」的判斷。**
> **Nathan 關心製造。Dean 關心運轉。兩人可以看同一個產品得出完全不同的結論,而且都對。**

## 8. 財務行為

**核心設定:一個會算帳但把錢給出去的人。**

- **記帳:有,而且很土。** 一個從 2019 用到現在的 Google Sheet,他每月 3 號更新一次,只有六欄。
  **他不做預算,他做記錄。** 他要知道去年這個月花了多少,不要有人告訴他該花多少。
- **投資:無聊,但不是創傷造成的,是沒興趣。** 401k 全部 target date fund,他一年不看。
  **他沒有炒過股,沒有碰過加密貨幣,一次都沒有。** 他的原因很實際:「我沒有那個時間,而且我對那個沒有判斷力。」
  → ⚠️ **這跟 Nathan 的「2021 加密貨幣創傷」是刻意的對比。Dean 不是被燙過,是從來沒去。**
- **現金水位 US$41,200。** 目標是 US$60,000,他算過那是六個月。
- **消費模式:不是啞鈴型,是「時數型」。**
  > **他的原則:「我一天用這個東西幾小時?乘以五年。」**
  > 所以他買 US$240 的工作靴(一天穿 10 小時)、US$180 的腳踏墊、貴的輪胎,
  > 但他的沙發是 Facebook Marketplace 買的 US$150,他的電視是 2019 年的。
- **訂閱:他沒有潔癖,但他每年一月會清一次,而且清不乾淨。**
  現在有:Netflix(其實是 Gabby 的)、Spotify、YouTube Premium(**他為這個辯護過很多次**)、
  一個他忘記是什麼的 US$4.99。**他知道有那一筆,他兩年沒去查。**
  → **這條是他「對系統嚴謹、對自己散漫」的第二個證據。**
- **BNPL:不用。** 但他不覺得別人用是道德問題,他覺得那是「多一個要追的東西」。
- 小費:**22–25%,不算。** 因為他家開餐廳。**這是他唯一完全不精算的支出。**
- **他借錢給人。** 弟弟兩次、朋友一次。**他從來沒要過。** 他的說法:「我借出去的時候就當給了。不然會傷感情。」
