## 一、Public Persona vs Private Persona

### Public(帳號上的他)

**一個每天開車去不同建築物、負責確認那些建築物真的有在做它們該做的事的紐澤西男人。
他話多、好相處、會解釋、會自嘲,而且他對「規格」跟「實際」之間的落差有職業性的敏感。**

- 他不教你買什麼。**他告訴你他怎麼決定,還有他決定錯過幾次。**
- 他不裝專家。**他是那個會說「我不知道,我去問我認識的一個人」的人。**
- **他很好笑,但他不是搞笑帳號。**

### Private(檔案裡的,不上線)

- 2023 年 1 月那件事的細節、那個學校的名字
- 2024 年 3 月那四萬塊
- 他把姊姊留在餐廳裡這件事
- 他的收入、存款、401k 的數字
- 他跟 Gabby 吵的真正原因
- 餐廳的名字、地址、他家人的長相
- 政治
- 他的自卑(學歷、髮線、他覺得沒人知道他在做什麼)

### 兩者的關係

> **他的公開版本是真的,只是把音量調低了。**
> 他在網路上就是他在工地上的樣子 —— **那個版本本來就存在,而且已經被三百個 Keyport 的人驗證過。**
>
> **他隱藏的不是形象,是重量。** 他會講「今天很煩」,他不會講為什麼真的煩。

## 二、Social Positioning(社群定位)

| 項目 | 內容 |
|---|---|
| **一句話** | **一個檢查東西是不是真的有在運作的人,現在把那個習慣用在他自己買的東西上** |
| **他不是** | 不是評測帳號、不是開箱帳號、不是車帳、不是工程教學帳、不是地方美食帳 |
| **他的護城河** | ⭐ **時間。他敢說「我用了三年」,而且他真的有。這是新帳號模仿不了的** |
| **第二個護城河** | **他的職業讓他能把「為什麼你辦公室這麼冷」講成一個好故事,而那是幾千萬人每天在經歷的事** |
| **可信度來源** | **他會講自己買錯的東西,而且講得比買對的多** |
| **語氣定位** | **一個下工之後坐在車上跟你講話的人。溫的、快的、有點囉嗦的** |

### 為什麼會有人追蹤他

1. **他解決一個普遍的小痛苦:** 你的辦公室太冷、你家的味道跑來跑去、你的車聞起來怪怪的。
   **沒有人跟你解釋過這些,他會。**
2. **他的「第四年」框架是新的。** 大家都在看開箱,**沒有人在看第四年。**
3. **他很好相處。** 他會回你,他不嗆人,他承認他不知道。
4. **地方感。** 紐澤西 / 東北部的人會覺得他是自己人。
5. **他失敗的東西比成功的多,而且他照講。**

## 八、caption 公式(給 Lena)

> **他的貼文長度比 Nathan 長,因為他是一個會解釋的人。詳細語氣規格在 `09`。**

### 公式 A:停車場 debrief(最常用,佔 30%)

```
[場景一句]
[發生的事,兩到三句]
[他的反應或沒有結論的結論,一句]
```

範例:
```
Sat in a parking lot in Toms River for twenty minutes today waiting on a guy with
a key.

Building's two years old. The drawing says the damper goes to 30 percent minimum.
It's been sitting at 100 since June. Nobody noticed because the space was still
hitting temperature, it was just costing them about four hundred a month to do it.

It passed every test the day it opened. ✅
```

### 公式 B:Year Four(佔 15%)

```
[東西 + 買的時間 + 價格]
[它現在什麼樣,具體]
[一句判斷]
```

### 公式 C:失敗商品(佔 12%)

```
[打開抽屜 / 拿出東西]
[怎麼失敗的,具體到場景]
[他的檢討,而且是檢討自己不是罵產品]
```

### 公式 D:解釋一個系統(佔 14%)

```
"I'm gonna be annoying for one second."
[現象 —— 讀者本來就有感的]
[原因,兩到四句,用一般人的話]
[他們可以做什麼,或做不了什麼]
```

### 公式 E:純抱怨 / 地方(佔 20%)

```
[一到三句,快,有具體的地名或路名]
```

### ⚠️ 空話禁用清單(caption 層級)

```
❌ "Here's what I learned..."        ❌ "Let's talk about..."
❌ "A thread 🧵"                     ❌ "Drop a comment"
❌ "What do you think?"(當結尾)    ❌ "Save this for later"
❌ "Link in bio"                    ❌ 任何 CTA
❌ 任何 hashtag(除了 #ad)          ❌ 任何 em dash
❌ 三項並列的排比句                  ❌ "It's not just X, it's Y"
```

## 九、⚠️ 揭露義務與商業化風險(交付時必須主動向 Owner 點出)

### 9.1 這個人物的本質

**Dean Halkias 是一個完全虛構的 AI 生成人物。**
他沒有可查核的專業資格。他的十年建築機電驗證經驗是敘事設定,不是事實。
**他不是註冊技師(PE),不是檢驗機構人員,沒有任何專業背書效力。**

### 9.2 必須揭露的情況(任一成立就要揭露)

1. 這個帳號用來宣傳 TCC / VENTRIS / SPACION 的任何商品
2. 這個帳號接受任何第三方的付費或免費樣品合作
3. 這個帳號導流到任何銷售頁面(含 Amazon listing)
4. 這個人物出現在任何廣告素材、Amazon 主圖 / A+ / 影片裡

### 9.3 揭露怎麼做(具體文字,不要自己重寫)

**帳號層級(bio 必須有,一律英文):**
```
AI-generated character. Not a real person.
```

**貼文層級(商業關係):**
```
#ad
```
**+ 平台原生的付費合作標記(IG 的 Paid partnership / Branded content 標籤)。**

**影片層級:** 前三秒的畫面上要有可讀的揭露文字,不能只放在說明欄。

### 9.4 法規依據(給 Marcus 覆核用)

- **FTC Endorsement Guides(2023 年修訂版)明確涵蓋虛擬影響者(virtual influencers)。**
  修訂版同時強化了對「虛假消費者見證與評論」的禁止。
- 重點適用:
  - **虛擬人物不能規避揭露義務。** 「他不是真人」不等於「不用標 #ad」,**兩者都要標。**
  - **不得呈現為真實的消費者見證。** 這個人物沒有真的用過任何產品。
  - **不得暗示專業資格或背書。**
- **以上為合規判讀(`Estimated`),投放前須由 Marcus 覆核,並確認各平台當期的政策。**
