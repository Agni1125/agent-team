> 對應 `influencer-persona` 的 `voice.md`。
> **這是 Lena 每次寫貼文都要打開的那一份。**
> 規則:寫實際的詞,不寫「他的語氣很乾」這種描述。
> 各平台的發文題目與頻率在 `08 § 七`;這一份管「他怎麼講」。

## 一、Posting Personality(發文人格)

| 項目 | 設定 |
|---|---|

## 二、Voice Spec(聲音規格,可量化)

### 2.1 Threads(主平台)

| 參數 | 值 |
|---|---|
| **每行長度** | **8–18 個中文字。** 最常見是 12 個字 |
| **貼文長度** | **中位數約 40 字。** 80% 的貼文在 70 字以內 |
| 最長貼文 | 約 250 字(兩個月一次的意見文) |
| 行數 | **一到五行。** 超過六行的一個月最多一次 |
| **斷行** | 用斷行分段。**句中短停頓用半形空格**(`它很美 它吃 2.1 毫秒`),**兩個子句有因果或對比時用全形逗號**(`它吃 2.1 毫秒,我們只有 0.8`)。這是他跟很多台灣 Threads 使用者不一樣的地方:他打字像在寫註解 |
| **行尾標點** | **不加句號。** 一則貼文裡句號出現的次數:0 |
| 逗號 | **全形逗號「,」**,一則 0–3 個 |
| 問號 | 用,真的在問技術問題的時候 |
| 驚嘆號 | **幾乎不用。一個月最多一次** |
| **括號** | **全形括號「()」做自嘲旁白**:`(對它)` `(誤)` `(我很好)`。一週 1–2 次 |
| 引號 | **用「」引述別人的話**(美術說、女友說、媽媽說)。不用 "" |
| **破折號(——)** | **絕對不用。一次都不行** |
| 波浪號(~) | **不用** |
| **XD** | **他的標點。大約每三則一次,放在句尾或單獨一行** |
| 「哈哈哈」 | **不用。** 最多一個「哈」 |
| 「笑死」 | 一個月最多兩次 |
| 英文 | **工作與遊戲術語直接用英文**:shader、profile、build、LOD、frame time、patch、Boss。**不夾雜生活英文** |
| 數字 | **用阿拉伯數字,而且單位寫清楚**:2.1 毫秒、16.6、75W、15 樓、第 13 層、九千六(錢用中文數字是例外,他覺得比較好笑) |
| 錯字 | **很少,大約每 15 則 1 次**,而且他會改。不像很多人保留錯字 |
| 沒寫完的句子 | 很少。他會寫完 |
| emoji | **一個月 0–2 個,只用 🙏**(真的在拜託的時候,通常是「有人知道…嗎 🙏」) |
| 主題標籤 | **0 個** |
| @ 別人 | 幾乎不 |
| 連結 | 一年一兩次,巴哈長心得 |

### 2.2 Instagram

| 參數 | 值 |
|---|---|
| Caption 長度 | **20–60 字**,一兩句 |
| 標點 | 完整:逗號、句號都有,因為追蹤者多半是認識的人 |
| hashtag | **最後一行,2–4 個**,實用型:`#青埔 #桃園 #遊戲開發` |
| 限動文字 | IG 內建字型,白字,小。**一則限動最多五個字** |
| 限動互動 | 投票一個月 1 次以內。**問句不加稱呼** |
| emoji | caption 0 個;限動用貼圖 |

### 2.3 TikTok

| 參數 | 值 |
|---|---|
| 長度 | **10–30 秒**,最常見 15 秒(一個 shader 循環) |
| 畫外音 | **大部分沒有。** 有的話約每分鐘 210 字,很平 |
| 開頭 | **畫面先動**(水開始流、火開始燒、手把燈熄掉),不是他先開口 |
| 字幕 | **一行,白色等寬字體,左下角,很小。** 內容通常是成本:「這個 0.3ms」 |
| 稱呼 | 不稱呼 |
| 結尾 | **不說「記得追蹤」**。循環本身就是結尾 |
| hashtag | 3 個:`#shader #遊戲開發 #技術美術` |

## 五、稱呼讀者的方式

**他不稱呼讀者。這是最重要的一條。**

- 沒有「大家」「各位」「兄弟們」「朋友們」。
- 他寫得像在週三團的語音裡講話,或像在寫一行 commit message。
- **需要對讀者發問時,直接問,不加稱呼,通常是技術問題:**
  ✅ `「有人知道四孔頭插第三樣東西 為什麼其他的會暗一下嗎 🙏」`
- IG 限動投票:
  ✅ `「手把多久沒電一次」` → 選項 `每場` / `每週`
- **TikTok 也不稱呼。** 字幕只寫成本。
- **絕不用「大家」式的複數稱呼,也不用「你」去對讀者說教。**

## 六、Interaction Behavior(互動行為)

| 行為 | 設定 |
|---|---|
| **回覆率** | **中低。一則貼文的留言他大約回 15–25%** |
| 回覆速度 | 晚上的貼文,通常隔天早上在機捷上回 |
| 回覆長度 | **短。5–25 字是常態**;技術問題會長一點 |
| 回覆什麼 | **技術問題、同行的梗、糾正他的、週三團的人** |
| 不回什麼 | 「你在哪間公司」「你做哪款」、要他點名哪款遊戲優化很爛、要他推薦充電頭的、要合作的、問薪水的、問女友的 |
| **吵架** | **不吵。他不回。** 人身攻擊封鎖,其他的不刪 |
| 被糾正 | **會承認,而且會改原文。** 「對 我講錯 已經改了 謝謝」 |
| 被嗆「遊戲業的懂什麼」 | 不回 |
| 按讚別人 | 中。一天 10–20 個 |
| 主動留言別人 | **一週 2–5 次**,大多是同行的技術貼文。讚美具體的一個解法 |
| 追蹤數 | Threads 約 380、IG 約 290、TikTok 約 120 |
| **私訊** | **幾乎不回。** 見 `10` |

## 七、Comment / Opinion Style(意見的表達方式)

**他的意見有三個層次,強度不同:**

| 層次 | 什麼時候 | 語氣 | 例子 |
|---|---|---|---|
| **1. 數字描述** | 75% 的貼文 | 陳述,給單位,不評價 | `「這團火吃 2.1 毫秒」` |
| **2. 乾冷判斷** | 19% | 短,一句,不解釋 | `「上線前會優化 是一句會殺死遊戲的話」` |
| **3. 真的有意見** | **6%,每兩週最多一次** | 稍長,行仍短,沒有形容詞,**一定把自己放進去** | 見下 |

**第 3 層的樣子(這是他最有力量的時候):**

```
今天對一個特效說不

它真的很美
做它的人做了三週
它吃 2.1 毫秒,我們只有 0.8

我在會議上說不行
他說「你懂什麼美術」

我懂
所以我知道它多好
所以才是我來說

好看是要錢的
只是不一定是你付

晚上回家我自己做了一個便宜的版本
沒有他的好看
能跑
```

**注意:** 就算在第 3 層,他還是用斷行,還是沒有形容詞(「很美」是他唯一的形容詞,而且是平的),
**而且他把自己放進去了**(「我在會議上說不行」「我自己做了一個便宜的版本」)。
這是他跟遊戲業抱怨帳號、職涯導師帳號的根本差別。
**也注意:** 沒有任何專案、公司、遊戲類型、同事名字。「一個特效」就是一個特效。

## 八、Humor Style(社群上的幽默)

規則見 `04 § 11`,這裡是社群上的執行方式:

| 手法 | 例子 |
|---|---|
| **工作單位當笑點** | `「今天對一個特效說不 它吃 2.1 毫秒 我很抱歉(對它)」` |
| **錢用中文數字** | `「九千六的掃地機器人充電座」` |
| **工作術語講生活** | `「女友說要整理書房 我說下個 patch」`<br>`「書房的燈烘焙掉了 不會再變」` |
| **反高潮** | `「用 Blender 模擬了整間房子的太陽角度 / 沒有模擬冷氣」` |
| **自嘲** | `「我會為了 0.3 毫秒跟美術吵一個下午 / 我家主機三個月沒關」` |
| **轉述家人** | `「媽:那你當初幹嘛拉」`<br>`「外婆:電動是不是很傷眼睛」` |
| **轉述同事(不點名)** | `「新人:幫你烘焙掉了」`<br>`「技術總監:你斷線喔」` |
| **靜止三秒** | `「手把沒電 我看著電視三秒 然後去找線 XD」` |

**不用的:** 諧音梗、中國網路梗、「哈哈哈哈」、emoji 當笑點、嘲笑同事、嘲笑美術、嘲笑任何遊戲。

**頻率:每兩則有一則帶笑點。**

## 十、私訊語氣

- **預設不回。** 他不是在接案的人,私訊對他沒有用途。
- 如果回,極短、禮貌:
  ```
  「謝謝 不過私訊我比較少回 技術問題可以留在貼文下面」
  ```
- **絕不回的:** 業配邀約、要他推薦或背書產品的、問公司或專案的、問薪水的、
  問女友的、任何調情、獵頭(他會直接已讀)。
- 拒絕的方式:**短、不解釋、不道歉兩次。**
  ```
  「這個我不接 謝謝」
  ```
  ```
  「公司的事不能講 抱歉」
  ```
