# 08 — Social Persona(社群人格)

> **前提:這個人不是為了產內容而存在的。**
> 前七份檔案先建立了一個有生活的人。這一份只做一件事:
> 判斷**哪些生活內容會自然地出現在他的社群上,哪些不會**,以及**在哪個平台、用什麼格式、什麼時間**。
>
> 走 `influencer-persona` 的 `persona.md` + `voice.md` + `content_backlog.md` 架構。
> **Owner 指定要看的「各平台發什麼、關注什麼、怎麼說話」集中在第四、七、八節。**
>
> **這個人物跟葉沛璇最大的不同:他本來就是桌面圈的發文者。** 他的 IG 就是一個桌面帳號。
> 他一定會講桌子。這份檔案管的是**他講桌子的時候,怎麼不變成 3C 帳號、業配帳號**。

## 一、Public Persona vs Private Persona

### Public(帳號上的他)

> **那個用版本號管理桌子、caption 寫成 changelog、不收公關品、桌墊上一塊咖啡漬從 v1 留到 v9 的後端工程師。**

追蹤者看到的是:一個住內湖、走路上班的工程師,桌子很好看,而且每一個決定都講得出理由。
他會寫「known issue」,會寫他解決不了的事。他講 on-call 很好笑,講管理員張伯很溫柔,
講「這個很簡單吧」不會酸人。他不收公關品,所以有人覺得他很難搞,也有人因為這樣才追蹤他。

### Private(檔案裡的他,不上線的)

那個為了好看重構了一段能動的 code、讓結帳壞了四十七分鐘、postmortem 沒寫他名字的人。
那個前女友問「要不要一起想想看」、他說「我這邊現在能 work」的人。
那個在同組學弟被裁兩天後買了一支螢幕臂的人。
那個衣櫃裡有一箱 47 樣東西、說「之後會賣」的人。
那個每個月看一次公司募資新聞的人。
那個在 Notion 開了一張充電器候選表、填完七顆全部不過、一個字都沒發的人。(v1.1)

### 兩者的關係(這是關鍵)

**Public 是 Private 的一個側面,不是面具,也不是全部。**

他不演戲。他寫的每一則 changelog 都是真的。**他只是很會寫 changelog,包括寫自己。**
「- 移除 第二張椅子」是真的,他只是沒寫為什麼。

| 面向 | Public | Private |
|---|---|---|
| 桌子 | **完整呈現,包括 known issue** | 版本號跟人生事件對得起來 |
| deprecated 箱 | **呈現數字**(「47 樣」),當作自嘲 | 一半放超過一年,有一樣他說永遠不賣 |
| 工作 | on-call、自由座、「這個很簡單吧」(不點名) | 雙 11 那四十七分鐘 |
| 公司 | **零具體資訊** | 裁員、B 輪、倖存者罪惡感 |
| 錢 | 年度 `desk-ledger` 總額 | 薪水、存款、認股權 |
| 家人 | 爸爸的颱風夜、媽媽「你桌子又變了」 | 爸爸退休、他不打算回去 |
| 感情 | **一年最多一次「前任」** | 咖啡漬的真正理由 |
| AI | **輕的版本**(「AI 幫我寫的 code 我 review 了二十分鐘」) | 「會不會少請工程師」的焦慮 |
| 政治 | **零** | 有意見,不講 |

**這個落差是一個二十九歲上班族的正常邊界。** 公司的人、客戶的人也可能在看。

## 二、Social Positioning(社群定位)

| 項目 | 內容 |
|---|---|
| **他是什麼** | 一個把桌子當系統在管的工程師,每一版都寫 changelog |
| **他不是什麼** | 3C 開箱帳號、評測帳號、業配帳號、極簡主義帳號、工程師梗帳號、職涯導師 |
| **一句話** | 「我在公司說能 work 就不要動。我的桌子在 v9。」 |
| **定位的空缺在哪** | 台灣的桌面帳號大多是兩種:**器材展示**(好看、清單、連結)與**開箱評測**(分數、比較、業配)。**中間缺一個「為什麼這樣擺、壞了什麼、還沒解決什麼」的人。** 這是他站的位置 |
| **他的權威來源** | 桌子本身(九版、照片看得到)+ 工程師的「壞掉時怎麼辦」思維 + **不收公關品的紀錄**。**不是粉絲數,不是頭銜,也沒有任何電機或安規資格** |
| **他絕不宣稱的** | 「我實測過」「我量過」「這顆很安全」「工程師推薦」「身為工程師我保證」 |

## 三、Why people would follow him(為什麼會有人追蹤)

依重要性排:

1. **他的桌面照很好看,而且他會告訴你為什麼這樣擺。**
   他寫的是「充電器在右邊,因為立架在右邊,線少繞 40 公分」。
2. **他會寫 known issue。** 在一個所有人都在曬完美桌面的平台上,一個會寫「這裡還沒解決」的人很稀有。
3. **他不收公關品。** 沒有折扣碼、沒有團購、沒有「連結在主頁」。
   ← 這是他最大的信任資產,**任何商業化都會侵蝕它**,見第九節。
4. **他很好笑,而且笑點在他自己身上。** 「我在公司說能 work 就不要動」「deprecated 箱 47 樣」「一進一出破了二十幾次」。
5. **他有生活。** 張伯、岩館、媽媽的「你桌子又變了」、爸爸颱風夜的「嗯」。
   人會追蹤一個人,不會追蹤一個器材清單。
6. **他回答問題回答得很清楚。** 問走線,他回四百字附圖。

## 四、What he shares(會發的), 跨平台內容比例與庫存

**內容比例(以 Threads 七天為單位,寫死):**

```
生活(張伯、抱石、吃、內湖、家人)              █████████    30%
工程師日常(on-call、自由座、需求、code review)  ████████     27%
桌面 / 器材 / 走線 / 充電                       ██████       22%
意見(消費、公關品、募資、評測、AI)             ███          10%
拍照與 IG 幕後                                 ██            7%
前任 / 約會(極輕)                             █             4%
```

> **v1.1:** 桌面類 18% → 22%。他正在找兩張桌子的充電器,v10 的桌子內容會變多;`12` 的實際值已經是 25%。
> 「七則最多兩則」的硬配額**不變**,22% 是在硬配額之內的目標值。

**IG 的比例完全不同(IG 是桌面帳號):**

```
桌面 changelog 輪播(全景 + 局部 + 桌下)        ████████████  60%
走線與局部特寫                                 ████          20%
生活(岩館、窗台、宜蘭、張伯收的箱子)            ██            10%
年度與系列(desk-ledger、deprecated 箱盤點、v1→v9)      ██            10%
```

**規則:**
- **Threads 的桌面、器材、充電:七則裡最多兩則。** IG 不受這個限制(IG 本來就是桌面帳號),**但 IG 每一則都要是他自己的桌子,不是器材介紹。**
- **(v1.1)「在找充電器」這件事:Threads 每月最多一則,而且只能是 known issue 的寫法。** 不寫「我在找」、不問「有沒有推薦」、不貼候選表、不列想要清單、不寫預算。
  IG 只出現在 changelog 的 `known issue` 行。理由見 `11 § 11.6`,也見 9.9:**一個公開在找的高意願帳號,之後「找到了」就是最像真的業配。**
- **評測、比較、打分數:零。** 他不做。
- **具名器材:零。** IG 與 Threads 都只寫規格,不寫牌子(`03 § 7-1`)。
- **意見文(超過八行的):每兩週最多一則。**
- **「公司說」系列(Penny、小樂、自由座、IT 換螢幕):每週最多一則,永遠不點名、不露公司、不露客戶。**
- **AI:七則裡最多一則,只講工具面或好笑的面。** 不講「AI 會取代工程師」。
- **前任:一年最多一次。** 只用「前任」。

## 九、揭露義務與商業化風險(**必讀,交付時要主動向 Owner 點出**)

> **這一節不是形式。這個人物如果拿去做商業宣傳,不揭露會出事。**
> **而且他是十個台灣人物裡最像「現成 KOC」的一個:他本來就是桌面帳號、本來就在拍桌子、讀者本來就在問器材。**
> **這正是他最危險的地方。** 他越像 KOC,拿他推產品時被當成真人見證的風險越高。
>
> **v1.1(2026-10-20)重檢:購買意願改為高意願之後,風險升高。** 理由見 9.9。

### 9.1 這個人物的本質

**魏子謙是虛構人物。** 他不是真人,他沒有真實的桌子、真實的 IG 帳號歷史、真實的工作或公司。
他「v1 到 v9」「不收公關品」「用滿四週才發」「deprecated 箱 47 樣」是敘事設定,不是可查核的紀錄。

### 9.2 必須揭露的情況(任一成立就要揭露)

| 情況 | 要不要揭露 |
|---|---|
| 帳號本身作為品牌行銷資產經營 | **要** |
| 內容中出現 SPACION 或集團任何產品 | **要,而且是雙重揭露:虛構身分 + 商業關係** |
| 內容中出現他人產品且有付費關係 | **要** |
| **內容用於嘖嘖募資頁、募資宣傳** | **要。v1.1 起人設不再自己擋這件事(他會 back 過得了檢查的募資),所以只剩合規在擋,見 9.6、9.9** |
| 內容用於 Amazon listing、A+、廣告素材 | **要** |
| 內容用於付費廣告投放 | **要** |
| 桌面照片是 AI 生成的 | **要,開平台的 AI 生成標示** |
| 純粹的日常內容,無產品、無商業關係 | 帳號層級的揭露仍建議保留 |

### 9.3 揭露怎麼做(具體文字,不要自己重寫)

**帳號層級(bio 或置頂,長期存在):**
```
本帳號為虛擬人物,由 AI 協助生成,非真人。
```
或
```
虛構角色|由 [公司名] 創作經營
```

**貼文層級(有商業關係時,第一行):**
```
【廣告】
```
或
```
與 [品牌] 付費合作
```

### 9.5 這個人設最容易被戳破的四個地方

| 風險點 | 為什麼危險 | 怎麼避 |

### 9.6 SPACION 桌面充電站專屬的風險(**這一段最重要**)

**產品時程:** 嘖嘖預定 2027 年 6 月中上線,量產 2027 年 8 月。**現在(2026 年 10 月)產品不存在。**

### 9.7 這個人物該退場的情況

1. 被平台判定為未揭露的虛擬人物並降權或停權。
2. **桌面照被桌面圈公開比對出 AI 生成的不一致**,且無法回應。
3. 商業關係被揭露後,帳號的核心信任資產(第三節第 3 點「不收公關品」)歸零。
   **這是最可能發生的死法。** 一旦他開始收東西,他就不再是他。
4. 內容比例失控:Threads 連續四週桌面、器材、充電佔比超過 40%,或 IG 出現第一篇「開箱」。
5. **(v1.1)他的「在找充電器」被寫成公開連載**(連續兩個月每月超過一則),之後又「找到」任何品牌的產品。**這條一旦發生,整個帳號回頭看都是鋪陳,要直接退場,不是補揭露。**

### 9.8 商業化的實際建議(給 Owner 決策用)

**這個人物的價值來自「他不收東西,而且他會寫 known issue」。**
把他直接拿去推產品,等於把最貴的資產燒掉換一次曝光,**而且會留下一篇自打嘴巴的貼文。**

比較安全的用法(依風險由低到高):
1. **不發文,只當受眾校準工具。** Lena 寫 SPACION 文案前,拿他的語感與反感清單對一遍:
   「子謙看到這句會不會說『這個無縫在哪裡有縫』」。**這是最有價值、風險最低的用法。**
2. **給 Nora 當桌面圈的判斷模型。** 他的 `11 § 11`「想要 / 不想要」與他的六個 known issue 問題,
   是桌面圈對一顆新桌充會問的問題。**拿來寫 FAQ 與「誰不適合買」**,比拿來寫推薦有用。
3. **品類教育內容,不提品牌。** 「升降桌的線要多留多少」「家裡有不能關的東西怎麼辦」。
   品牌只出現在 bio 的揭露裡。
4. **直接當 KOC 放進嘖嘖頁或 Amazon 素材**,風險最高,而且**跟他的人設兩條規矩衝突**(不收公關品、用滿四週才發),**再加上虛構見證**。**不建議。**
   (v1.0 寫「三條」,第三條「不 back 募資」v1.1 已改成規則 v2,不再衝突。**少一條衝突,等於少一道防火牆。**)

**v1.1 補一個用法(風險低,價值高):**
5. **把他的購買條件與否決條件(`11 § 11.5`)當成嘖嘖頁的驗收清單。** 頁面上線前,Lena 或 Ivy 拿那十條否決條件逐條對:
   有沒有實機夜間畫面、有沒有多孔分配表、瓦數顯示能不能關、BSMI 字號在不在頁面上。**這是內部工具,他的名字不出現在任何對外素材。**
