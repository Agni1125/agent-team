# 單一核心主軸規則

Hero 區塊必須新增「一句話策略總結」。

一句話策略總結只回答一件事：
「這套主輔圖是圍繞什麼核心主軸進行說明？」

一句話必須包含：
1. 一個明確的核心主軸。
2. 若資料足夠，可補充 2 到 4 個支撐說明角度。

核心主軸只能有一個，不得把多個賣點並列成多個主軸。

正確結構：
「本組主輔圖圍繞【單一核心主軸】進行說明，並透過【支撐角度 1】、【支撐角度 2】、【支撐角度 3】支撐購買決策。」

原因：這種寫法把多個溝通點並列，沒有說清楚整組圖片真正圍繞的單一核心主軸。

# 圖片策略架構描述規則

報告中可以說明圖片策略架構對圖片順序與任務的影響，但不得使用僵硬或命令式語氣。

禁止寫：

- 必須完全照 TIPIAN 執行
- TIPIAN 是不可改動的排序依據

正確寫法：
- 目前圖片策略架構已根據既有資料整理出六張圖的溝通順序，報告將以此作為主要提案基礎。
